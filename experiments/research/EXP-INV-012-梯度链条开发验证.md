# EXP-INV-012：梯度链条开发验证

**状态：Draft，已登记，未实施或运行，尚未形成执行锁。** 开发别名为 `MVP-INV-001`。问题是：冻结 Global–Local 的梯度能否经 Fourier 参数化传递，并在最终硬几何上带来可复核的 MPB 目标裕量改善？本实验只验证机制，不承担独立泛化或正式优越性结论。

## 执行前冻结

1. 锁定源 spec、模型 factory/指纹/state-dict/hash、输入字段、shape、k、normalizer 和原始参考输出；确认固定融合与门控身份。
2. 在合成及源几何上检查 tensor 与 NumPy Fourier 标准化、软/硬材料和降采样合同，禁止在参数链条中 detach。
3. 仅用本来源的代理与数值重复诊断校准 $T,\beta,\gamma$、AD–FD 容差、噪声阈值、Adam 学习率及步数，再锁定物理方向清单。先固定温度；continuation 留作有独立版本的开发扩展。
4. 锁定所有候选生成规则、随机种子、物理配置、失败规则、预算及六个 WSL 复核角色。完成本轮必要工程测试后才生成不可覆盖执行锁。

这些未决数值不以“合理一致”作为事后过门标准。开发校准可以失败或产生新版本；每版留下配置和全部结果，正式比较前再冻结独立协议。

## 候选与有界预算建议

以下是可审阅的首轮预算提案，不继承旧 011 额度，也不代表本次已经授权提交。用单例准入测量核时/内存后确认能否容纳；不足时调整协议版本和额度，不在运行中减少原已承诺的对照。

| 部分 | 预定规则 | 新增硬几何物理评价上限 |
|---|---|---:|
| 局部测试点 | $z=0,\pm0.05e_1,\pm0.05e_2$ | 5 |
| 方向检查 | 每点在半径 0.05、0.10 各测 $+g,-g,+r,-r$；随机单位方向按固定种子产生 | 40 |
| MPB FD | 原点，两个坐标，两个归一化步长 0.025、0.05，中心差分 | 8 |
| 物理 FD 方向 | 从已锁定 FD 规则得到的方向及反向，半径 0.05、0.10 | 4 |
| 短程优化 | 原点各运行 Adam、DE、Random；每组最多 20 个搜索目标评价，选一个硬候选 | 3 |
| 合计 | 包含不复用时的所有中心和候选，重复栅格按预定规则复用并保留提案记录 | **60** |

先在原点完成方向、FD 和三个短程终点，再扩展其余四个局部点；原点链路和数值条件不成立时，停止受影响部分并保留原上限，不扩展局部点。60 是候选评价组上限，不是 MPB 单次调用上限。每组包含带边加密和 192/224 分辨率计算，其内部任务数逐项记账。MPB FD 方向使用物理结果，是额外高保真参考，其全部 FD 成本单列；其余方向及优化候选在揭示这些结果前锁定。梯度为零、非有限、几何非法或投影后同栅格时保留无效/重复状态，不抽新点替代。

代理 AD–FD 在五个局部点采用多个预冻结步长，例如 $10^{-2},3\times10^{-3},10^{-3}$ 的归一化坐标扰动，并检查减小步长是否受 FP32 噪声主导。软结构的真实一致性检查另预留最多 **3 个**连续材料诊断组：在原点对三个冻结温度用相同 81 k 的 MPB 与代理比较；这些是灰度物理诊断，不计作最终二值设计成功。总新增评价组上限因此为 **63**。

拟设 M9 新增分配核时总上限 **150 核时**（含准入、失败和获授权重试），GPU 总上限 **1 卡时**；最多 4 个 CPU 作业并发。WSL 六个预选角色复核另设 **20 核时**上限；以上为草案，需由相同数值合同的实测确认。达到任一上限即保留 partial，不自动扩容或补样。代理几何/FD 诊断、搜索 forward/backward、硬重预测与缓存分别计数，不能把 20 次目标评价当成相同计算成本。

## 物理合同与公平性

首版名义偏移为零。拟复用 010 的 512 物理主栅格、`resolution=192/224`、`mesh_size=7`、eigensolver tolerance $10^{-9}$、10 条目标带加 4 条 guard band、自适应带边 2–6 层及连续两层稳定的合同；edge/resolution tolerance 均为 $5\times10^{-4}$，WSL 全谱绝对差容差为 $10^{-6}$。具体字段以执行锁内完整求解配置为准，不能用这段摘要替代配置 hash。

区分以下比较：AD–FD 使用同一软函数；软诊断用相同介电分布与 81 k；最终方向收益使用合法硬几何和相同加密/分辨率。精确 $J_{81}$、平滑目标和加密 $J_P$ 分列。原始代理谱带序异常单独记录；主实验不静默排序后继续，排序修复若研究则作命名控制版本并保留原谱。

五点方向实验对所有方法用相同半径；边界裁剪或非法几何不随结果更换候选。Adam、DE、Random 使用相同软目标、箱域、温度和硬候选选择规则；本来源短程终点只作链路比较，不据此宣布优化器优劣或收敛。L-BFGS、多初值和维度扩展进入 013。

WSL 六个复核角色预定为原点基线、原点半径 0.10 的正梯度、负梯度、正随机、Adam 终点和 DE 终点；几何重复则标记重复及有效角色覆盖，不按已知结果替换。来源 8 已知可能有正裕量，必须报告相对初值的改进，不能只凭最终 $J>0$ 声称梯度使设计成功。

## 指标、gate 与失败

| Gate | 要提交的证据 | 对下一步的影响 |
|---|---|---|
| 身份与复现 | 源几何/输入/原始预测一致；权重无更新；所有 hash 与求解合同可验证 | 不符先修复，不提交候选 |
| 参数数学梯度 | 五点完整 AD–FD、步长稳定性、相对误差/余弦/范数，按预冻结容差判定 | 输入空间诊断不能替代本 gate |
| 松弛与投影 | 连续诊断误差、软硬预测差、硬几何可行性和投影后的 MPB 结果 | 失真先调整表示，再登记新版本 |
| 真实方向 | 所有正/负/随机/FD 候选的真实增益及误差尺度，六角色跨环境状态 | 判断是否值得扩展；混合或负结果允许结束 MVP，不宣称普遍改善 |
| 记录和资源 | 全部尝试、失败、重复、原谱、费用和物理未决完整 | 缺失不能标 completed |

MVP 的方向判读预先区分：改善高于冻结数值噪声且跨局部点可重复、结果混合、无可判定改善。具体噪声尺度在候选揭示前校准；不追求事后漂亮的正方向比例。S2 的独立多来源公平对照才检验平均方向收益及优化优越性。63 组未完成时报告覆盖和原因；失败不从分母删除。
