# PCSEL多晶格测试数据生成协议

用户已认可形状确认图谱，并授权使用Bingxing M9计算及交付N40。冻结S01、S02、D01–D05、T01–T03、Q01、U01共十二族，各2000参数点，共24000结构；全部为测试数据。旧EXP-DAT-007的12000结构同时交付N40，不重新求解。主层为L3；仅为接入现有数据与HPC接口增加必要的L4实现，不执行模型评价。

## 一、冻结几何

精确参数积与图谱一致，入口为 `pcsel_parameter_rows`；解析几何入口为 `pcsel_primitives`。图谱确认版本为Draft01，用户确认日期2026-10-21。所有长度均以方形单胞边长归一化。

| 族 | 定义 | 名义点数 |
|---|---|---:|
| S01 | 变高底比等腰三角；100面积×5高底比×4角度 | 2000 |
| S02 | 等腰直角三角；200面积×10角度 | 2000 |
| D01 | 双椭圆不等面积；100面积×5面积比×4位移 | 2000 |
| D02 | 双椭圆等面积；100面积×5位移×4轴比 | 2000 |
| D03 | 倾斜椭圆与圆；100面积×5位移×4轴比 | 2000 |
| D04 | 轴向椭圆与圆；100面积×5轴比×4面积比 | 2000 |
| D05 | 对角双圆；100面积×5面积比×4位移 | 2000 |
| T01 | 固定半周期位置的三个等圆；2000面积 | 2000 |
| T02 | 右上圆孔移位；100面积×5偏移幅度×4偏移比例 | 2000 |
| T03 | 对角三圆；100面积×5孔位扰动×4面积比 | 2000 |
| Q01 | 不等面积四圆；100面积×5面积比×4孔位偏移 | 2000 |
| U01 | 三圆并集连通孔；100面积×5圆间距×4三角高度比 | 2000 |

U01保留“参考照片的候选近似”身份；D01/D02只复现俯视几何，未包含孔深非对称；全部结构不声称完整PCSEL器件复现。多孔面积指周期并集面积。U01使用精确圆弧并集面积和积分重心缩放，替代图谱绘图用的384边形面积近似，不改变形状定义。

来源：[Wang等2022](https://doi.org/10.3390/app122010581)、[Yoshida等2019](https://doi.org/10.1038/s41563-018-0242-y)、[Wang等2024](https://doi.org/10.1038/s41377-024-01387-4)。其中未在论文给出精确尺寸的扩展仍记录为项目测试参数，不升级为原器件精确复刻。

## 二、求解与资源

配置为[冻结配置](../../configs/research/full_cell_pcsel_exp_dat_008_bingxing_v1.yaml)。沿用TE、真实MPB、r64、mesh3、10条目标能带加4条guard、频率排序、容差1e-7及原9×9完整BZ顺序。介电常数为空气1、材料8.9；输出 `Wh[24000,81,10]` 及解析结构、32/64/128/256输入表示。

沿用M9的4个独立分片，每片6000结构、64个单线程worker、64GB，总并发最多256核。先验证新解析接口及全量几何；使用既有plan→solve-shard→finalize控制面。不得自动重试、resume、取消失败任务或改变资源。标签生成不构成新形状r64/r96/r128收敛通过；本次保留 `generation_only` 边界。

## 三、审计和交付

逐结构记录解析身份、面积误差、含周期像的分离间距证书、栅格哈希和失败记录。T01细密面积扫描等可能出现相同栅格输入；保留不同解析边界，并明确记录输入碰撞分组，不将其解释为独立制造样本，不静默丢弃或扩域补点。参数重复仍为错误。

集群完成、下载与哈希审计、WSL Ubuntu/meep_env跨环境验收、N40交付分别记录。N40文件以临时后缀传输，SHA-256相同后原子落位；遇已有不同内容时停止，不覆盖。保留数据文件、配置、sample plan、metadata、版本、哈希清单、耗时、失败及Slurm记录。无标签内容、失败或非有限频率时不能称完成。

## 四、接入边界

新几何独立放在 `phc2d.data.pcsel_geometry`，通过已有材料评估器和 `full_cell_band` adapter接入。历史 `full_cell_generation.py` 已超出模块行数警戒线；本次仅增加协议分派薄接口，避免对既有运行格式和哈希合同做大范围迁移。结构构造与配置校验留在新模块，后续模块化另行处理。

下一门为正式数据完整性与跨环境验收；本协议不授权模型训练、normalizer重拟合或利用测试标签选checkpoint。
