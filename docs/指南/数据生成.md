# 数据生成

本指南描述通用顺序。每个正式任务仍以对应 config 和 experiment profile 为准。

## 开始前

1. 确认任务是 synthetic smoke、历史 p4m 还是当前 full-cell。
2. 检查输出路径、样本数、seed、结构族、材料参数、k 点、band 和 solver 设置。
3. 对 MPB/Meep 任务进入 WSL `Ubuntu` + `meep_env`。
4. 先运行 profile 指定的 solver/preflight；失败时停止。

## 生成并检查

数据命令入口从下面的帮助开始：

```bash
python -m phc2d.cli data --help
python -m phc2d.cli data generate --help
python -m phc2d.cli data inspect --help
```

正式生成后检查：

- 样本数和分片范围完整、无重叠；
- `sample_id` 唯一并可追溯到结构参数；
- split 冻结且 hash 可复核；
- 数据 shape 来自 metadata；
- k 点、band ordering、单位和 guard-band 策略明确；
- HDF5/NPZ 与 manifest 的 SHA-256 一致；
- 失败样本未被静默写成空数据。

## Full-cell 特别检查

解析结构是物理真值；32/64/128 栅格应从同一结构独立生成。核对 binary/graded material kind、结构族覆盖、材料分数、分辨率收敛与 real-MPB 回放。

## 发布条件

只有 finalizer 完成范围、hash、失败数和 schema 检查后，才把 incomplete 文件原子发布为正式数据。生成完成不等于模型训练或物理研究结论完成。

集群规模化执行见[超算物理任务](超算物理任务.md)。
