# 分级复现

复现开始前先确定等级。较低等级通过不能自动升级为较高等级。

## 选择等级

| 等级 | 最小输入 | 目标 | 允许表述 |
|---|---|---|---|
| R0 | 干净 Git 克隆、Python 3.10+ | 安装、help、版本和 registry | 接口检查通过 |
| R1 | `train` extra、合成配置 | 数据到训练产物的最小闭环 | 非物理 smoke 通过 |
| R2 | 数据、manifest、split、配置、可选 checkpoint | 重跑代理训练、评估或统计 | 对应 surrogate 协议结果 |
| R3 | WSL `Ubuntu`、`meep_env`、真实物理输入和 gate | 数据生成、replay 或跨环境复核 | 对应 real-MPB/Meep 证据 |

R0/R1 的命令见[快速上手](../开始/快速上手.md)。

## 准备 R2

正式代理实验开始前核对：

1. 数据文件 SHA-256 与 manifest；
2. train/validation/test split 和 sample lineage；
3. 配置、模型 identity、seed、precision 与设备；
4. 源 run 的 `run.meta.json`、`config.resolved.yaml` 和结果文件；
5. checkpoint 与 normalization identity。

公共仓库不包含完整 `.npz`/`.h5` 数据、checkpoint 或原始 runs。不要依据文件名或报告推断本地已经具备这些输入。

## 运行 R2

从相应研究 profile 和配置执行，而不是从日期报告复制临时命令。运行后至少检查标准产物、实际 seed 数、运行时间、失败案例和 test 使用边界。

| 任务 | 当前稳定入口 | 证据边界 |
|---|---|---|
| Full-Wh | `phc2d forward benchmark` | surrogate |
| Query | `phc2d query benchmark` | query surrogate |
| Inverse | `phc2d inverse benchmark` 的显式 stage | 候选、排序与 replay 分层 |
| Field/PINO | `phc2d forward train` 或 field profile | 修正度规与准入 gate |

## 准备并运行 R3

R3 只在 WSL `Ubuntu` + conda `meep_env` 或协议明确允许的原生集群环境中执行。原生集群生成仍需固定 WSL 跨环境 replay 才能获得项目正式验收。

必须记录 solver、geometry、k 点、band ordering、分辨率、环境、源结构、配置和逐例失败。R3 通过也只支持对应任务和数据范围。

## 复现完成清单

- [ ] 已明确 R0/R1/R2/R3。
- [ ] 已记录 commit、环境、配置和命令。
- [ ] 已核对数据、split、checkpoint 和 solver lineage。
- [ ] 只报告实际生成的产物和指标。
- [ ] 已区分 surrogate、field residual 与 real-MPB replay。
- [ ] 已写明不能得出的结论和剩余 gate。
- [ ] 已更新对应[结果索引](../results/README.md)，而不只在聊天中保留结论。
