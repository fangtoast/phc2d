# 训练与评估

本指南适用于 Forward、Query 和 Field 模型。正式比较必须在训练前冻结协议；测试集不参与 checkpoint 选择。

## 冻结实验身份

记录以下内容：

- 数据路径、SHA-256、schema、split 与 normalization；
- registry model name、architecture fingerprint 和参数；
- seed、precision、device、epoch、batch size、优化器与学习率；
- validation 选择指标和 test headline 指标；
- 预注册的交叉评估、消融和失败判据。

原始 baseline 与升级模型使用不同名称和 checkpoint，不覆盖历史身份。

## 运行

从对应命令帮助和 config 开始：

```bash
python -m phc2d.cli forward train --help
python -m phc2d.cli forward eval --help
python -m phc2d.cli query --help
```

运行目录必须符合 `runs/{yyyymmdd}/{experiment_id}_{YYYYMMDDHHmm}/`。中断续训时复用原 run 目录，并验证 checkpoint、配置和数据身份一致。

## 评估顺序

1. 在 validation 上选择 checkpoint。
2. 冻结 checkpoint 后只执行一次主要 held-out test。
3. 分别报告逐 band、结构族、cross-lane、分辨率与资源诊断。
4. 记录 wall time、train/eval time、单样本推理时间与 throughput。
5. 保留失败 seed、NaN、shape mismatch 和不适用项。

## 不要混用的结果

- final-fit monitor 与 held-out test；
- native test 与 cross-lane；
- 直接 32/128 输入与独立分辨率重训；
- surrogate error 与 real-MPB replay；
- field residual 与 frequency/field error。

结束后把精选结论写入对应日期报告并更新[证据索引](../results/README.md)。
