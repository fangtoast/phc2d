# 符号与单位

| 符号 | 含义 | 常用约定 |
| --- | --- | --- |
| $a$ | 晶格常数 | 长度基准 |
| $\mathbf{k}$ | Bloch 波矢 | 由 reciprocal basis 或路径坐标描述 |
| $f$ | 普通频率 | Hz；报告时必须说明是否无量纲化 |
| $\omega$ | 角频率 | $\omega=2\pi f$ |
| $\tilde f$ | 归一化频率 | 常用 $fa/c$ |
| $\varepsilon(\mathbf r)$ | 相对介电常数分布 | 无量纲 |
| $\mathbf E,\mathbf H$ | 电场、磁场本征模 | 归一化方式由数据 metadata 声明 |
| $N$ | 样本数 | 不含 batch 或 band 维 |
| $K$ | 每个条件的候选数 | 用于 best-of-k |

## 维度顺序

数组维度必须由数据 schema 指明。例如 `Wh[N, Q, B]` 中的 $Q$ 和 $B$ 只是查询点数与 band 数的角色名称，不能被文档或模型写成固定常量。场数据还应声明空间轴、复数表示和分量顺序。

## 误差单位

- 绝对误差保留目标本身的单位。
- 相对误差和 MRE 无量纲；以百分数显示时应明确乘以 $100\%$。
- 频率、带隙宽度和中心频率必须使用同一归一化约定再比较。
- wall time、train/eval/replay time 使用秒，单样本推理通常使用毫秒。
