# 核心代码导航

本页把稳定方法映射到当前公共实现。方法页只展示可解释的短片段；完整实现和所有边界条件仍以源码、配置和测试为准。

| 主题 | 核心实现 | 主要合同 |
|---|---|---|
| 数据表示 | [`data/representations.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/data/representations.py)、[`data/target_specs.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/data/target_specs.py) | `DataRepresentationSpec`、`TargetSpec` |
| full-cell 结构与 HDF5 | [`data/full_cell.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/data/full_cell.py) | `FullCellStructureSpec`、`FullCellDatasetBundle` |
| MPB/Meep | [`solvers/full_cell.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/solvers/full_cell.py)、[`solvers/meep_scattering.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/solvers/meep_scattering.py) | 解析介质 callback、本征频带、有限阵列散射 |
| 模型 registry | [`models/registry.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/models/registry.py) | 模型身份、factory、输入输出能力 |
| Forward/Query | [`forward/runner.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/forward/runner.py)、[`query/runner.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/query/runner.py) | 数据加载、损失、checkpoint、held-out 评估 |
| Field/PINO | [`forward/field_eigen_v2.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/forward/field_eigen_v2.py)、[`physics/torch_eigen_residual.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/physics/torch_eigen_residual.py) | 相位不变损失、TE residual、Rayleigh 项 |
| full-cell inverse | [`inverse/full_cell_codec.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/inverse/full_cell_codec.py)、[`inverse/full_cell_training.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/inverse/full_cell_training.py) | 解析参数 codec 与 Stage-A |
| V2 inverse/replay | [`inverse/runner.py`](https://github.com/fangtoast/phc2d/blob/main/src/phc2d/inverse/runner.py) | 候选生成、筛选、rerank 与 replay |

源码中的默认 shape 只用于构造默认配置；运行时 shape 必须服从数据 metadata 和解析配置。模型身份与结果状态见[模型目录](模型目录.md)，文档字段见[文档元数据](文档元数据.md)。
