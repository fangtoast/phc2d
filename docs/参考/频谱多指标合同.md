# 频谱多指标合同

`phc2d.spectral_regression.v1` 对反标准化后的 `[N,K,B]` 预测与真值计算误差。结构、离散 k 点和组内 band 等权；维度来自输入，不假定固定网格或能带数。适用实验见 [EXP-FWD-031 补充评价协议](https://github.com/fangtoast/phc2d/blob/master/experiments/research/EXP-FWD-031-多指标补充评价.md)，当前结果见[多指标补充评价](../results/forward/EXP-FWD-031-多指标补充评价.md)。

## 指标和单位

记 $d_i=\hat Y_i-Y_i$，每个结构包含 $K\times B$ 个频率。

| 字段 | 定义与聚合 |
|---|---|
| `mre_pct` | $100\operatorname{mean}_{i,k,b}(|d_{ikb}|/\max(|Y_{ikb}|,10^{-8}))$ |
| `relative_l2_mean_pct` | $100\operatorname{mean}_i(\|d_i\|_F/\|Y_i\|_F)$ |
| `relative_l2_median_pct` / `relative_l2_p95_pct` | 逐结构相对 L² 百分数的中位数 / 线性插值 95% 分位数 |
| `relative_l2_global_pct` | $100\sqrt{\sum_i\|d_i\|_F^2/\sum_i\|Y_i\|_F^2}$，与逐结构平均分开命名 |
| `mae` | $\operatorname{mean}_{i,k,b}|d_{ikb}|$ |
| `mse` | $\operatorname{mean}_{i,k,b}d_{ikb}^2$ |
| `rmse_global` | $\sqrt{\mathrm{mse}}$ |
| `rmse_sample_mean` | 逐结构 RMSE 的均值，仅用于诊断历史口径差异 |
| `r2_variance_weighted` | 在结构维度对每个 k/b 坐标中心化后计算的方差加权 R²；零方差坐标显式排除并计数 |
| `band_order_violation_rate` | 先计算每个结构出现任意相邻 band 倒序的 k 点比例，再对结构平均；单 band 标记不适用 |

MAE/RMSE 使用标签中的频率单位，MSE 使用平方单位；不与 train-only 标准化坐标下的 `normalized_mse` 合并。离散矩阵 L² 不代表连续布里渊区积分，也不代表电磁场误差。

真值 Frobenius 范数不超过 $10^{-12}$ 时，相对 L² 标为未定义。总体输出 `null`、逐样本输出 NaN 并记录计数；补算工作流暂停该单元验收，不静默丢弃。NaN/Inf、空数组、形状不匹配直接拒绝。

## 接口与来源

纯数组接口为 `phc2d.forward.full_cell_metrics.compute_spectral_regression_metrics(prediction, target, *, band_groups=None, norm_tolerance=1e-12)`，返回总体字典、分组逐样本数组、逐 band 记录。默认组为 `all_bands`、`band1` 和多 band 时的 `bands2_last`。旧 `compute_band_metrics` 的字段和 reduction 不变。

文件工作流使用 JSON manifest 的 `cells` 列表。每项必需字段如下：

| 类型 | 字段 |
|---|---|
| 唯一身份 | `cell_id`, `model`, `source_domain`, `target_domain`, `seed`, `comparison_role` |
| 来源 | `checkpoint_sha256`, `dataset_sha256`, `split_sha256`, `k_points_sha256`, `sample_count`, `expected_mre_pct` |
| 数组 | `prediction_path`, `target_path`, `indices_path`；或 `archive_path` 含 `prediction`/`target` 加独立 `indices_path`；或 `h5_path` 含 `prediction`/`label`/`dataset_index` |
| 文件校验 | `files_sha256`：所有数组完整路径到 SHA256 的映射 |
| 阻塞 | 缺失单元保留身份并设置 `blocked_reason`，不制造数组或指标 |

样本索引必须唯一、非负、整数，数量匹配，且按保存顺序计算的字节 SHA 与冻结 split SHA 相同。旧 NPZ 未保存样本索引时，必须从原冻结 split 和评估程序恢复顺序；不能直接假定 `arange(N)`。

```bash
python -m phc2d.forward.spectral_metric_evaluation --manifest manifest.json --output new_run
python -m phc2d.forward.frozen_spectral_replay --manifest replay_manifest.json --output new_replay
python -m phc2d.forward.spectral_metric_aggregation --manifest full_manifest.json --run n40_result --run n56_result --run replay_result --output merged_result
python -m phc2d.plot.spectral_metrics --run new_run --output new_run/figures
```

补算只创建新目录，拒绝覆盖。复算 MRE 与原值的绝对差必须不超过 $10^{-5}$ 个百分点。重推理接口先完成 manifest 指定数量的原域单元并逐项通过同一回归门，才开始跨域和新几何；失败记录在 `failure.json`，不自动重试。远端运行遵循 `AGENTS.md` 的授权要求。

## 汇总与验收

每个 seed 先独立算指标，再对 seed 0/1/2 汇总均值和样本标准差 `ddof=1`。P95 不混池。原域、跨域、新几何和混合来源独立测试分组展示；四域宏平均要求四域齐备并等权，不能把已算子集平均标为四域平均。

标准输出是 `cell_audit.csv`、`cell_metrics.csv`、`per_band_metrics.csv`、`three_seed_summary.csv`、等权比较表 `comparison_summary.csv`、逐 cell 的 `metrics.json` 和压缩逐样本 CSV，以及含 manifest/指标源码 SHA 的 `aggregation_audit.json`。全清单中的 blocked 项继续计入分母；仅当全部输入通过且所有预期三 seed 组完整时，状态才为 `complete`。

参考定义：[NeuralOperator 相对范数实现](https://neuraloperator.github.io/dev/_modules/neuralop/losses/data_losses.html)、[MSE 官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.mean_squared_error.html)。所称“爱森”论文尚未确定，当前合同不声称与该文完全对齐。
