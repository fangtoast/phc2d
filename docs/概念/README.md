这一节解释项目研究什么、不同任务怎样连接，以及什么证据可以支持什么结论。它不提供逐条执行命令。

- [研究主线与证据等级](研究主线与证据等级.md)：理解闭环和最重要的声明边界。
- [光子晶体任务](光子晶体任务.md)：区分 Full-Wh、Query、Field、Inverse 与 Replay。
- [数据与表征](数据与表征.md)：理解解析结构、栅格、能带矩阵、查询样本与本征场记录。

准备运行任务时转到[操作指南](../指南/README.md)；需要公式、schema 或模型 identity 时转到[参考手册](../参考/README.md)。
