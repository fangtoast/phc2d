# 光子晶体任务

项目不是单一的 `rho_wedge → Wh` 回归。不同任务共享结构与物理背景，但训练样本、输出形状、指标和验证门不同。

## Full-Wh

给定一个结构表示，一次预测固定 k 点集合和固定 band 集合上的完整频率矩阵。当前全胞主任务使用 `material_weight_grid_64 → Wh[81,10]`；历史 p4m 任务使用不同的结构表示和 k 路径，不能混作同一数据协议。

Full-Wh 适合批量评估和逆向候选排序，但其 test MRE 仍是 surrogate 指标。

## Continuous Query

给定结构与一个具体查询 `(band, k)`，预测该查询的频率或 band vector。Query 更直接表达“对任意条件求响应”的神经算子思想，但必须冻结 query 采样、physical-k metadata 和结构 split，避免同结构泄漏。

## Field / adapted PINO

给定结构、k 点和 band，预测 TE Bloch 本征场及频率。数据包含复数场的实通道表示、公共相位规范和介电加权度规。adapted PINO 在场 FNO 上增加 TE Bloch residual 约束；它不是独立的 faithful PINO 复现。

## Generative inverse design

给定目标能带，生成多个候选结构。一个目标对应多个可行结构，因此逆向任务需要候选多样性、合法性、去重、代理排序和真实求解器复核，而不是只比较一个结构向量的像素误差。

## Replay

Replay 使用 real-MPB 重新求解候选结构，并计算目标频带或完整谱的真实误差。它是逆向物理结论的最终裁决层，但其结论仍受候选集合、求解器设置和目标范围限制。

## 任务之间怎样连接

| 上游 | 下游用途 | 必须保留的边界 |
|---|---|---|
| Full-Wh / Query | 快速筛选 inverse 候选 | checkpoint、数据版本和 cross-surrogate gap |
| Field/PINO | 物理场诊断或条件分支研究 | frequency、dense-k、跨分辨率与 residual 校准 |
| Inverse generator | 提供候选池 | seed、K、去重、多样性和结构合法性 |
| Replay | 真实求解器复核 | solver provenance、逐例失败和 aggregate 口径 |

对应实现与模型入口见[模型目录](../参考/模型目录.md)。
