# 数据与表征

相同的“结构”可以表现为解析参数、材料权重、介电常数栅格或模型 tensor。比较两个结果前，必须先对齐数据身份、结构划分、k 点、band、单位和 normalization；文件名相似不代表合同相同。

## 1. 问题与输入输出

数据层承担两项转换：把可回放结构变成求解器输入，并把求解器输出变成不同学习任务的目标。

```text
结构身份 ──> 解析几何 ──> MPB/Meep ──> 物理标签
   │                                      │
   └──> 学习栅格 / 参数向量 ──────────────┘
                         │
                         ├── Full-Wh
                         ├── Query
                         ├── Field
                         └── inverse condition
```

| 任务 | 输入角色 | 输出角色 |
|---|---|---|
| Full-Wh | 一个结构表示 | 完整 `Wh[N_k,N_b]` |
| Query | 结构与一个 physical-k 条件 | 该 k 点的 band vector |
| Field | 结构网格、k 点、band | 三个复场分量与频率 |
| inverse | 目标谱、latent、可选参考结构 | 一个或多个结构候选 |

## 2. 两代数据合同

### V2 10k

V2 数据由 `rho_wedge` 经 p4m/D4 对称展开得到完整结构，再生成 `epsilon_grid` 和 MPB 标签。正式 V2 结果固定到 10k 数据身份，目标为 `Wh[10000,31,10]`。这里的 31 和 10 是该数据集的 metadata，不是模型常量。

### 新全胞数据

全胞数据先冻结 `FullCellStructureSpec`。real-MPB 通过材料回调直接查询解析结构；`material_weight_grid_32/64/128` 是从同一结构独立采样的学习视图。

```text
FullCellStructureSpec
  ├── analytic periodic material callback ──> real-MPB Wh
  └── rasterize(32/64/128) ──────────────────> model input / audit view
```

正式全胞结果的谱目标是 `Wh[N,81,10]`：81 来自无边界重复的 $9\times9$ 全 BZ 网格。MPB resolution 与模型输入 grid resolution 是两个独立变量。

## 3. 公式与符号

材料权重 $u(\mathbf r)\in[0,1]$ 到介电常数的映射为

$$
\varepsilon(\mathbf r)=\varepsilon_{\mathrm{air}}+
\left(\varepsilon_{\mathrm{material}}-\varepsilon_{\mathrm{air}}\right)u(\mathbf r).
$$

Full-Wh 数据可抽象为

$$
\mathcal D_{\mathrm{Wh}}
=\{(x_i,Y_i)\}_{i=1}^{N},\qquad
Y_i\in\mathbb R^{N_k\times N_b}.
$$

Query 数据在结构划分冻结后展开：

$$
\mathcal D_{\mathrm{query}}
=\{(x_i,\mathbf k_q,\mathbf y_{iq})},\qquad
\mathbf y_{iq}\in\mathbb R^{N_b}.
$$

因此同一结构的不同 query 不得分别落入 train 与 test。

## 4. 实际 tensor shape

| 数据/任务 | 代表性 shape | 说明 |
|---|---|---|
| V2 Full-Wh 正式数据 | `Wh[10000,31,10]` | Γ–X–M–Γ 路径，10 bands |
| 全胞 Full-Wh | `grid[N,H,W]`, `k_points[81,2]`, `Wh[N,81,10]` | `H,W` 由选择的 32/64/128 视图决定 |
| Query materialized split | `structure[N_s×N_k,...]`, `k_coordinate[N_s×N_k,2]`, `target[N_s×N_k,N_b]` | 先按 structure split，再展开 k |
| Field 历史合同 | `grid[B,5,H,W]`, `context[B,3]`, `field[B,6,H_f,W_f]` | 6 个实通道编码 3 个复场分量 |
| inverse candidate pool | `candidates[B,K,...]` | `...` 由参数 codec 或栅格合同给出 |

`B` 是 batch size，`N` 是样本数，不能混用。任何 reshape 都应从 dataset schema 或模型输出合同推导。

## 5. 核心源码

下面是数据合同的实际实现节选，核对版本为 `c347845`。完整源码见 [`data/representations.py`](https://github.com/fangtoast/phc2d/blob/c347845/src/phc2d/data/representations.py) 与 [`data/target_specs.py`](https://github.com/fangtoast/phc2d/blob/c347845/src/phc2d/data/target_specs.py)。

```python
@dataclass(frozen=True)
class DataRepresentationSpec:
    """Input/output contract used by data conversion, models, and metrics."""

    input_repr: InputRepresentation
    output_target: OutputTarget
    grid_shape: tuple[int, int] | None = None
    k_points: int | None = None
    n_bands: int | None = None
    polarization: str | None = None
    field_components: tuple[str, ...] = ()
    source_repr: str | None = None
    normalization: dict[str, Any] = field(default_factory=dict)


@dataclass(frozen=True)
class TargetSpec:
    output_target: OutputTarget
    shape: tuple[int, ...] | None = None
    k_points: int | None = None
    n_bands: int | None = None
    units: str | None = None
```

这段代码的关键不是 dataclass 本身，而是 shape、极化和 normalization 都与数据同行，模型不需要猜测固定尺寸。

## 6. 配置与最小检查

最小 smoke 明确标记为合成、非物理数据：

```yaml
dataset:
  path: data/generated/phc2d_synthetic_smoke.npz
  input_repr: rho_wedge
  output_target: Wh
  smoke: true
```

```powershell
python -m phc2d.cli data make-smoke --config configs/smoke/synthetic_dataset.yaml
python -m phc2d.cli data inspect --path data/generated/phc2d_synthetic_smoke.npz
```

真实全胞生成必须在 WSL `Ubuntu` + conda `meep_env` 使用研究配置；执行前先读[数据生成指南](../指南/数据生成.md)。

## 7. 产物、身份与证据边界

可复现实验至少保留：

- `sample_id`、结构 lineage、generator family 与 material kind；
- train/validation/test 索引或 hash；
- k 点坐标、band ordering、极化和频率单位；
- 数据、配置、代码 revision 与 solver provenance；
- field bootstrap 的 `source_sample_id`；
- HDF5/NPZ hash 和标准 run 产物。

学习栅格可以证明模型看到了什么，不能自动证明 MPB 求解了同一个离散栅格；合成 smoke 可以证明接口连通，不能支持科学结论；旧 V2 与新全胞数据上的指标也不能跨合同直接比较。精确字段见[数据模式与运行产物](../参考/数据模式与运行产物.md)。
