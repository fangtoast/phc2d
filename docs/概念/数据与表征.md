# 数据与表征

相同的“结构”可以有解析参数、占据量、介电常数栅格或神经网络输入等多种表示。文档和实验必须说明当前使用的是哪一层，不能把学习栅格当作求解器几何真值。

## 当前全胞合同

每个样本先冻结一个可序列化的解析周期结构。real-MPB 通过材料函数在查询位置计算介电常数；`material_weight_grid_32/64/128` 是从同一解析结构独立重采样的学习和审计视图。

```text
FullCellStructureSpec
  -> analytic periodic material function
  -> real-MPB Wh label
  -> synchronized 32 / 64 / 128 raster views
```

因此，网络输入分辨率实验与 MPB 求解器分辨率实验是两件事。

## 历史 p4m 合同

历史数据从 `rho_wedge` 通过 p4m/D4 对称展开得到完整结构，再映射到 `epsilon_grid`。这些数据继续支撑 A1/A2 和 Field/PINO 历史证据，但不能替代全胞、多形态、全 BZ 数据上的重新验证。

## 目标表示

| 任务 | 典型输入 | 典型目标 |
|---|---|---|
| Full-Wh | `rho_wedge` 或 `material_weight_grid` | `Wh[N_k,N_b]` |
| Query | 结构、`k`、band 条件 | 单频率或 band vector |
| Field | 结构、`k`、band | 复数 E/H 场与频率 |
| Inverse | 目标频带或完整谱 | 结构参数或候选栅格 |

形状必须来自数据 metadata、schema、`DataRepresentationSpec`、`TargetSpec` 或配置，不能在模型和指标中假设固定 `16×16`、31 个 k 点或 10 条 band。

## 身份与划分

可复现实验至少保留：

- `sample_id` 与结构 lineage；
- train/validation/test 索引或 hash；
- generator family 与 material kind；
- k 点、band ordering 和单位；
- 数据、配置与求解器 provenance；
- 用于 field bootstrap 时的 `source_sample_id`。

精确字段和标准运行产物见[数据模式与运行产物](../参考/数据模式与运行产物.md)，生成流程见[数据生成指南](../指南/数据生成.md)。
