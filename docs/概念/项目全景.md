# 项目全景与研究闭环

`phc2d` 研究如何用神经代理降低二维光子晶体频带与场计算的重复成本，并让逆向生成的结构最终回到真实 MPB/Meep 求解器接受裁决。本页解释稳定的系统关系，不维护易漂移的排行榜数字。

## 研究闭环

```mermaid
flowchart LR
    S["解析结构或栅格"] --> P["MPB/Meep 物理求解"]
    P --> D["带 provenance 的数据集"]
    D --> F["Full-Wh / Query / Field 代理"]
    F --> G["条件生成多个候选"]
    G --> C["合法性、多样性与代理排序"]
    C --> R["real-MPB replay"]
    R --> E["结果、失败与下一 gate"]
```

代理模型负责加速筛选，真实求解器负责最终物理判定。低 surrogate MRE、低 PDE residual 或高候选多样性都不能单独替代 replay。

## 两代主要数据合同

| 数据家族 | 结构与采样 | 目标 | 当前角色 |
|---|---|---|---|
| V2 10k | p4m wedge、Γ–X–M–Γ 路径 | `Wh[10000,31,10]` | 公平基线和已完成 inverse replay |
| full-cell B/G | binary/graded 全胞、$9\times9$ 全 BZ | `Wh[N,81,10]` | 当前数据、正向升级与后续 full-cell inverse 底座 |

shape 是数据身份的一部分，不是全项目常量。模型和指标必须从 metadata、schema 或配置读取维度。

## 四类学习任务

- **Full-Wh：** 一次预测完整 `Wh[N_k,N_b]`。
- **Query：** 给定结构与 `(band,k)`，预测局部频率或 band 向量。
- **Field/PINO：** 预测 TE Bloch 本征场与频率，并计算数据项和物理残差。
- **Inverse：** 根据目标频带生成多个结构，经筛选后交给 real-MPB replay。

## 证据如何升级

```text
implemented
  → smoke-tested
  → surrogate held-out
  → candidate preflight
  → solver replay / physical validation
  → human acceptance
```

每一级只回答自己的问题。当前正式结果只收录[V2 10k](../results/V2-10k正式结果.md)和[新全胞数据](../results/全胞数据正式结果.md)；其他记录保留在[历史档案](../历史档案.md)。
