# 正向与查询代理

Forward 与 Query 都近似结构到光子能带的映射，但它们的输出合同不同。比较时必须固定数据 lineage、结构 split、目标 band、physical-k metadata、训练预算和 checkpoint 选择。

## Full-Wh

Full-Wh 一次输出整个 `Wh[N_k,N_b]`。项目中的模型族包括：

- `mlp` 与 ResMLP：固定拓扑的向量回归参照；
- `lifted_cnn`：局部卷积能力下界；
- `fno2d_band_v2`：band-aware 频谱强基线；
- Mixer、Gated ResMLP、ConvNeXt、TFNO 与 dual-lane operator：全胞任务的独立升级模型。

升级模型使用独立 registry name 和 checkpoint identity，不覆盖原始 baseline。

## Continuous Query

Query 模型接收结构与 `(band,k)` 条件。当前族包括低复杂度 `mlp_query`、Branch/Trunk 风格的 `deep_onet_query_v2` 和频谱结构编码的 `fno2d_query_v2`。

Query 训练不能把同一结构的不同 query 随机分散到 train/test；结构身份必须先冻结，再在划分内部展开查询。

## 训练与选择

训练损失、checkpoint 选择和 headline 指标是不同职责：

- loss 驱动参数更新；
- validation 选择 checkpoint；
- test 只用于冻结后的最终评估；
- 逐 band、cross-lane、跨分辨率和 threshold proxy 属于诊断或附加 gate。

不能用 final-fit 的训练重叠评估替代 held-out test，也不能把输入分辨率稳定性写成 MPB 求解器收敛。

## 在逆向设计中的角色

Forward 或 Query checkpoint 可以对候选进行快速排序。它们仍可能产生 surrogate exploitation，因此应记录：

- checkpoint、数据版本与 normalization；
- 候选池、K 和 Top-M；
- 主代理与交叉代理分歧；
- `best_of_k_surrogate_mre` 与 `best_of_k_replay_mre`；
- `surrogate_replay_gap`。
