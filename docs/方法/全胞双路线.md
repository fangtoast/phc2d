# 全胞双路线

全胞双路线取消历史 p4m 楔形表示对几何的强约束，又避免把一个固定像素图误当作求解器几何真值。每个样本都有可序列化、可重新求值的解析结构；binary 与 graded 是两种分布，不是逐样本配对。

## 1. 问题与输入输出

输入是一份 `FullCellStructureSpec` 与 k 点集合；输出包括 real-MPB 能带、同源的 32/64/128 材料权重栅格、结构 identity 和求解器 provenance。

```text
seed + generator config
          │
          ▼
FullCellStructureSpec
   ├── epsilon_at(x,y) ──> MPB material callback ──> Wh[N_k,N_b]
   └── rasterize(H,W) ─────────────────────────────> model grid
```

两条路线共享数据 schema、全 BZ k 网格和验收门，但分别冻结结构分布、split 和 normalization。

## 2. 结构与求解公式

$$
\varepsilon(x,y)=\varepsilon_{\mathrm{air}}+
\left(\varepsilon_{\mathrm{material}}-\varepsilon_{\mathrm{air}}\right)u(x,y),
$$

其中 $u(x,y)$ 对晶格周期延拓。Binary 路线使 $u\in\{0,1\}$；graded 路线保留 $u\in[0,1]$。给定 Bloch 波矢 $\mathbf k$，MPB 求解

$$
\mathcal L_{\varepsilon,\mathbf k}u_{n\mathbf k}
=\left(\frac{\omega_{n\mathbf k}}{c}\right)^2u_{n\mathbf k}.
$$

求解器可多算 guard bands，再按配置声明的 ordering 截取目标 bands；不能假定输出天然与学习目标顺序一致。

## 3. 两条结构分布

| 路线 | 主要结构族 | 材料语义 | 研究作用 |
|---|---|---|---|
| Binary | 周期极坐标空气孔、Fourier threshold | 空气/材料二值分布 | 离散拓扑与边界变化 |
| Graded | RBF、Fourier 与 logistic 组合 | 连续 graded medium | 连续材料权重与平滑结构 |

模型可以联合训练两条路线，也可以分别训练；无论哪种方式，native-lane 与 cross-lane 指标必须分开解释。

## 4. 实际 tensor shape

| 对象 | shape | 语义 |
|---|---|---|
| `k_points` | `[81,2]` | centered、无边界重复的 $9\times9$ 第一 BZ 网格 |
| `Wh` | `[N,81,10]` | 每个结构的 10 条目标 band |
| `material_weight_grid_32` | `[N,32,32]` | 低分辨率学习/审计视图 |
| `material_weight_grid_64` | `[N,64,64]` | 主训练常用视图 |
| `material_weight_grid_128` | `[N,128,128]` | 跨分辨率诊断视图 |
| `parameter_vector` / `parameter_mask` | `[N,P]` | 解析参数与有效位；`P` 由结构变体决定 |

81 和 10 是当前全胞数据合同；实现仍从 schema 读取，不把它们写死进模型或指标。

## 5. 核心源码

`FullCellStructureSpec` 同时提供可哈希身份、解析求值和多分辨率 raster。以下节选核对版本为 `c347845`，完整实现见 [`data/full_cell.py`](https://github.com/fangtoast/phc2d/blob/c347845/src/phc2d/data/full_cell.py)。

```python
@dataclass(frozen=True)
class FullCellStructureSpec:
    sample_id: str
    generator_family: str
    material_kind: str
    parameters: dict[str, Any]
    parameter_names: tuple[str, ...]
    parameter_vector: tuple[float, ...]
    parameter_mask: tuple[bool, ...]
    epsilon_air: float = 1.0
    epsilon_material: float = 8.9

    def evaluate_material_weight(self, x: Any, y: Any) -> np.ndarray:
        if self.generator_family == "graded_rbf_fourier":
            weight = _graded_weight(np.asarray(x), np.asarray(y), self.parameters)
        elif self.generator_family == "binary_polar_holes":
            weight = _binary_polar_weight(np.asarray(x), np.asarray(y), self.parameters)
        else:
            weight = _binary_spectral_weight(np.asarray(x), np.asarray(y), self.parameters)
        return np.clip(np.asarray(weight, dtype=np.float64), 0.0, 1.0)

    def rasterize(self, grid_shape: Sequence[int]) -> np.ndarray:
        x, y = _grid_coordinates(grid_shape)
        return self.evaluate_material_weight(x, y).astype(np.float32)
```

MPB 不读取上述 raster，而是惰性查询解析结构：

```python
def build_full_cell_material_function(mp: Any, structure: FullCellStructureSpec):
    """Build a lazy MPB material function from a serializable structure spec."""

    def material(position: Any):
        epsilon = structure.epsilon_at(float(position.x), float(position.y))
        return mp.Medium(epsilon=float(epsilon))

    return material
```

## 6. 配置与最小命令

研究配置分别声明 generator、solver、k-grid、输出栅格与 provenance。真实生成示例：

```powershell
python -m phc2d.cli data generate --config configs/research/full_cell_graded_bz9_pilot64.yaml
python -m phc2d.cli data generate --config configs/research/full_cell_binary_holes_bz9_pilot64.yaml
python -m phc2d.cli data converge --config configs/research/full_cell_resolution_convergence_v1.yaml
```

这些命令须在 WSL `Ubuntu` + conda `meep_env` 中执行。`--max-samples` 只适合链路检查，不能替代完整数据验收。

## 7. 产物与证据边界

标准数据 run 应保留 `sample_plan.jsonl`、结构 spec、HDF5、manifest、hash、失败 shard、`run.meta.json`、`config.resolved.yaml`、`metrics.json` 与 `results.json`。跨机器生成还需通过固定结构的 WSL replay 接受测试。

本方法能够证明“同一解析结构可生成可追溯的学习视图与 real-MPB 标签”。它不能单独证明模型精度、inverse 可行、MPB 分辨率收敛或 Meep 有限阵列响应；这些结论分别由训练、replay、convergence 与 scattering 页面承担。

具体字段见[数据模式与运行产物](../参考/数据模式与运行产物.md)，已验收数据见[全胞数据构建与验收](../results/data-provenance/full_cell_dual_lane_pilot_20260803.md)。
