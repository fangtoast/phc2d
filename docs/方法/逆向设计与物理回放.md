# 逆向设计与物理回放

光子晶体逆问题通常是一对多映射。同一目标谱可以对应多个结构，所以项目优化的是“为给定目标产生健康候选，并由真实求解器验证”，而不是复原唯一真值像素图。

## 1. 问题与闭环

设目标谱为 $y^\star$，条件生成器产生

$$
\rho_j=G_\theta(y^\star,z_j),\qquad j=1,\ldots,K.
$$

冻结代理 $S$ 给出候选误差，选出的 Top-M 再交给物理求解器 $P$：

```text
target + latent seeds
        │
        ▼
candidate generator ──> legality / diversity / collision checks
        │
        ▼
frozen surrogate ranker + cross-surrogate diagnosis
        │ Top-M
        ▼
real-MPB replay ──> replay error + per-case failures
```

## 2. 两代候选表示

V2 p4m 路线包括 train-only retrieval、direct inverse、single-mode 和 mixture conditional generator。mixture 表示多个条件 mode，不应称为 cVAE 或 diffusion。

Full-cell Stage-A 则预测五类解析结构变体的有效参数。每个 `FullCellAnalyticCodec` 负责：

- 对训练 split 统计参数位置、尺度和上下界；
- 对周期/角度参数使用 sin/cos 编码；
- hard decode 为可回放 `FullCellStructureSpec`；
- soft decode 为可微 raster，供训练损失使用。

不同变体的 encoded width 可以不同，不能用一个无语义 padded vector 直接解释全部结构。

## 3. 目标函数与候选健康

代理侧目标可写为

$$
\mathcal L_{mathrm{inv}}=
\lambda_s\mathcal L_{\mathrm{surrogate}}
+\lambda_x\mathcal L_{\mathrm{cross}}
+\lambda_g\mathcal L_{\mathrm{gap}}
+\lambda_d\mathcal L_{\mathrm{diversity}}
+\lambda_c\mathcal L_{\mathrm{collision}}
+\lambda_r\mathcal L_{\mathrm{regularization}}.
$$

候选健康必须单独报告：

- 参数范围、解析结构合法性和材料语义；
- exact duplicate 与 near-neighbor collision；
- 最近邻 Hamming/连续距离和有效 K；
- 结构族覆盖、fill fraction、二值性与 total variation；
- latent response 与候选间多样性；
- Top-M 是否覆盖多个独立候选。

低 surrogate error 不能补偿候选池坍缩。

## 4. best-of-k 与 replay

代理 best-of-k 为

$$
e_S^\star=\min_{1\le j\le K}d(S(\rho_j),y^\star).
$$

真实求解器回放后计算

$$
e_P^\star=\min_{j\in\mathrm{replayed}}d(P(\rho_j),y^\star),
\qquad
\Delta_{S\to P}=e_P^\star-e_S^\star.
$$

报告字段分别使用 `best_of_k_surrogate_mre`、`best_of_k_replay_mre` 与 `surrogate_replay_gap`。只有 $P$ 的结果能支持候选在指定 MPB 协议下满足目标。

## 5. 实际 tensor shape

| 阶段 | 代表性 shape | 说明 |
|---|---|---|
| V2 target | `[B,31,10]` 或展平后 `[B,310]` | 正式 V2 10k 数据合同 |
| V2 candidate grid | `[B,K,H,W]` | p4m 候选；`H,W` 来自 geometry metadata |
| full-cell target | `[B,81,10]`，条件宽度 810 | 当前全胞谱合同 |
| full-cell encoded output | `[B,K,P_v]` | `P_v` 由结构 variant codec 决定 |
| soft raster | `[B,K,H,W]` | 用于 raster/代理目标；不是 hard analytic replay 几何 |
| replay result | `[B,M,N_k,N_b]` | `M≤K`，只包含实际回放候选 |

## 6. 核心源码

以下节选展示 inverse 目标如何把代理误差、交叉代理与多样性分开组合。核对版本为 `c347845`，完整实现见 [`inverse/objective.py`](https://github.com/fangtoast/phc2d/blob/c347845/src/phc2d/inverse/objective.py)。

```python
surrogate_loss = band_relative_error_loss(
    predictions,
    target,
    torch=torch,
    n_bands=n_bands,
    band_start_one_based=band_start,
)
total = surrogate_weight * surrogate_loss

cross_loss = candidates.new_tensor(0.0)
if secondary_predictions is not None and cross_weight:
    cross_loss = cross_surrogate_consistency_loss(
        predictions if secondary_primary_predictions is None
        else secondary_primary_predictions,
        secondary_predictions,
        torch=torch,
        n_bands=n_bands,
        band_start_one_based=band_start,
    )
    total = total + cross_weight * cross_loss

diversity_loss = candidates.new_tensor(0.0)
if diversity_weight:
    diversity_loss, diversity_value = candidate_diversity_loss(
        candidates,
        torch=torch,
        target_diversity=_as_float(
            objective.get("target_diversity_hamming"), 0.035
        ),
        group_size=group_size,
    )
    total = total + diversity_weight * diversity_loss
```

Full-cell 的 hard/soft 参数转换见 [`inverse/full_cell_codec.py`](https://github.com/fangtoast/phc2d/blob/c347845/src/phc2d/inverse/full_cell_codec.py)；replay runner 见 [`inverse/runner.py`](https://github.com/fangtoast/phc2d/blob/c347845/src/phc2d/inverse/runner.py)。

## 7. 配置、命令与产物

A2 公平协议把候选数、replay 数、split 和禁止主张写入配置：

```yaml
protocol:
  seeds: [0]
  requested_k: 128
  replay_top_m: 5
  selection_split: val
  final_evaluation_split: test
  prohibit_claims:
    - cross_seed_stability
    - universal_significant_superiority
```

```powershell
python -m phc2d.cli inverse benchmark --config configs/research/a2_inverse_single_seed_v1.yaml --stage preflight
python -m phc2d.cli inverse benchmark --config configs/research/a2_inverse_single_seed_v1.yaml --stage replay --run-dir <run_dir>
python -m phc2d.cli inverse benchmark --config configs/research/a2_inverse_single_seed_v1.yaml --stage aggregate --run-dir <run_dir>
```

run 必须保留 target manifest、candidate manifest、checkpoint hash、每个候选的 identity/score、replay shard、失败记录、aggregate statistics 与全部 runtime。执行过程见[逆向候选与回放](../指南/逆向候选与回放.md)。

单 seed、100-target pilot 或 surrogate-only objective 不能证明跨 seed 稳定性和普遍优越；full-cell codec/Stage-A smoke 也不能证明候选排序与 replay 已完成。正式 V2 证据见[V2 10k 结果](../results/V2-10k正式结果.md)，full-cell inverse 当前状态见[计划与治理](../planning/全胞逆向索引.md)。
