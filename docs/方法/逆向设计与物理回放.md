# 逆向设计与物理回放

光子晶体逆问题通常是一对多映射。同一目标能带可能对应多个结构，因此项目以“候选池—筛选—回放”为基本单元，而不是要求生成器复原唯一真值结构。

## 候选生成

历史 p4m 路线包含 direct inverse、single-mode 和 mixture conditional generator。当前 full-cell Stage A 输出五类解析结构变体的参数，由各自 codec 完成 hard decode 或 soft raster；它们不是一个统一 padded vector 的无差别输出。

生成阶段需要记录目标、seed、latent、候选序号、结构变体和 checkpoint identity。

## 候选健康

进入排序前至少检查：

- 参数范围和结构合法性；
- 二值化或连续材料语义；
- 精确重复与近邻碰撞；
- 最近邻 Hamming 或连续距离；
- 结构族覆盖与候选有效率；
- K、去重后的有效 K 和 Top-M 覆盖。

高 surrogate 精度不能补偿候选池坍缩。

## 代理排序

冻结的 Forward 或 Query checkpoint 对候选进行批量打分。主代理用于选择，交叉代理用于检查模型间投机和不一致。排序策略、目标 band、normalization 与 checkpoint 必须写入候选 manifest。

## real-MPB replay

Top-M 候选由 real-MPB 重新求解。报告分别给出 surrogate 和 replay 指标，并保留逐例失败：

$$
\text{surrogate-replay gap}
=\text{replay error}-\text{surrogate error}.
$$

只有 replay 可以支持指定候选在指定求解协议下满足物理目标。单 seed、小目标集或 pilot 仍不能证明跨 seed 稳定性或普遍优越。
