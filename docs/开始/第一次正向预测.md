# 第一次正向预测

本教程使用确定性合成数据完成“配置 → 数据 → 模型 → 训练 → 运行产物”的最小闭环。它只验证接口和数据流，不产生真实光子晶体结论。

## 前置条件

先完成[安装与环境](安装与环境.md)，并确认 `python -m phc2d.cli --help` 可运行。

## 生成 smoke 数据

```bash
python -m phc2d.cli data make-smoke --config configs/smoke/synthetic_dataset.yaml
```

该配置生成小型合成数组，用来验证 schema、shape 解析和运行目录。它不调用 MPB。

## 训练最小正向模型

```bash
python -m phc2d.cli forward train --config configs/smoke/forward_synthetic_res_mlp.yaml
```

运行后检查新建的 `runs/{yyyymmdd}/.../`，至少应看到配置快照、日志、指标和结果文件。实际文件集合以运行类型为准。

## 解释结果

这一步可以说明：

- CLI 找到了配置和模型；
- 数据能够按 metadata 解析；
- 一次前后向和产物写入能够完成。

这一步不能说明：

- 模型在 V2 10k 或 full-cell 数据上有效；
- 论文结果已复现；
- MPB/Meep 物理验证已通过。

下一步先阅读[项目全景与研究闭环](../概念/项目全景.md)，再根据目标选择[数据生成](../指南/数据生成.md)或[训练与评估](../指南/训练与评估.md)。
