# 快速上手

本教程完成安装、CLI 检查和可选的合成数据训练。正式数据、代理实验和 real-MPB 复核见[分级复现](../指南/分级复现.md)。

## 选择环境

| 环境 | 用途 | 允许表述 |
|---|---|---|
| Python 3.10+ | 安装、help、模型清单、文档审计 | R0 接口检查通过 |
| 安装 `train` extra | 合成数据的一轮最小训练 | R1 非物理 smoke 通过 |
| WSL `Ubuntu` + `meep_env` | 正式测试、MPB/Meep、replay | 由具体 R2/R3 gate 决定 |
| Windows `.venv` | 编辑和临时调试 | 不构成项目验收 |

`torch`、`h5py`、MPB 和 Meep 均不是基础 CLI 的强制依赖。

## 安装并完成 R0

### Windows PowerShell

```powershell
git clone https://github.com/fangtoast/phc2d.git
Set-Location phc2d
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m phc2d.cli --version
.\.venv\Scripts\python.exe -m phc2d.cli --help
.\.venv\Scripts\python.exe -m phc2d.cli models list
```

### Linux 或 WSL

```bash
git clone https://github.com/fangtoast/phc2d.git
cd phc2d
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
python -m phc2d.cli --version
python -m phc2d.cli --help
python -m phc2d.cli models list
```

看到版本、顶层帮助和模型清单后，R0 完成。它只证明轻量接口可加载。

## 可选：完成 R1

安装训练依赖：

```bash
python -m pip install -e ".[train]"
```

生成确定性的非物理合成数据：

```bash
python -m phc2d.cli data make-smoke --config configs/smoke/synthetic_dataset.yaml
python -m phc2d.cli data inspect --path data/generated/phc2d_synthetic_smoke.npz
```

运行一次最小训练：

```bash
python -m phc2d.cli forward train --config configs/smoke/forward_synthetic_res_mlp.yaml
```

预期得到标准 run 目录及 `run.log`、`run.meta.json`、`config.resolved.yaml`、`results.json`、`metrics.json`、`history.csv` 和 `figures/`。这些产物只证明链路可执行。

## 文档自检

需要维护本站时安装文档依赖并严格构建：

```bash
python -m pip install -e ".[docs]"
python -m phc2d.cli report docs-audit --root README.md --strict
mkdocs build --clean --strict
```

## 常见问题

| 现象 | 处理 |
|---|---|
| `torch` 未安装 | R0 不需要；R1 前安装 `.[train]` |
| smoke 数据已存在 | 默认拒绝覆盖；确认后显式使用 `--overwrite` |
| 没有正式数据 | 公共仓库不提交完整数据；按复现合同获取或生成 |
| Windows 测试通过 | 不能写成 WSL 或 MPB/Meep 验收 |
| MPB/Meep 导入失败 | 使用项目规定的 WSL `meep_env` 并先完成 preflight |
