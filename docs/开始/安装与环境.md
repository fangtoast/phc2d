# 安装与环境

本页帮助读者建立能够检查 CLI 和阅读数据合同的基础环境。它不下载正式数据，也不运行 MPB、Meep 或训练任务。

## 环境分层

| 层级 | 用途 | 允许证明 |
|---|---|---|
| Python 3.10+ 基础环境 | CLI、配置、schema、模型 registry | 接口可加载 |
| `train` 可选依赖 | PyTorch、h5py、训练与非物理 smoke | 训练链路可执行 |
| WSL `Ubuntu` + `meep_env` | MPB/Meep、正式数据和 solver replay | 对应协议的物理求解证据 |

## 安装基础包

```bash
python -m pip install -e .
python -m phc2d.cli --help
python -m phc2d.cli models list
```

需要训练功能时安装：

```bash
python -m pip install -e ".[train]"
```

## 验收边界

- `--help` 成功不代表数据、checkpoint 或 GPU 可用。
- Windows 环境可以承担编辑和轻量诊断，但不能替代 WSL `meep_env` 的 MPB/Meep 验收。
- 不要在未确认数据、配置、运行成本和授权时启动正式训练或 solver 任务。

安装完成后进入[第一次正向预测](第一次正向预测.md)，或者直接阅读[分级复现](../指南/分级复现.md)。
