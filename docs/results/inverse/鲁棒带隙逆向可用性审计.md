# 鲁棒带隙逆向可用性审计

**P2 尚不具备扩大搜索的条件：最新严格批次数值检查通过，但全来源代理选择统计不可用。** 该批 60 个候选在 M9 均通过冻结数值门，6 个预选案例的 WSL 对照通过；唯一有正目标共同裕量的来源在两个模型 seed 上出现带序异常，因此按冻结规则不可评分。这是分层开发批结果，不能替代独立目标测试或连续 BZ 认证。较早 validation 批的 64→96 数值检查为 31/60 通过，与本批合同不同，应分开理解。

## 结果与解释

计算使用固定带对，主分辨率 64、验证分辨率 96，至少两层、最多四层局部加密，并要求连续两层稳定；带边及分辨率容差均为 $5\times10^{-4}$。`complete gap` 是对所计算 k 点的判断。排序的随机基线为每组四个非锚点候选的均匀平均，12 组并非总体随机样本，三个 checkpoint 共享同一候选集和求解结果，不能当作三个独立物理试验。

梯度是正向网络输入栅格上的梯度，再投影到四个实际候选的有限栅格位移；不是二值几何的解析梯度。seed 1 沿单位 L2 随机输入方向的中心差分相对误差对步长敏感（0.01、0.03、0.1 时中位数约 0.216、0.102、0.051）；尚无预注册阈值，可微分支切换与单精度数值误差也未分离。梯度加速暂不进入主搜索，先保留无梯度方案。

512 栅格改善了这 12 个锚点的数值门通过数，但不能直接换作当前代理的输入合同：分别从 256 和 512 栅格面积平均到 64×64 后，三个偏移的输入逐像素绝对差中位数约为 0.0034，最大单像素差约为 0.156。模型误差和输入一致性仍需按新合同重新验证。

当前[周期二值偏移](../../../src/phc2d/inverse/morphology.py)使用栅格中心距离；对于 $N\times N$ 栅格，绝对值小于 $1/N$ 的非零偏移不会改变栅格。不能简单缩小 256 栅格偏移并称其为已解析的较小制造误差；需使用更高分辨率或另行验证的几何表示，并以同一表示中的名义结构作对照。
