# 鲁棒带隙逆向可用性审计

**目前不满足 P2 扩大搜索的数值条件。** 60 个名义候选的 M9 MPB 自适应带边计算已完成，但只有 31 个同时满足带边加密和 64→96 分辨率稳定门；12 组局部候选中只有 1 组的 5 个候选全部通过。这是 validation 上的探索性结果，并非独立目标测试或正式 WSL 验收。

## 结果与解释

| 检查 | 当前结果 | 含义 |
|---|---|---|
| 样本与目标 | K5 Binary validation 的 12 个锚点，每个含锚点共 5 个候选；TE、B9–B10、目标 $a/\lambda=0.83$ | 样本与频率在查看开发分布后确定，不是预注册测试 |
| 带边与分辨率门 | 31/60 同时通过；28/60 加密收敛但分辨率未通过，1/60 两者均未达到完整门 | 主要瓶颈是当前结构上的分辨率，而非求解任务失败 |
| 更高分辨率诊断 | 12 个锚点在 96→128 下 10/12 通过；原 64→96 下同批为 7/12 | 4 个由失败转为通过、1 个由通过转为失败；并非所有结构均收敛 |
| 粗网格与加密 | 6/60 从 complete gap 转为 pseudo gap | 固定 81 点会给部分候选产生错误的带隙判断 |
| 目标位置 | 14/60 的加密结果在目标频率处有正裕量，其中 6 个同时通过数值门 | 这些是有限局部 k 搜索结果，不证明连续 BZ 全局极值 |
| 代理排序 | 三个 Global–Local checkpoint 的代理选中候选相对同组候选均匀随机选择的平均裕量差分别为 0.0148、0.0176、0.0196 | 包含未通过数值门的候选，仅作探索性描述，不能证明可靠优势 |
| 假设的制造扰动 | 60/60 完成名义与 ±1/256 晶格常数的周期栅格偏移加密；0/60 有正共同区间，只有 10/60 的全部偏移通过数值门 | 未获得目标共同带隙；其余 50 个未达到稳定门，不能作确定性物理判决 |
| 几何表示差异 | 解析结构与零偏移 256×256 栅格的加密上下带边最大差分别约 0.00318、0.00313；带隙类别无翻转 | 二者的独立自适应搜索和材料表示不同，不能将解析结构直接视为扰动栅格的精确替代 |
| 梯度 | 输入梯度审计尚在进行 | 未验证真实几何梯度方向收益 |

计算使用固定带对，主分辨率 64、验证分辨率 96，至少两层、最多四层局部加密，并要求连续两层稳定；带边及分辨率容差均为 $5\times10^{-4}$。`complete gap` 是对所计算 k 点的判断。排序的随机基线为每组四个非锚点候选的均匀平均，12 组并非总体随机样本，三个 checkpoint 共享同一候选集和求解结果，不能当作三个独立物理试验。

## 下一决定与证据

剩余 48 个局部候选的 96→128 复核进行中；待数值门、真实方向审计及基线均可判定后，再决定是否启动 P3 闭环。96→128 是观察原门失败后的新诊断，不追溯改变本页 64→96 的统计。扰动基于 256×256 周期二值栅格，幅度是一格宽的假设边界偏移；这批候选的材料占比绝对变化中位数约为 2.6 个百分点，不代表实际工艺误差或良率。

原始候选、求解数组、配置与日志保留在 M9 的 `runs/20261030/EXP-INV-007_preflight_202610301200/`，其中 `batch_cases/` 是固定网格，`refine_batch_cases/` 是名义加密，`perturb_batch_cases/` 是扰动加密；该目录名是预检标识，不代表正式 `EXP-INV-007` 已注册或完成。候选 manifest SHA-256 为 `8f43e0af29e1dc65f8b14a02dcb336186db951b118447149d46e5b3af78fdbd0`，名义加密部署 commit 为 `bf3078e2534b00bb8144cae27019d3dcea90d469`，扰动加密部署 commit 为 `d88346b313bcd54c525be44fc0866b59b8c5ba1a`。结果汇总及身份检查见[名义加密核对](../../../src/phc2d/inverse/audit_refined_reconcile.py)和[扰动核对](../../../src/phc2d/inverse/audit_perturb_reconcile.py)；研究阶段与准入依据见[长期计划](../../planning/鲁棒带隙逆向/实验与验证.md)。
