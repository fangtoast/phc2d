# B2 residual 准入与 B1-1k TE Bloch 本征场数据，2026-07-20

本报告确认两项 WSL `Ubuntu` + conda `meep_env` 证据：64 条真实场数据通过 B2 residual gate；随后生成的 1,000 条 real-MPB TE Bloch eigenfield 数据集达到 `field_data_ready`。它们均**不是**已训练的 field/PINO/MaxwellNet 模型，也不构成 field inverse 或跨方法性能结论。

## B2 residual gate

有效 run 为本地 `runs/20260720/field_eigen_te_b2_residual_202607201057`，输入只使用有效的 64-record B1 数据集。残差采用 $a=c=1$、$\omega=2\pi f$、Bloch-periodic 中心差分的 $\nabla\times\nabla\times E-\omega^2\epsilon E$；空间尺寸与 epsilon 上采样比例由 HDF5 schema 推导。

| 审计项 | 实际结果 |
|---|---:|
| schema/provenance failure | 0 |
| solver-reference median relative residual | 1.5614 |
| deterministic random-field median | 23.2619 |
| solver-reference 胜随机场比例 | 100% |
| gate 状态 | `b2_residual_gate_pass` |

该 residual 仅证明正确 solver reference 与随机复场可区分；它不等同于训练后模型的低 residual。

## B1-1k real-MPB 数据集

有效 run 为本地 `runs/20260720/field_eigen_te_b1_1000_202607201058`，其启动被上述 B2 run 的 `results.json` SHA256 绑定。数据集为 `field_eigen_te_b1_1000.h5`，文件 SHA256 为 `6d980307d2f8d591431cbc1385cc44eec6d844ccd9a1d3f7c7380f170c936795`；selection manifest SHA256 为 `4aba5e773814f5704a28c890033dabd5581f7810dcff771ced4a789818d14f2c`。

状态为 `b1_1000_field_data_ready`。下一步是独立的 supervised field baseline（固定 split、三 seed、field relative L2/amplitude/phase/residual/runtime），不是直接启动 PINO、MaxwellNet 或 inverse integration。PINO/MaxwellNet 仍为 `blocked`，直至该独立 forward evidence 形成。
