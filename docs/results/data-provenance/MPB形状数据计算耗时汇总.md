# MPB形状数据计算耗时汇总

两批共36,000条逐结构计时记录均完整、无重复、耗时有效，并与各自最终HDF5的样本顺序逐条一致。旧六族单孔平均每结构13.38秒，新十二族平均12.63秒；两批四分片求解阶段的实际工期分别为11分53秒和21分02秒。全部求解成功，无失败或自动重试。

## 统计口径

- **每个结构耗时**：`sample_metadata.jsonl` 的 `mpb_solve_time_s`。每个结构一次计算81个k点，保留10条目标能带，内部加4条guard；不是单个k点或单条band耗时。
- **每族累计耗时**：该族2,000条逐结构计时之和。它是并发worker各自墙钟时间的累计，不能称为该族的实际等待时长，也不是操作系统实测CPU时间。
- **实际并行工期**：以Slurm的Start/End与ElapsedRaw为准。求解数组工期为最早分片开始至最晚分片结束；批次工期为plan开始至finalize结束，含阶段间等待，不含首次plan启动前的排队、传输和审计。
- **分配核时**：仅求解阶段的 `Σ(分片ElapsedRaw×64)/3600`，不包含plan/finalize，不等同用户计费或实际CPU消耗。
- 标准差为样本标准差（ddof=1）；P95采用NumPy线性分位数。表中值四舍五入，复算使用原始秒数。

计时实现使用 `time.perf_counter()`，包围求解器调用以及输出转换/哈希等轻量worker处理，不包含父进程队列等待、分片归档及最终栅格化。定义见项目源码 `src/phc2d/solvers/mpb_parallel.py` 的 `_solve_worker`，导出见 `src/phc2d/data/full_cell_hpc.py`。

两批均在Bingxing M9的amd_m9_768分区运行，4个独立分片、每片64 CPU/64GB、单线程worker；合同为真实MPB、TE、r64、mesh3、容差1e-7，空气/材料介电常数1/8.9。本页不是不同硬件或不同分辨率的性能对比。

## 证据与复算

固定统计制品位于 `runs/20261021/EXP-DAT-007-008_20261021_timing_summary/`：

- `逐结构耗时_36000.csv`：sample_id、孔形、分片、Slurm任务号及原始秒数；覆盖全部36,000结构。
- `孔形耗时汇总_18族.csv`：18族全精度均值、标准差、中位数、P95、极值与累计值。
- `Slurm实际工期.csv`：12条顶层任务的状态、退出码、开始/结束和ElapsedRaw，不重复计算batch/extern步骤。
- `统计与校验.json`：完整性断言、两批输入元数据哈希和HDF5哈希、统计口径与批次结果。
- `summarize_mpb_timing.py`：本次一次性统计程序，不属于公共生产接口；重算必须使用相同冻结输入。

上游为EXP-DAT-007的 `EXP-DAT-007_12000_20261020_bingxing_4x64_v1` 与EXP-DAT-008的 `EXP-DAT-008_202610211514`，使用各自 `sample_metadata.jsonl` 与最终HDF5；Slurm任务链为 `6259235→6259236_[0-3]→6259237`、`6284297→6284298_[0-3]→6284299`。本统计在WSL Ubuntu/meep_env离线复算通过；Slurm记录由Windows SSH只读取得，WSL未配置同名SSH别名，不在WSL重新连接超算。

复算公式：每族均值为 `sum(t_i)/n`，累计小时为 `sum(t_i)/3600`，样本标准差为 `sqrt(sum((t_i-mean)^2)/(n-1))`。逐结构CSV与汇总CSV可直接交叉核算。

## 解释与边界

18族单结构均值约11.49–14.26秒，本次配置下求解成本处于相近量级。此观察不能归因为孔数单因素：孔形、面积、栅格表示、节点及共享负载同时变化。新几何427组相同栅格输入按解析参数身份保留；本统计按实际执行的24,000次任务计时，不做去重或独立制造样本推断。

两批数据已交付N40并通过哈希核验，但正式WSL MPB复算验收仍未完成，新几何分辨率收敛未评估。本页只冻结生成耗时证据，不新增数值精度、完整带隙、器件复现或模型性能结论。下一门是补齐正式验收适配并按冻结合同复算；不因此自动重跑正式数据。
