## Conclusion

The prior N=256 guarded V2 gate passed as `physically_verified_with_documented_numerical_tolerance` in `runs/20260620/k_path_physical_validation_v2_256_202606201454`, after canonical generation with `band_order_policy=frequency_ascending`.

The N=1000 guarded V2 dataset was generated by real MPB in WSL `meep_env` and then physically validated by real MPB replay on 2026-06-21. The validation decision is `physically_verified_with_documented_numerical_tolerance`; `max_abs_error=1.1324882507324219e-06` is below `accepted_tolerance=1.2345293748383668e-05`. The validation runner promoted the sidecar and manifest.

The user explicitly allowed `workers=20` for this N=1000 gate. This is MPB sample-level worker parallelism, not GPU acceleration.
