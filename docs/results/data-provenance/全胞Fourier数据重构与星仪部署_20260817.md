# 全胞 Fourier 数据重构与星仪部署

## 结论

全胞数据代码已完成兼容性重构，并新增统一 Fourier v2 数据合同。旧的 polar-hole、spectral-threshold 和 graded RBF/Fourier 生成逻辑继续保留；新 B/G 路线共享硬截止 Fourier 潜在场、64 位确定性 seed、256 母版直接面积平均、版本化参数/内容哈希和 fail-closed 碰撞账本。

代码提交 `777b485` 与 `6fc4e71` 已通过本机 WSL `Ubuntu` + conda `meep_env` 回归，并把固定提交 `6fc4e718ca29b3bb9c8b2a2c29d492374bf8fd10` 部署到星仪。此次只部署代码、配置和默认 dry-run 作业入口，没有调用 `sbatch`，也没有产生 8+8 或 64+64 real-MPB 结果。
