# 全胞 K20 与 50K 跨数据域正向验证（2026-08-20）

本文只报告 `surrogate_held_out_cross_domain` 证据，不包含 p4m、inverse 或 MPB/Meep replay 结论。目标矩阵为：K20 B/G 各 1,000 个 held-out test 样本，50K B/G 各 5,000 个 held-out test 样本；68 个冻结 checkpoint 对四域各评估一次，共 272 cells。

## 一、冻结矩阵与分片

| 来源 | checkpoint | 目标域 | test | 分片 |
|---|---:|---|---:|---:|
| K20 | 17（seed 0） | K20-B/K20-G/F50-B/F50-G | 1,000/域 | 1/1/3/3 |
| 50K | 51（seeds 0/1/2） | K20-B/K20-G/F50-B/F50-G | 1,000/域或 5,000/域 | 1/1/3/3 |

正式提交前通过了 checkpoint hash、dataset/split hash、test cache hash、plan hash 和 batch preflight。v2 使用部署 commit `85c8162cfc2653eb1495c167825bd29997d16d0d`，plan hash 为 `0c67d1ea36084564e806b9e9e6c9d17acfe7d9dbcca05f2609c9c4e36f11c913`；预检 Slurm `5423640`，正式 array `5423642[0-7%8]`，finalizer `5423650`。

## 二、指标与比较

主指标为 bands 2–10 MRE；辅助输出包括 full-matrix MRE、MAE、RMSE、逐 `(k, band)` 方差加权 R²、逐 band/k 误差、band-order violation rate 和真实 GPU profile。相同目标 test 集上的跨域与同架构 native 模型使用逐样本 paired bootstrap，10,000 次；K20 统一使用 seed 0，50K seeds 1/2 只作为来源模型 seed 稳定性补充。

`dual_lane_band_operator_v1` 标记为 `joint_source_family`，不进入 B→G/G→B 泛化结论。任何结果均不得表述为 real-MPB、physically verified 或 inverse 成功。

## 四、人工理解记录

- **解决了什么问题：** 在不重训、不微调、不重新选择超参数的前提下，把 K20 与 50K Full-cell 冻结模型放到同一四域 held-out test 合同中比较。
- **为什么采用这个方案：** 四个域一次性冻结，目标域内部只加载一次缓存，固定 shard plan 可复现且便于发现缺失 cell。
- **改变了哪一层：** 主要改变 L3 实验/证据协议；模型架构和物理数据定义不变。
- **最大风险与下一 gate：** 远端 checkpoint/cache/hash 或任一 shard 失败会使 campaign blocked；完成后仍需人工审阅 Draft 报告，不能升级为物理验证。
