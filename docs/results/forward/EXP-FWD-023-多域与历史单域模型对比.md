# EXP-FWD-023：多域统一模型与历史单域模型对比

## 结论

这次对比回答两个不同问题，答案也不同：

1. **如果目标域事先已知，并允许为每个域保留一个专用模型，历史单域专家仍然更准。** 在 `9 模型 × 6 旧目标域 = 54` 个对应比较中，六个单域专家的 Bands 1–10 原生域平均 MRE 为 **0.8676%**，T07 六域统一模型在同一批目标上的平均为 **1.2443%**，高 0.3767 个百分点；T07 只在 3/54 个单元上低于对应原生专家。
2. **如果只能部署一个模型覆盖 K5/K20/F50 的 Binary/Graded 六域，T07 明显比任何单一来源模型稳健。** 九个模型平均后，T07 的六域宏平均为 **1.244%**；六类历史单一来源模型的六域宏平均在 **3.456%–6.672%**。对每一种架构，T07 都低于该架构历史上最好的单一来源六域宏平均，优势为 1.234–3.096 个百分点。
3. **统一模型相对专家的主要代价来自 Bands 2–10，不是 Band 1。** 54 个同目标比较中，Band 1 平均仅从 1.3785% 变为 1.3838%，差 0.0053 个百分点，T07 在其中 16 个单元更好；Bands 2–10 则从 0.8108% 变为 1.2288%，差 0.4180 个百分点。
4. **T07 内部仍以 M08/M09 为第一梯队。** 十二域 Bands 1–10 宏平均为 M08 TFNO **0.500344%**、M09 Global-Local **0.505812%**。M09 在六个旧域的宏平均略低，M08 在 K8/K10 和十二域总平均略低；当前没有这两者跨 campaign 的直接配对区间，不能宣称差异显著。

因此，现有证据支持的工程决策是：**已知单一目标域时优先保留专域专家；需要一个 checkpoint 同时覆盖多个 K 和两条路线时优先使用 T07/M08 或 T07/M09。** 这不是“综合域模型全面击败单域模型”，而是“以有限原生精度损失换取显著更好的跨域稳健性”。

## 可比性与限制

| 项目 | 审计结果 | 对结论的影响 |
|---|---|---|
| 旧六域 test 身份 | 六个数据集 SHA-256、`idx_test` 哈希和 k 点哈希在历史评估与 EXP-FWD-021/023 中一致 | 数值确实来自同一批 held-out 样本，可做逐目标描述性比较 |
| seed | 本页全部固定 seed 0 | 避免把 F50 的三 seed 均值与 T07 单 seed 混用，但不能说明跨 seed 稳定性 |
| 训练量 | K5/K20 单域为 8k；F50 单域为 40k；T07 总计 8k | F50 专家与 T07 不是等数据量比较 |
| 训练轮数 | K20 历史任务为 100 epochs；K5 多数为 200，M07/M08 延续至 220–320；M09 部分延续至 300；T07 固定 200 | 本页不是严格受控的训练制度因果实验 |
| normalizer | 历史模型使用各自源域 normalizer；T07 使用六域 pooled normalizer | 符合各 checkpoint 冻结合同，但 normalizer 也是训练制度的一部分 |
| 新 K 域 | 历史单域 checkpoint 没有 K8/K10/K15 的冻结结果 | 新六域只报告 T07，不填造历史对照 |
| 显著性 | 未重新生成跨 campaign 的逐样本配对 bootstrap | 只报告差值，不宣布统计显著性 |

本页每个结果格均按 **`Band 1 / Bands 2–10 / Bands 1–10`** 给出 MRE（%，越低越好）。它完整保留了 Band 1 与全 Band 汇总口径，但历史合并证据没有保存 Band 2、3、…、10 的逐 Band 展开，因此不能把本页误读为历史逐 Band 明细。若要补齐历史模型逐 Band 1–10 和 K8/K10/K15，必须另开一次只评估、不重训的冻结 campaign。

## 如何解释这些结果

### 事实：单域专家更擅长自己的域

单域 normalizer、全部训练预算和 validation 选择都针对一个分布，原生域优势符合预期。尤其是 F50-G 的 M05/M07/M08/M09，Bands 1–10 MRE 分别只有 0.076%、0.051%、0.099%、0.098%；T07 必须用总共 1,333 条 F50-G 样本与另外五域共享 8k 预算，不可能把全部容量都用于该域。

### 事实：单域模型的跨域风险很大

专域模型一旦离开来源域，误差可能增加一个数量级。例如 M03 H-F50-B 在 K20-G 为 31.240%，M08 H-K20-G 在 F50-B 为 8.044%。这也是为什么六类历史来源的九模型六域平均都明显高于 T07。T07 的价值不是刷新每个原生域的最低点，而是压低最常见的跨域失配。

### 解释：T07 学到的是共享结构与折中表示

六域混合使同一模型同时看到不同 Fourier 截断、数据规模来源以及 Binary/Graded 结构分布；pooled normalizer 又要求它在统一坐标尺度下拟合。因此它更可能形成跨域共享的低频与局部结构表示，但会牺牲对单一分布细节的专门拟合。这个机制与数值一致，但仍是解释，不是由当前对比直接证明的因果结论。

### Band 1 为什么必须单独看

如果只看 Bands 2–10，会把“统一模型相对专家的损失主要来自高阶 Band”这一点隐藏掉。本次重新统计后，Band 1 平均几乎持平，而 Bands 2–10 存在明显差距。因此今后所有跨训练制度比较都应同时报告 Band 1、Bands 2–10 和 Bands 1–10，不能根据结果好坏事后切换口径。

## 下一步决策

现有结果已经足够支持“专家部署”与“统一部署”的选择，但还不足以做严格的公平训练制度结论。若要把比较升级为同一合同实验，下一步应是：

2. 对完全相同的 test `sample_id` 生成单域专家与 T07 的逐样本配对 bootstrap，直接报告 T07 的原生损失与跨域收益区间。
3. 若还要回答“训练制度本身是否更好”，再用相同 8k、200 epochs、相同 seed 集合重训六类单域与 T07；F50 40k 历史模型只能保留为额外数据量参考，不进入公平主排名。
