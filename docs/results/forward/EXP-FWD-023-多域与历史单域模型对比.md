# EXP-FWD-023：七种混合训练与历史单域模型对比

## 结论

这次对比回答两个不同问题，答案也不同：

1. **如果目标域事先已知，并允许为每个域保留一个专用模型，历史单域专家仍然更准。** 在 `9 模型 × 6 旧目标域 = 54` 个对应比较中，六个单域专家的 Bands 1–10 原生域平均 MRE 为 **0.8676%**，S3-BG 六域混合模型在同一批目标上的平均为 **1.2443%**，高 0.3767 个百分点；S3-BG 只在 3/54 个单元上低于对应原生专家。
2. **七种混合训练制度并非都同样有效，S3-BG 明显最好。** 九个模型平均后，T01–T07 的十二域宏平均依次为 2.914%、2.219%、3.057%、3.444%、2.602%、1.990%、**1.471%**；覆盖六个来源域的 S3-BG（T07）最低，S3-G（T06）第二。增加混合来源不是单调改善，S2-K20-BG 就明显弱于 S3-G/S3-BG。
3. **统一模型相对专家的主要代价来自 Bands 2–10，不是 Band 1。** 54 个同目标比较中，Band 1 平均仅从 1.3785% 变为 1.3838%，差 0.0053 个百分点，S3-BG 在其中 16 个单元更好；Bands 2–10 则从 0.8108% 变为 1.2288%，差 0.4180 个百分点。
4. **S3-BG 内部仍以 M08/M09 为第一梯队。** 十二域 Bands 1–10 宏平均为 M08 TFNO **0.500344%**、M09 Global-Local **0.505812%**。M09 在六个旧域的宏平均略低，M08 在 K8/K10 和十二域总平均略低；当前没有这两者跨 campaign 的直接配对区间，不能宣称差异显著。

因此，现有证据支持的工程决策是：**已知单一目标域时优先保留专域专家；需要一个 checkpoint 同时覆盖多个 K 和两条路线时，在七种混合制度中优先使用 S3-BG/M08 或 S3-BG/M09。** 这不是“所有混合训练都全面击败单域模型”，而是“完整六域混合以有限原生精度损失换取大幅更低的跨域平均误差”。

## 可比性与限制

| 项目 | 审计结果 | 对结论的影响 |
|---|---|---|
| 旧六域 test 身份 | 六个数据集 SHA-256、`idx_test` 哈希和 k 点哈希在历史评估与 EXP-FWD-021/023 中一致 | 数值确实来自同一批 held-out 样本，可做逐目标描述性比较 |
| seed | 本页全部固定 seed 0 | 避免把 F50 的三 seed 均值与七种混合制度的单 seed 混用，但不能说明跨 seed 稳定性 |
| 训练量 | K5/K20 单域为 8k；F50 单域为 40k；T01–T07 每个任务均为总计 8k | F50 专家与混合制度不是等数据量比较 |
| 训练轮数 | K20 历史任务为 100 epochs；K5 多数为 200，M07/M08 延续至 220–320；M09 部分延续至 300；T01–T07 固定 200 | 本页不是严格受控的训练制度因果实验 |
| normalizer | 历史模型使用各自源域 normalizer；每个混合制度使用该制度独立的 pooled normalizer | 符合各 checkpoint 冻结合同，但 normalizer 也是训练制度的一部分 |
| 新 K 域 | 历史单域 checkpoint 没有 K8/K10/K15 的冻结结果 | 新六域报告全部 T01–T07，不填造历史对照 |
| 显著性 | 未重新生成跨 campaign 的逐样本配对 bootstrap | 只报告差值，不宣布统计显著性 |

本页每个结果格均按 **`Band 1 / Bands 2–10 / Bands 1–10`** 给出 MRE（%，越低越好）。它完整保留了 Band 1 与全 Band 汇总口径，但历史合并证据没有保存 Band 2、3、…、10 的逐 Band 展开，因此不能把本页误读为历史逐 Band 明细。若要补齐历史模型逐 Band 1–10 和 K8/K10/K15，必须另开一次只评估、不重训的冻结 campaign。

## 按测试目标域比较训练集选择

本节把“测试域”固定后再横向比较训练来源，直接回答同一个模型用哪种训练数据更好。绝对值表使用 Bands 1–10 MRE（%，越低越好），**粗体表示该模型在该目标域的最低误差**。

提升表固定使用同目标、同架构的历史单域专家作为基线：

$$\Delta_{\mathrm{pp}}=\mathrm{MRE}_{\mathrm{single\ native}}-\mathrm{MRE}_{\mathrm{mixed}}.$$

`Δpp > 0` 表示混合训练误差更低，`Δpp < 0` 表示相对单域专家退化；**粗体表示该模型七种混合制度中最有利的变化**。这里是 MRE 百分点变化，不是相对百分比。

## 如何解释这些结果

### 事实：单域专家更擅长自己的域

单域 normalizer、全部训练预算和 validation 选择都针对一个分布，原生域优势符合预期。尤其是 F50-G 的 M05/M07/M08/M09，Bands 1–10 MRE 分别只有 0.076%、0.051%、0.099%、0.098%；S3-BG 只有 1,333 条 F50-G 样本，而且要与另外五域共享总计 8k 的预算，不可能把全部容量都用于该域。

### 事实：单域模型的跨域风险很大

专域模型一旦离开来源域，误差可能增加一个数量级。例如 M03 H-F50-B 在 K20-G 为 31.240%，M08 H-K20-G 在 F50-B 为 8.044%。这也是为什么六类历史来源的九模型六域平均都明显高于 S3-BG。S3-BG 的价值不是刷新每个原生域的最低点，而是压低最常见的跨域失配。

### 事实：混合训练的收益取决于混合方式

- T01/S1-B 与 T02/S1-G 在各自路线内较强，但跨路线目标仍然明显退化；其十二域宏平均分别为 2.914% 和 2.219%。
- T03/S2-K5-BG 与 T04/S2-K20-BG 虽然同时包含 Binary/Graded，却只覆盖一个 K；跨 K 后并不稳定，十二域宏平均为 3.057% 和 3.444%。
- T05/S3-B 与 T06/S3-G 同时覆盖 K5/K20/F50，但仍缺另一条路线；T06 的 1.990% 明显优于 T05 的 2.602%，说明本轮 Graded 来源的跨域共享更强。
- T07/S3-BG 同时覆盖三种 K 来源和两条路线，十二域宏平均降至 1.471%，是九个模型平均意义下最均衡的制度。不过 M04/FNO 的最佳制度是 S3-G，而不是 S3-BG，说明“六域全混合最佳”仍不是逐架构无例外规律。

### 解释：S3-BG 学到的是共享结构与折中表示

六域混合使同一模型同时看到不同 Fourier 截断、数据规模来源以及 Binary/Graded 结构分布；pooled normalizer 又要求它在统一坐标尺度下拟合。因此它更可能形成跨域共享的低频与局部结构表示，但会牺牲对单一分布细节的专门拟合。这个机制与数值一致，但仍是解释，不是由当前对比直接证明的因果结论。

### Band 1 为什么必须单独看

如果只看 Bands 2–10，会把“统一模型相对专家的损失主要来自高阶 Band”这一点隐藏掉。本次重新统计后，Band 1 平均几乎持平，而 Bands 2–10 存在明显差距。因此今后所有跨训练制度比较都应同时报告 Band 1、Bands 2–10 和 Bands 1–10，不能根据结果好坏事后切换口径。

## 下一步决策

现有结果已经足够支持“专家部署”与“统一部署”的选择，但还不足以做严格的公平训练制度结论。若要把比较升级为同一合同实验，下一步应是：

1. 冻结历史六类单域 checkpoint 与 T01–T07 checkpoint，不重训；先在同一 N56 十二域 cache 上补齐历史单域 checkpoint 的 K8/K10/K15 评估和逐 Band 1–10 记录。
2. 对完全相同的 test `sample_id` 生成单域专家与 T01–T07 的逐样本配对 bootstrap，分别报告七种混合方式的原生损失与跨域收益区间。
3. 若还要回答“训练制度本身是否更好”，再用相同 8k、200 epochs、相同 seed 集合重训六类单域与七种混合制度；F50 40k 历史模型只能保留为额外数据量参考，不进入公平主排名。

这些步骤都是新的评估或训练 campaign，不由本文档自动授权。本页保持 `seed0 descriptive surrogate comparison`，不产生模型 promotion、real-MPB/Meep 或物理有效性结论。
