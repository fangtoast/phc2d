## 如何理解这些表

1. **同路线制度通常取得单目标最低值。** Binary 列常由 S1-B/S3-B 中的 TFNO 或 Global-Local 最低，Graded 列常由 S1-G/S3-G 最低。
2. **S3-BG 的优势是统一覆盖。** 它不要求预先知道测试目标属于哪个 K 或哪条路线，并在九模型平均的旧六域、新六域和十二域三个汇总上都最低。
3. **逐目标冠军和统一冠军不是同一个问题。** 表内粗体允许每一列分别挑模型；总体部署时仍应比较同一个 checkpoint 的十二域宏平均。
4. **M08/M09 是最稳定的第一梯队。** 但当前只有 seed 0，二者之间没有直接的跨 seed 显著性证据。

## 证据边界

- 本页是 `seed0 exploratory surrogate evidence`，样本 bootstrap 不能替代跨 seed 稳定性。
- K8/K10/K15 已通过 N56 文件哈希、schema、split、同 lane 配对和训练/validation 隔离审计，但仍标记为 `cluster_audited_pending_wsl_acceptance`。
- 本页不包含 real-MPB/Meep replay，不构成物理有效性或模型 promotion 证据。
- 历史 K5/K20/F50 单域 checkpoint 尚未在 K8/K10/K15 上形成冻结结果；本页只呈现 EXP-FWD-021 的 T01–T07 checkpoint。
