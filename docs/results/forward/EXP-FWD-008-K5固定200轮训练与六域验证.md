# EXP-FWD-008：K5 固定 200 轮训练与六域验证

**当前结论：17/17 任务均完整训练 200 epoch，但仅 5/17 满足原 bands 2–10 收敛门，因此 EXP-FWD-008 未按原合同通过训练验收。** 用户随后豁免该阻断，并在 EXP-FWD-009 中续训五个指定身份及完成六域评估；这不能回写为 EXP-FWD-008 的 17/17 收敛通过。EXP-FWD-007 的文件与结果保持独立。

## 验收门

| 门 | 必须证据 | 当前状态 |
|---|---|---|
| K5 训练 | 17/17，完整 epoch 1–200，`model.pt` + `epoch200.pt` + 身份摘要 + 曲线 | 通过 |
| 收敛 | 单路线主指标及 joint Binary/Graded/等权三曲线均 `r≤0.005` | **5/17，通过数不足** |
| checkpoint | 17 个 K5 terminal checkpoint | 完整，但 12 个带 `convergence_not_met` 状态 |
| preflight / shards | 原合同要求先由 17/17 收敛解锁 | EXP-FWD-008 内未解锁；后续由 EXP-FWD-009 人工豁免执行 |
| 数值回归 | K20/F50 408-cell 与旧 272-cell 子矩阵 `≤1e-6` | 在 EXP-FWD-009 中通过 |
| K5 paired bootstrap | 102 个对应 cell，三频带口径，10,000 次可复现 paired bootstrap | 在 EXP-FWD-009 中完成 |

## 后续结果

带人工收敛豁免的最终 17-checkpoint inventory、三频带口径六域表、MAE/RMSE/R²/band-order violation、102-cell paired bootstrap 和 finalizer 恢复证据，统一见 [EXP-FWD-009 结果](EXP-FWD-009-K5权重热启动与六域验证.md)。

## 证据边界

本页只代表 fixed-200 surrogate training evidence；不得把人工豁免写成原收敛合同通过，也不得升级为 real-MPB replay、物理验证、paired-K 因果效应或 inverse 成功。
