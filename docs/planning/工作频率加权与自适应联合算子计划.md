# 工作频率加权与自适应联合算子计划

## 结论与执行边界

本计划不预设一个大规模新网络。当前最有依据的路线是先回答两个问题：

1. 以平均折射率估计的一阶 Bragg 频率为中心，提高相邻能带的训练权重，能否减少最大带隙 band、边缘 $k$ 点和工作频率选择错误，同时保留完整能带精度？
2. 现有模型在不同数据域上的优势，能否在**同一个 Joint block 内**还原为频谱、局部卷积和通道混合支路的稳定贡献；若能，是否只需把当前全局固定门控改为轻量样本自适应门控？

两条路线必须先独立消融，再组合。任何模型改动都以现有 `dual_lane_band_operator_v1` 为直接基线；不新建 Maxwell 本征求解器、不增加场预测头、不把 KAN 直接并入主干，也不把本计划视为 N40 训练授权。

| 项目 | 本计划定义 |
|---|---|
| 主要修改层 | L1 科学假设；L2 架构候选只有通过前置 gate 后才准入 |
| 当前状态 | Draft，待人工接受 |
| 主要证据 | K5 六域 held-out、50K/K20 跨域结果、EXP-PHY-004 选频与真实响应差异 |
| 非目标 | inverse、field/PINO、完整 Maxwell residual、远程作业提交、模型 promotion |
| 物理证据边界 | 训练指标仍是 surrogate evidence；真实物理结论仍需 real-MPB/Meep replay |

## 一、为什么只做这两类改进

### 1.1 现有结果支持的推断

| 已观察事实 | 最小推断 | 对应实验，不直接推出的结论 |
|---|---|---|
| K5 bands 2–10 MRE 较低，但 EXP-PHY-004 六个代表结构中 ConvNeXt 仅 1/6、Joint 仅 4/6 同时选对 band 与 $k$ | 完整矩阵 MSE 与下游选频目标不完全一致 | 先改目标权重；不能据此要求更复杂 backbone |
| 最大单例选频偏差达到 29.390%，并改变冻结 real-Meep 响应 | 带边附近的少数坐标具有高下游代价 | 增加工作频率/带边指标；不能把六个样本当作总体失败率 |
| K5 单路线主指标由 TFNO v3 领先，50K native 由 ConvNeXt 领先，跨生成器和跨 lane 的赢家继续变化 | 局部与频谱组件的有效性可能依赖数据域 | 先在同一 Joint block 内做支路干预；不能直接拼接两个完整模型 |
| 当前 Joint 每个 block 已含 spectral/local/channel 三支路，但门控是每层三个全局标量 | 当前结构不能按样本或材料状态调整支路比例 | 若支路贡献确实随域变化，再改成轻量自适应门控 |
| lane embedding 维度 8/16/32 的差异仅约 0.15% | embedding 大小不是明显瓶颈 | 不继续扩大 embedding |
| 公平 Joint 续训到 300 epoch 只在 K5 Binary 胜出，且 K20 Graded 显著退化 | native 优化不保证跨域改善，可能存在负迁移或过拟合 | 先测梯度冲突与域分支贡献；不能先用 PCGrad 或复制 backbone |

以上事实分别来自[EXP-FWD-009/010/011 汇总](../results/forward/EXP-FWD-009-K5权重热启动与六域验证.md)、[K5 代理选频与真实响应差异](../results/field-physics/代理选频与真实响应差异_20260825.md)、[K20 与 50K 跨域验证](../results/forward/全胞K20与50K跨数据域正向验证_20260820.md)和[历史单 seed 灵敏度分析](../results/forward/灵敏度分析.md)。

### 1.2 当前不能使用的推断

- K5 与 K20 是独立样本，不能把二者差异解释为 Fourier cutoff 的单变量因果效应。
- “TFNO 在某域更好”不能直接证明 spectral branch 导致改善；模型容量、优化轨迹和输出头同时不同。
- “ConvNeXt native 更好”不能直接证明局部卷积更符合 Maxwell 方程。
- 平均折射率的一阶频率只是低阶尺度先验，不是每个高对比度二维结构的精确共振或真实最大带隙中心。
- 当前 Full-Wh 模型不输出本征场，因此本计划不加入 Maxwell 场残差；PINO 文献只作为未来条件，不作为本轮方法依据。

## 二、工作频率的物理先验

### 2.1 统一使用 MPB 无量纲频率

项目中的 `Wh` 使用 MPB 无量纲频率

$$
\tilde f=\frac{fa}{c}=\frac{\omega a}{2\pi c}=\frac{a}{\lambda}.
$$

后文虽然沿用用户提出的 $\omega_0$ 记号，但实现和报告必须记录实际使用的是 $\tilde f_0$，不能混用 Hz、角频率和 MPB 频率。

### 2.2 第一候选：平均折射率的一阶 Bragg 尺度

对每个解析结构定义胞内平均折射率

$$
\bar n
=
\frac{1}{|\Omega|}\int_\Omega \sqrt{\varepsilon(\mathbf r)}\,\mathrm d\mathbf r.
$$

对方形晶格的第一 reciprocal shell，均匀有效介质色散在 BZ 边界给出第一候选尺度

$$
\tilde f_0^{(X)}=\frac{1}{2\bar n}.
$$

该式只表示“第一阶 Bragg 尺度”。二维全 BZ 还含对角方向，因此 $\tilde f_0^{(M)}=\sqrt{2}/(2\bar n)$ 只作为预注册的方向敏感性对照，不与主候选混合调参。若训练集统计表明目标带主要不经过这两个窗口，则本假设在进入训练前即应判为不适用。

`\bar n` 必须由解析 `FullCellStructureSpec` 或冻结高分辨率材料场计算，并在 Binary/Graded 使用同一公式。禁止用 test 的真实最大带隙反推 $\tilde f_0$。

### 2.3 为什么不能把 $\tilde f_0$ 写成精确共振频率

平均折射率忽略了高对比度、偏振、各向异性、局部边界和高阶 Fourier 耦合。平面波展开研究还表明，介电函数不连续会影响 Fourier factorization 与收敛。因此本计划只检验：

> 一个由输入结构独立计算的低阶频率尺度，能否成为比“810 个坐标等权”更有用的训练先验。

若该先验不能改善 validation 的工作频率指标，路线应停止，而不是继续增加公式复杂度。

## 三、工作频率损失设计

### 3.1 用户提出的逆距离形式

图片中的候选可写为

$$
\mathcal L_{\mathrm{image}}
=
\operatorname{mean}_{q,b}
\frac{|\widehat{\tilde f}_{qb}-\tilde f_{qb}|}
{|\tilde f_{qb}-\tilde f_0|+\epsilon_f}.
$$

它会提高真实频率靠近 $\tilde f_0$ 的坐标权重，因而不需要预先固定“第几条 band”。但它同时改变了误差范数、频率尺度和平均梯度幅度；当 $\epsilon_f$ 过小时，少量坐标可能主导训练。

### 3.2 主实验形式：归一化逆距离加权 MSE

为了只改变“坐标重要性”，主实验保留当前 train-only z-score target 与平方误差：

$$
r_{qb}=\frac{1}{|\tilde f_{qb}-\tilde f_0|+\epsilon_f},
\qquad
w_{qb}=\frac{r_{qb}}{\operatorname{mean}_{q,b} r_{qb}},
$$

$$
\mathcal L_{\mathrm{inv}}
=
\operatorname{mean}_{q,b}
w_{qb}(\hat z_{qb}-z_{qb})^2,
$$

$$
\mathcal L_{\mathrm{total}}
=(1-\alpha)\mathcal L_{\mathrm{full}}
+\alpha\mathcal L_{\mathrm{inv}}.
$$

这样做保留完整谱监督，并把每个样本的平均权重固定为 1，降低 Binary/Graded 因频率分布不同造成的隐式 loss-scale 偏差。

### 3.3 稳定性对照：有界高斯窗口

逆距离权重的必要对照为

$$
w_{qb}^{\mathrm{gauss}}
=1+\rho
\exp\left[
-\frac{(\tilde f_{qb}-\tilde f_0)^2}{2\sigma_f^2}
\right].
$$

它的最大权重被 $1+\rho$ 限制。若逆距离形式改善工作频率指标但造成 full-spectrum 或跨域明显退化，而高斯形式保持改善，则应选择有界形式，不能因为更接近原图片而保留不稳定分母。

### 3.4 预注册参数与泄漏门

| 项目 | 冻结规则 |
|---|---|
| $\tilde f_0$ | 只由输入结构的 $\bar n$ 和晶格公式计算 |
| $\epsilon_f$ | 由 train split 的频率间隔分布预注册；不得读取 test |
| $\alpha$ | 小规模 validation screen 选择，候选数不超过 3 |
| $\rho,\sigma_f$ | 只用于高斯稳定性对照，候选数各不超过 2 |
| normalizer | 继续使用每个 lane 的 train-only 统计量 |
| checkpoint | 同时满足 full-spectrum 与 work-frequency validation gate；不按 test 选择 |

## 四、工作频率指标不能只看一个 loss

每个样本都要同时报告完整谱、频率窗口和带隙决策三层指标。

| 层级 | 指标 | 目的 |
|---|---|---|
| 完整谱 | Band 1、Bands 2–10、Bands 1–10 MRE/MAE/RMSE/R² | 防止只拟合窗口而牺牲整体 |
| 工作窗口 | $|\tilde f-\tilde f_0|\le\Delta_f$ 内 MRE/MAE；窗口覆盖的 band 分布 | 检验损失是否真的改善关注频率 |
| 最大带隙 | band pair accuracy、上下边缘 $k$ accuracy、joint band+$k$ accuracy | 对齐 EXP-PHY-004 失败模式 |
| 频率决策 | selected-frequency MRE、gap width/center error | 检验下游选频 |
| gap 类型 | complete/pseudo gap 一致率分开报告 | 避免多数 pseudo gap 淹没 complete gap |
| 泛化 | K5/K20/F50 × Binary/Graded 六域逐域结果 | 禁止用全域平均掩盖方向性退化 |

主 promotion 采用双门：

1. 工作频率/带隙指标相对原损失显著改善；
2. 六域中的 full-spectrum 指标不得出现预注册的实质退化。

六个 EXP-PHY-004 样本只用于 response sensitivity 回放，不承担模型选择。

## 五、从模型差异到组件差异

### 5.1 当前只能形成的组件假设

| 现有信号 | 候选组件解释 | 证据强度 |
|---|---|---|
| TFNO v3 在 K5 Binary/Graded 单路线主指标最低 | 低截止 Fourier 数据可能更适合频谱全局建模 | 相关性；未固定容量与优化 |
| ConvNeXt 在 50K native Binary/Graded 最低 | 更宽生成分布中局部层级特征可能更有用 | 相关性；不能推广到跨域 |
| FNO v2 在部分 B→G/G→B 方向较强 | 共享频谱算子可能在部分材料迁移中更稳定 | 方向性 seed0 证据 |
| Mixer 的 32/128 直接输入诊断相对稳 | 全局 token mixing 可能降低部分分辨率敏感性 | 诊断，不是严格不变性 |
| 赢家随 K5/K20/F50 和迁移方向变化 | 固定全局支路比例可能不是最佳 | 研究假设 |

以上信号不能通过“拼接 TFNO + ConvNeXt + Mixer”直接转化为新网络。必须先在同一参数合同下识别组件贡献。

### 5.2 现有 Joint 已具备可检验的三个组件

当前 [`FactorizedOperatorBlock`](https://github.com/fangtoast/phc2d/blob/master/src/phc2d/models/full_cell_operators.py) 已包含：

- `spectral`：Tucker-factorized Fourier convolution；
- `local`：circular-padding 局部卷积；
- `channel`：逐点通道混合；
- `gates`：每层三个全局可训练标量。

因此最小研究问题不是“再设计三条新支路”，而是：

> 三条现有支路在六域中的边际贡献是否不同，以及全局固定 gate 是否限制了 Joint。

### 5.3 阶段 A：冻结 checkpoint 的无训练干预

对现有 Joint checkpoint 逐层记录 gate，并分别执行：

- 屏蔽 spectral；
- 屏蔽 local；
- 屏蔽 channel；
- 只保留单支路；
- 保持原模型不变。

该阶段只测 prediction delta、六域 MRE delta、工作窗口 delta 和 gap-selection delta。由于屏蔽后分布偏移，它只用于定位候选，不可作为“该支路导致性能”的因果结论。

### 5.4 阶段 B：匹配训练消融

若冻结干预出现稳定方向，再以相同数据、seed、epoch、优化器和 head 从零训练：

| 候选 | 变化 | 回答的问题 |
|---|---|---|
| 原 Joint | 无 | 直接基线 |
| no-spectral | 删除频谱更新 | K5 优势是否确实依赖频谱支路 |
| no-local | 删除局部更新 | 50K/边界优势是否依赖局部支路 |
| no-channel | 删除通道支路 | 通道混合是否只是冗余容量 |

只有同一支路在冻结干预与匹配训练中方向一致，才准入自适应门控。

## 六、唯一的候选新网络：轻量自适应门控 Joint

### 6.1 改动范围

保持以下部分不变：

- `material_weight_grid_64` 主输入；
- lift、六个 operator blocks、Tucker factorization；
- spectral/local/channel 三支路实现；
- dense `Wh` head；
- lane-specific normalizer；
- 输出 shape 与 checkpoint identity 规则。

仅把每层全局 gate

$$
\mathbf g_l=\operatorname{sigmoid}(\mathbf a_l)
$$

改为样本条件 gate

$$
\mathbf g_l(x)
=
\operatorname{softmax}
\left(
W_l[\operatorname{GAP}(h_l),p(x)]
\right),
$$

其中 $p(x)$ 最多使用三个经阶段 A 验证的低成本描述量，例如材料平均值、灰度比例或高频能量比例。若没有任何描述量跨 validation/domain 稳定，$p(x)$ 置空，只使用 block 的 pooled feature；若自适应 gate 仍无收益，则停止该架构路线。

### 6.2 为什么它具有可解释性

每个样本、每一层都能输出三支路权重：

$$
(g_l^{\rm spectral},g_l^{\rm local},g_l^{\rm channel}).
$$

计划检验这些权重是否与以下量关联：

- Binary/Graded，而不仅是 lane ID；
- Fourier 高频能量和边界变化量；
- K5/K20/F50；
- 工作频率窗口和带隙选择是否成功。

只有 gate 与受控支路消融、结构描述量和误差变化三者一致时，才称为“组件解释”；单独展示 gate 大小不构成物理规律。

### 6.3 暂不纳入的改动

- 不新增完整 ConvNeXt 分支；
- 不新增 Mixer 分支；
- 不更换 dense head，因为历史筛选未选择 `k_conditioned`；
- 不使用 PCGrad，除非先测得 Binary/Graded 共享参数的持续负梯度余弦；
- 不把符号 KAN 放入主模型；只在最终解释阶段拟合少量稳定描述量与 gate/gap 的关系。

## 七、分阶段实验计划

| 阶段 | 主要问题 | 训练范围 | 通过门 | 失败动作 |
|---|---|---|---|---|
| P0 频率先验审计 | $\tilde f_0^{(X/M)}$ 覆盖哪些真实 band/gap？ | 不训练 | train/validation 中覆盖目标 band，Binary/Graded 均非退化 | 停止工作频率路线或重定义研究目标，禁止从 test 调中心 |
| P1 loss-only screen | 逆距离/高斯权重是否改善工作指标？ | 固定原 Joint，seed0，完整 K5 train | work/gap validation 改善且 full-spectrum 不实质退化 | 淘汰该 loss；不改 backbone 补救 |
| P2 loss confirmation | 改善是否跨 seed、跨域？ | 原 Joint，3 seeds；六域冻结评估 | paired CI、收敛门和六域退化门通过 | 保留为负结果，不进入架构组合 |
| P3 冻结支路审计 | 三支路贡献是否随域变化？ | 不训练 | 至少一支路的影响在多 checkpoint/域具有稳定方向 | 不做自适应 gate |
| P4 匹配组件消融 | 支路影响是否在从零训练中复现？ | 原/no-spectral/no-local/no-channel，先 seed0 validation | 冻结干预与训练消融方向一致 | 停止新网络路线 |
| P5 自适应 gate screen | 小门控能否改善 Joint？ | 原 gate vs adaptive gate，固定 loss，seed0 validation | 参数/成本增量受控，至少两 lane 改善或一 lane 改善且另一 lane不退化 | 淘汰 candidate |
| P6 组合确认 | work-loss 与 adaptive gate 是否互补？ | 2×2 factorial，3 seeds | 存在正交收益；六域与 gap gate 同时通过 | 选择单项而非强行组合 |
| P7 物理解释 | 关键描述量/gate 是否对真实扰动稳定？ | 少量配对 Fourier 扰动 + real-MPB | 方向、模型梯度和 MPB 频移一致 | 只能称经验解释，不能称物理规律 |

P1–P6 的远程训练、重试或预算变化均需新的明确授权。本计划不授权提交作业。

## 八、P6 的 2×2 因果拆分

只有 loss 与 gate 分别通过后才运行：

| 架构 | 原 full loss | 选中的 work-frequency loss |
|---|---:|---:|
| 原全局 gate Joint | A：基线 | B：只改 loss |
| adaptive gate Joint | C：只改 gate | D：组合 |

由此分别估计：

- loss 主效应：$B-A$；
- gate 主效应：$C-A$；
- 组合交互：$D-B-C+A$。

若 D 最好但 B、C 均不稳定，不得称两个组件分别有效。

## 九、统计、公平性与 promotion 门

### 9.1 固定比较合同

- 同一阶段保持 train split、normalizer、batch、optimizer、学习率、epoch/step、seed 和 checkpoint 选择一致。
- loss screen 不改变 backbone；gate screen 使用已经冻结的 loss。
- Binary/Graded 分开报告，Joint 保持等量 batch，但不得把两条 lane 平均后隐藏单 lane 退化。
- K5/K20/F50 均使用来源 checkpoint normalizer，不微调、不重拟合。
- test 只在候选与超参数冻结后访问一次。

### 9.2 候选 promotion 至少同时满足

1. 3 seeds 均完成且收敛门通过；
2. K5 Binary/Graded work-frequency 和 gap-selection 主指标形成 paired 改善；
3. 六域逐域报告，跨域没有超过预注册容忍度的实质退化；
4. Band 1 与 Bands 2–10 分开通过门；
5. 参数量、显存、训练与推理时间均记录；
6. gap-selection 全 test 审计完成；
7. real-MPB/Meep 只在 candidate freeze 后做分层回放；
8. 仍保持 `surrogate_held_out`、`solver_replay`、`physical_validation` 三类字段分离。

## 十、可能形成的理论贡献

本计划优先验证三层由弱到强的主张：

### T1：任务目标主张

> 对完整能带等权拟合不足以保证带隙驱动的下游选频；由输入结构估计的 Bragg 频率尺度可以作为预注册的频率关注先验。

这项主张只需要 loss-only 实验和完整 gap-selection 审计。

### T2：组件条件主张

> 光子晶体代理中的频谱、局部和通道混合组件没有统一赢家，其边际贡献随材料形态、生成器和目标频率窗口变化。

这项主张需要同一 Joint block 内的匹配支路消融，不能使用不同模型排行榜替代。

### T3：PDE 神经算子主张

> 对参数化 PDE，泛化改进未必来自更大的统一算子；更可检验的策略是用方程给出的尺度先验重加权目标，并让已有局部/全局算子按输入状态做低成本选择。

只有 P6/P7 跨域与物理扰动验证通过后，才讨论该主张；当前计划本身不构成结论。

| 文献 | 对本计划的启发 | 不直接采用的部分 |

| Christensen et al., [Predictive and generative machine learning models for photonic crystals](https://doi.org/10.1515/nanoph-2020-0197) | CNN 可从介电结构预测二维光子晶体能带 | 其数据/结构范围不同，不能替代本项目六域比较 |

文献只用于提出可证伪假设。项目中的模型优劣、物理规律和 promotion 必须由本仓库冻结数据、run 制品与 real solver 证据决定。

## 十三、人工决策点

在实施前需要人工确认：

1. 是否接受 $\bar n=\langle\sqrt\varepsilon\rangle$ 与 $\tilde f_0^{(X)}=1/(2\bar n)$ 作为主先验，$M$ 方向只做敏感性对照；
2. loss 主候选是否采用“归一化逆距离加权 MSE”，图片中的直接加权 L1 仅作附加对照；
3. P1 是否先在原 8k+8k Joint 上做 seed0 loss-only screen；
4. 只有 P3/P4 证明支路贡献随域变化后，是否准入 adaptive gate；
5. 每次 N40 训练、重试和物理 replay 的单独预算与授权。

## 十四、完成定义

本计划只有在以下条件全部满足后才能标记 `completed`：

- P0–P6 每一阶段都有 formal Experiment ID、配置、run 与结果链接，失败阶段也被保留；
- 选中的 loss 和架构完成 3 seeds 与冻结六域评估；
- 完整谱、工作频率、gap-selection、资源和收敛指标齐全；
- 物理回放状态与 surrogate 状态分开；
- 人工负责人接受最终结论或接受负结果。
