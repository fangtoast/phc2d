# 工作频率与带隙损失探索计划

## 结论

当前最值得继续的不是重新寻找一个简单“共振中心公式”，而是研究：

> 在保留完整 `Wh[81,10]` 监督的同时，加入一个较弱的带隙决策辅助项，能否改善 band、边缘 $k$、gap 宽度和 complete-gap 判断，而不明显牺牲全谱精度？

现有证据表明辅助损失可以改善 $k$ 点和部分 gap 指标，但当前权重会使 Bands 2--10 MRE 恶化；同时，粗 $9\times9$ BZ 标签不足以承担精确 complete-gap 监督。因此下一步必须先解决标签可信度，再进行一次受控 loss 筛选。

本计划只改变 loss，不改变 backbone。它不授权新的 N40 训练、real-MPB 扩样本或自动重试。

## 要验证的猜想

| 编号 | 猜想 | 当前依据 | 如何证伪 |
|---|---|---|---|
| L1 | 完整矩阵 MSE 与下游带隙决策不完全一致 | EXP-FWD-014 中 band-$k$ accuracy 明显改善，但全谱 MRE 恶化 | 若更换辅助项后 gap 指标仍不改善，则停止 loss 路线 |
| L2 | 主要问题是 gap 排序和 complete-gap 召回，而不是评价口径过严 | EXP-FWD-015 排除近简并后，正确率仍低 | 若排序/状态辅助项不能提高召回，则该猜想失败 |
| L3 | 标签精度限制了损失上限 | EXP-PHY-006 显示粗 BZ 会高估 gap，并出现 complete→pseudo 翻转 | 若加密标签与粗标签差异很小，则可解除该限制 |
| L4 | 简单标量工作频率不是可靠主监督 | EXP-FWD-012 与 EXP-PHY-005 的现有标量候选均未过门 | 除非新的方向张量或胞元模型先通过独立物理校准，否则不恢复该路线 |

## 要做什么

### L0：先通过标签门，不训练

对冻结 validation 结构做自适应全 BZ band-edge 加密，至少记录：

- 九个相邻 band pair 的上下边缘、中心和 signed width；
- complete/pseudo 状态及粗标签到精标签的翻转；
- edge shift 与 resolution shift 是否同时收敛。

只有精标签稳定后，才能用它选择或评价新的 gap loss。若 L0 未通过，继续训练只会把粗标签误差写进模型。

### L1：只选择一个新 loss 候选

保留现有完整谱损失：

$$
\mathcal L_{\mathrm{total}}
=
\mathcal L_{\mathrm{full\ Wh}}
+\lambda\mathcal L_{\mathrm{gap}}.
$$

`L_gap` 只允许包含三类信息：候选 gap 排序、带边 $k$ profile、complete-gap 正号或召回。候选必须减少 EXP-FWD-014 中重复的绝对回归竞争；权重只用 train/validation 预注册，不读取 test 调参。

### L2：seed0 配对短筛

| 固定项 | 合同 |
|---|---|
| 模型 | 同一个 `dual_lane_band_operator_v1` |
| 数据 | 公平 K5 Binary 4k + Graded 4k |
| 对照 | 原 `normalized_full_matrix_mse` vs 一个新 loss |
| 其他 | split、normalizer、seed、epoch、optimizer、batch 和 checkpoint 规则完全一致 |

### L3：通过后再做确认

只有 seed0 同时通过“gap 改善”和“全谱安全”两道门，才补 seeds 1/2，并在候选冻结后做 K5/K20/F50 × Binary/Graded 六域评估。任一失败都保留为负结果，不自动改权重重跑。

## 看哪些指标

| 目标 | 指标 | 通过原则 |
|---|---|---|
| 完整谱安全 | Band 1、Bands 2--10、Bands 1--10 MRE/MAE | 不超过预注册实质退化阈值 |
| 决策位置 | band accuracy、上下边缘 $k$ accuracy、joint band+$k$ accuracy | 两条 lane 均形成 paired 改善 |
| gap 数值 | width、center、selected-frequency error | 不能只改善其中一个并牺牲其余指标 |
| gap 状态 | complete-gap precision、recall、status accuracy | 重点检查少数 complete-gap 样本 |
| 泛化 | 六域逐域结果 | 不用六域平均隐藏单域退化 |

## 停止条件

- 精标签门未通过：停止训练。
- seed0 的全谱误差明显恶化：停止扩 seed。
- 只改善 $k$ 点但 complete-gap 召回仍接近零：不 promotion。
- 只有 test 上有效：判定为无效，不回头调参。

## 与组件计划的关系

[组件归因计划](FNO-TFNO-ConvNeXt组件归因计划.md)与本计划并行，但组件实验始终使用原始 loss。两条路线分别通过后，才做“原/新 loss × 原/新组件”的 $2\times2$ 组合实验。

## 下一人工决定

1. 是否先授权 L0 的 validation-only 精标签扩展；
2. L0 通过后，是否只准入一个 seed0 loss 候选；
3. 每次 N40 训练、扩 seed 和物理 replay 是否继续单独授权。
