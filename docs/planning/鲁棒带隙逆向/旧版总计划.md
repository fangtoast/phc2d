# 鲁棒带隙逆向研究计划

> **规划已取代（2026-11-04）。** 当前入口为[纯代理逆向研究](研究总方案.md)。下方原正文保留为历史合同；旧阶段、资源和未来安排不再作为新路线的默认执行指令，既有证据与失败状态不变。

**在现有 phc2d 与 GitHub 仓库中开展独立研究：冻结正向模型，以受约束搜索和少量真实 MPB 反馈寻找目标频段内、制造扰动后仍保留的共同带隙。** 本组文档是待人工审阅的长期路线；当前已有探索性候选和真实 MPB 审计，[P2 数值条件尚未满足](../../results/inverse/鲁棒带隙逆向可用性审计.md)，不代表正式逆向设计完成。

| 范围 | 决定 |
|---|---|
| 首要目标 | 二维 Binary、现有单偏振合同、归一化频率下的目标带隙与数值制造鲁棒性 |
| 科学问题 | 正向预测能力能否在优化分布偏移、k 网格漏采样和几何扰动下转化为设计效率 |
| 核心假设 | 结构可信范围与物理带边校正共同减少虚假改进；收益须在相同预算下验证 |
| 组织 | 同仓库，复用已有模块；无新顶层代码目录、无新 GitHub 仓库 |
| 本轮主层级 | L0 长期路线；专题分别约束 L1/L2/L3，后续一次只执行一个主要层级 |
| 暂不覆盖 | 生成式逆向、完整器件、双偏振共同带隙、实验加工良率与连续 BZ 数学认证 |

## 现有基础和缺口

| 事实 | 能支持什么 | 尚不能支持什么 |
|---|---|---|
| [四域冻结正向测试](../../reports/EXP-FWD-031四域完整测试结果_20261029.md) | 选择待审计 checkpoint 和对照模型 | 直接宣称梯度有效或逆向成功 |
| [EXP-PHY-007](../../results/field-physics/EXP-PHY-007-validation带隙标签门.md)及其原始 run | 64 个 validation 结构的粗网格风险；18/64 全带对稳定，3 次 complete→pseudo | 最新模型失效率、连续全 BZ 的全局保证 |
| 现有 inverse、replay、physics 与集群作业接口 | 候选结构、筛选、求解与证据组织的复用起点 | 当前 checkpoint 已与旧逆向适配器兼容 |
| 旧[全胞逆向计划](../全胞逆向索引.md) | 生成式路线的历史与原合同 | 自动约束本次非生成式路线 |

本计划新增非生成式分支，不替换旧生成式协议，也不升级旧实验状态。

## 阶段路线与完成定义

| 阶段 | 目标与主要产物 | 升级条件 |
|---|---|---|
| P0 身份与协议冻结 | 数据、checkpoint、栅格化、归一化、目标、平台与预算 manifest；登记空闲 EXP-INV 编号 | 来源一致、协议可审阅、资源预算明确 |
| P1 合同实现 | 非生成式搜索最小闭环；单元、合同、WSL 集成测试 | 无重型强制导入；重启不重复求解；几何与预测复现通过 |
| P2 12 结构可用性审计 | 排序、方向、带边和扰动诊断；一份有边界的结果页 | 数值可用且代理优于简单候选选择基线，才扩大 |
| P3 小规模闭环 pilot | 冻结目标的名义设计，比较静态代理与物理反馈 | 真实改进、预算可控、失败可解释；pilot 不升级正式结论 |
| P4 鲁棒方法与必要校准 | 加入制造误差、带边残差；必要时单独微调对照 | 开发集确定方法后冻结版本；负结果同样保留 |
| P5 正式比较 | 多目标、多 seed、模型与组件对照；独立物理复核 | 完整矩阵、统计不确定性、预算审计与 WSL 验收 |
| P6 论文与复现 | 结果表、失败机制、成本分析与复现入口 | 人工接受证据边界；不能只靠最好案例形成结论 |

原 P2 失败状态保留；[EXP-INV-010](../../../experiments/research/EXP-INV-010-事前排除目标搜索.md)提供了有限开发证据，[EXP-INV-011](../../../experiments/research/EXP-INV-011-名义物理反馈开发预检.md)可按其已登记的范围和预算推进名义反馈开发。此类 pilot 与原 P2 判定分别报告，不能替代 P2 或 P5 正式结论。后续工作以真实闭环为主线，复用适用于当前合同的既有验证，按[资源与迭代](资源与迭代.md)完成必要交接。
