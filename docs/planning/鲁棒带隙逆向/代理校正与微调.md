# MPB 反馈驱动的代理校正与微调

**MPB 在外层提供少量真实观测，代理适配后在内层继续提供设计梯度。** 纯代理及其末尾复核是完整对照；本页定义与之并行比较的物理反馈方法，属于主研究内容。目标不是每一步调用 MPB，而是测定少量物理计算能否纠正局部代理偏差并提高真实设计效率。返回[总方案](研究总方案.md)。

## 两种代理适配的含义

| 版本 | 更新对象 | 首版安排 |
|---|---|---|
| S0 原始代理 | 原有 GL 权重固定 | 纯代理基线，全程 GL 设计与选型，末尾 MPB 复核 |
| SR 局部残差校正 | GL 固定，拟合参数到上下带边误差的仿射模型 | 按附件推荐首先实现，校正值和参数梯度均可用 |
| SF 权重微调 | 用 MPB 新样本更新原 GL 的选定参数，生成新的 checkpoint | 单独比较的适配方案；训练数据、可训练层和训练预算在对应协议确定 |

本次明确的研究方向是可微代理与真实物理反馈相结合。附件首版采用 SR，故先复用已有仿射回归；SF 与 SR 是不同方法，不把残差系数变化称为 GL 权重已经微调。二者均不要求训练新的目标到结构生成器。后续若 SF 成为主比较，单独登记对应正向微调实验并与 EXP-INV-014 连接。

## 双层循环与数据使用

```text
原始 GL / 当前校正代理
  → 多步参数梯度优化 → 硬候选及原始预测
  → 一批 MPB → 形成带边/频谱观测
  → 局部残差适配，或选定权重微调
  → 冻结本轮代理版本 → 下一批可微优化
  → 最终候选锁定 → 独立 MPB 数值审查
```

纯代理 S0 的 MPB 成绩只进入评价；反馈 SR/SF 的优化观测允许影响后续代理。两者的最终审查均不再用于该版本的优化。反馈频率、每轮批量和轮数在阶段配置中设置，按累计真实改进和成本分析；保持大量梯度步由代理完成。

首个二维开发包可以使用锚点与两坐标正负扰动构成局部样本，再优先评价当前最好候选及覆盖不同方向的候选。候选选择规则、每轮 MPB 额度与重复几何处理在揭示该轮结果前固定。已有相同结构及相同求解合同的观测可复用并单列成本；不同保真度的中心和候选先统一评价后再比较改进。

## 首版 SR：上下带边仿射校正

对参数 $z$ 的硬二值几何，保存 MPB 带边 $b_P=(L_P,U_P)$ 与原 GL 硬输入带边 $b_h$。局部模型拟合

$$
r_h(z)=b_P(z)-b_h(z),\qquad \widehat r_h(z)=c+A(z-z_c).
$$

它可随参数变化调整上下带边。训练只用已返回且数值有效的观测；真实表现不佳的有效候选也有误差信息。两个参数的仿射斜率至少需要三个非共线样本；样本几何重复或方向不足时先用常数偏差，获得覆盖后再拟合斜率。

已有 `inverse/local_edge_correction.py` 提供 NumPy 仿射拟合和硬边校正。实现时复用拟合合同，将求值表达式写成 tensor 运算，保留 $A$ 对结构参数的导数；不将历史 MPB 求解纳入 autograd。

## 软几何与硬物理的衔接

内层优化采用软材料；MPB 观测对应硬几何。保存软输入精确带边 $b_T$、软输入平滑带边 $b_{T,\beta}$，分解

$$
b_P-b_{T,\beta}=(b_P-b_h)+(b_h-b_T)+(b_T-b_{T,\beta}).
$$

第一项是硬输入代理到物理的差异，第二项是软硬表示差，第三项是目标平滑差。首版在固定几何温度和带边平滑参数下，对复合残差 $r_{T,\beta}=b_P-b_{T,\beta}$ 做双带边仿射拟合，构造 $\widetilde b=b_{T,\beta}+\widehat r_{T,\beta}$，再由两侧裕量形成可微目标。分别保存三项以解释收益，复合残差不能称为纯模型误差。

一次内层求解固定系数与温度版本；continuation 改变后，使用已保存硬谱和重新预测的软谱重建残差目标，重新预测计入费用。样本覆盖以外不无限外推，采用局部参数范围与几何约束。精确硬输入预测和数值有效的真实最优设计始终单独保存。

## SF：MPB 样本更新 GL 权重

SF 从同一原始 checkpoint 热启动；MPB 新标签与源训练数据的适量 replay 组成训练集，源 normalizer 保持冻结以便比较。保留原验证子集评价遗忘，适配观测分成训练/局部验证角色，最终独立目标不进入微调。具体全谱/带边辅助 loss、训练层、学习率、轮数和早停由开发批选择后固定。

若 MPB 观测只有密 k 带边，它可以直接训练 SR，却不能当作固定 81×10 全谱标签训练 GL。SF 须在真实相同材料与几何上取得匹配 checkpoint k 坐标的 MPB 频谱。只拥有硬几何标签时，先训练硬输入分支；若希望改善软输入，还需显式的软材料标签或经独立评价的桥接方案，不能把硬谱贴到任意软结构上。

每次权重更新结束保存新 checkpoint、父 checkpoint、样本与配置；恢复结构优化时冻结新权重，仅对结构参数求梯度。先按小批学习曲线决定样本与训练预算，不预设少数 MPB 点足够微调整个 GL。原始模型误差、局部误差、原验证保持情况、梯度方向与新设计质量共同评价 SF。

## 轨迹控制与代理更新分开比较

保留三组最小对照：S0 原始代理、T0 原始代理加真实接受/拒绝、SR 校正代理加同一轨迹政策。SF 是另一组适配版本。T0 相对 S0 检验物理决策，SR 相对 T0 检验模型校正的额外作用，避免只凭拒绝坏候选就宣称代理改善。

若使用现有信赖域，预测增益是同一轮冻结模型对候选与中心的差，实际增益是同一求解精度下的真实差。形成本轮决定后才把新观测加入下一版本，预测增益接近零时沿用现有受控分支。中心更新、历史真实最优和适配观测分别保存；拒绝候选仍可提供有效误差样本。

校正误差在下一观测进入拟合之前评价。最终设计效果以统一物理复核、全来源成功率、真实裕量、共同带隙与总成本判断；拟合样本误差下降仅说明拟合。反馈无收益或 SF 退化仍是 EXP-INV-014 的有效结果，按实验结果选择后续方法版本。

## 实现与输出

复用冻结代理、Fourier/硬栅格、局部回归、信赖域、已有日志/预算和 MPB 请求接口。优先补 tensor 校正求值、版本化适配观测和批次衔接；不为阶段交接重建通用调度平台。SR/SF、接受/拒绝、代理更新和求解分别保持可关闭的接口，使用共用几何与目标完成消融。

run 附适配观测清单、原始/校正/微调模型身份、温度/平滑版本、拟合前预测、系数或新 checkpoint、接受决定、真实最优与全资源账目。成本分为原始设计、MPB 采样、拟合或训练、再设计和独立复核。推进顺序见[推进与交付](推进与交付.md)。
