# 可微代理与 MPB 反馈逆向研究入口

**主任务：纯代理可微设计＋MPB 反馈校正/微调代理，最终实现制造鲁棒的目标带隙设计。** 先交付全程 GL 的纯代理基线，再以少量外层物理观测适配代理、继续优化，并用独立 MPB 结果比较收益和总成本。方向按作者最新说明确定，详细协议为 Draft。

首个工作包是来源 8、固定融合 3×3 GL 的 [EXP-INV-012 / MVP-INV-001](https://github.com/fangtoast/phc2d/blob/master/experiments/research/EXP-INV-012-梯度链条开发验证.md)。先完成模型/几何接入与可微设计器，再运行预定纯代理候选和末尾复核；之后按 EXP-INV-013/014/015/016 依次推进算法比较、MPB 适配、鲁棒和独立研究。状态与交付以[推进与交付](推进与交付.md)为准。

规划文件解释长期方法和工作包；具体配置、阈值、预算进入 experiments/configs，运行证据进入 runs，结论变化时更新结果页。相同合同已有的有效检查直接复用，通过阶段条件后继续已授权的后续工作。

## 本次补充思路如何采用

七份技术附件与先前提供的版本内容一致，补充正文重申完整研究主线。Fourier 松弛、平滑目标、梯度可信度、两层物理反馈、局部仿射校正、G×P 和六图均纳入现行专题。附件中的实验编号建议保留为历史来源，实际沿用已登记/预留的 012–016；目录树按当前模块责任接入，不照搬新目录。部分粘贴片段中途结束，不作为已实现算法。主比较既报告固定物理预算下质量，也报告端到端总成本，不把历史秒数直接当本研究效率。
