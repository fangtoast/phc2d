# Global–Local 纯代理逆向研究总方案

**当前主方法在优化与选型阶段全程使用冻结 Global–Local；候选全部锁定后，MPB 只负责独立复核。** 先回答纯代理能否产生有效设计，再用实验证明少量物理反馈是否值得加入。在线反馈、局部残差和 MPB 信赖域不再是主方法必备模块，也不是制造鲁棒研究的前置 gate。

研究方向已由作者确认；本组详细协议为 Draft，具体权重、超参、阈值与计算预算尚待执行冻结。当前未实施或运行新算法。目录入口为 [README](README.md)。

已有正向训练成果、Fourier 几何、代理排序、周期边界和 MPB 复核继续作为本研究的基础。上版归档只取消反馈优先的执行安排；该方案中的通用能力按当前代码和证据复用，见[现有基础与复用](现有基础与复用.md)。

## 科学问题与论证顺序

冻结正向能带算子的输入梯度，能否通过可微几何参数化，在不调用在线物理求解器的情况下完成目标带隙设计，并使锁定结构通过独立 MPB 复核？

| 命题 | 必要证据 | 不支持该命题的情况 |
|---|---|---|
| 参数梯度可用 | 参数 AD–FD 一致；预先选定的梯度候选在末尾 MPB 检查中具有真实收益 | 计算图正确，但硬投影或真实方向失效 |
| 纯代理逆向有效 | 多来源和多起点下，代理选定结构具有目标带隙，成功率与总成本可核验 | 只报告预测最优，或物理复核后重新挑选成功候选 |
| 代理鲁棒目标有效 | 全部制造场景由 GL 优化，最终真实扰动几何具有共同目标区间 | 三个任意位置的带隙或仅软材料结果 |
| 在线反馈值得使用（后续比较） | 对照纯代理，在统一最终验收下呈现可重复的质量—成本收益 | 增加物理计算而无相应质量收益；此时保留纯代理方案 |

论文主线为：已有正向预测 → 可微几何与参数梯度 → 纯代理设计及真实谱差异 → 制造共同带隙 → 独立验证与总成本。反馈是否纳入最终方法由后续比较决定；不预设它必然更准确、更慢或更划算。自动微分本身不构成创新性证据。

## 主流程与信息隔离

```text
目标/材料/几何约束
  → Fourier 软参数化 → 冻结 Global–Local → 目标及梯度
  → Adam 多步/多起点优化 → 硬二值化与 GL 重评分
  → 依照预注册规则选型 → 锁定结构、顺序、预测、全部轨迹
  → MPB 同 k 复核 → 带边加密/分辨率/制造场景独立审查
  → 报告成功、失败、误差和成本
```

主方法不读取本批候选的 MPB 结果来更新参数、调温度、接受/拒绝、拟合残差或更换最终候选。开发阶段允许用独立诊断批研究误差；由这些结果修改的方法须形成新版本，并重新冻结独立评估批。固定范围、步长控制或仅基于代理的约束管理可以使用，但须与 MPB 驱动信赖域区分。

## 首版选择

| 对象 | 当前选择 | 待执行冻结 |
|---|---|---|
| 任务 | TE，B4–B5，$a/\lambda=0.57$ | 材料、晶格、k、单位 |
| 主模型 | 固定 0.5/0.5 融合、周期 3×3 局部分支的 Global–Local，权重冻结 | K5 Binary 的 checkpoint、seed、factory/指纹、normalizer、原始参考输入 |
| 参数化 | 标准化 Fourier、Sigmoid 松弛与硬阈值，先两个参数 | 模态索引、参数范围、潜场归一化及主栅格合同 |
| 优化 | Adam；DE、随机搜索、后续多初值/L-BFGS 对照 | 平滑温度、步数、重启数、学习率与公平成本 |
| 选型 | 先生成合法硬几何，再按硬输入 GL 精确目标评分；首版每 trial 固定提交 Top-1 | 并列与重复规则、候选清单锁定方式 |
| 鲁棒扩展 | 名义/过刻蚀/欠刻蚀全部使用 GL 评分与最坏场景目标 | 真实周期边界偏移语义、幅度、可微近似与未见扰动 |
| 最终评价 | 锁定候选的 GL–MPB 谱差异、真实目标覆盖、共同带隙、总成本 | 同 k 谱比较、密 k/分辨率数值门、WSL 复核 |

多个结构可以满足同一目标，没有唯一“真实结构”。主要比较同一锁定结构的代理谱与 MPB 谱，以及 MPB 谱是否满足设计要求；若附已有参考结构对照，明确其来源与作用。

## 模型训练策略

首版加载并冻结已有正向 checkpoint，通过优化结构参数得到每个目标的设计，不训练目标到结构的新网络。冻结指不更新网络权重，输入到目标的梯度仍要保留。先以 K5 Binary 的固定融合 3×3 为主候选，具体 checkpoint 与其原始输入合同须在 S0 核对，不能凭模型名或代码默认参数认定身份。

如果软结构的预测、参数方向或硬化后结果不可靠，先诊断输入栅格、温度、归一化、硬投影和 k 采样；如确需补充 MPB 样本或微调，另行提出数据/正向训练实验和预算，保留冻结模型作为对照。开发所得 MPB 反馈不能用于当前已锁定的独立测试；新模型须冻结后使用新的独立评价批。
