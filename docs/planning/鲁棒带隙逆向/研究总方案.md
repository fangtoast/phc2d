# 可微代理与 MPB 物理反馈逆向研究总方案

**完整研究主线为可微代理与真实物理反馈相结合：先实现全程 GL 的纯代理设计，再用少量 MPB 观测校正/微调代理并继续优化，最后验证制造共同带隙与计算效率。** 纯代理是必须完成的基线，MPB 代理适配是主研究包；MPB 按批次或外层轮次调用。

方向沿用作者最新说明和补充附件，详细协议为 Draft。当前已完成规划组织，尚无这条新算法的完整实现或实验结果。已有正向训练、Fourier 几何、周期操作、MPB 与预算组件继续复用，见[现有基础与复用](现有基础与复用.md)。工作包与下一交付集中维护在[推进与交付](推进与交付.md)。

## 科学问题与论证顺序

如何用神经算子的结构梯度高效优化目标带隙，并通过少量真实物理观测改善代理与设计轨迹，得到可通过独立数值复核的名义及制造鲁棒结构？

| 命题 | 必要证据 | 不支持该命题的情况 |
|---|---|---|
| 参数梯度可用 | 参数 AD–FD 一致；预先选定的梯度候选在末尾 MPB 检查中具有真实收益 | 计算图正确，但硬投影或真实方向失效 |
| 纯代理逆向有效 | 多来源和多起点下，代理选定结构具有目标带隙，成功率与总成本可核验 | 只报告预测最优，或物理复核后重新挑选成功候选 |
| 代理鲁棒目标有效 | 全部制造场景由 GL 优化，最终真实扰动几何具有共同目标区间 | 三个任意位置的带隙或仅软材料结果 |
| MPB 代理校正/微调有效 | 对照纯代理，在统一最终验收下呈现可重复的质量—成本收益 | 增加物理计算而无相应质量收益；此时保留纯代理方案 |

论文主线为：已有正向预测 → 参数梯度与纯代理基线 → MPB 反馈怎样校正代理及改善设计 → 制造共同带隙 → 独立验证与总成本。分别用对照检验梯度、物理反馈和鲁棒目标；论文贡献由结果决定，自动微分和组件组合本身不等于新颖性。

## 主流程与信息隔离

```text
目标/材料/几何约束
  → Fourier 软参数化 → 冻结 Global–Local → 目标及梯度
  → Adam 多步/多起点优化 → 硬二值化与 GL 重评分
  → 依照预注册规则选型 → 锁定结构、顺序、预测、全部轨迹
  → MPB 同 k 复核 → 带边加密/分辨率/制造场景独立审查
  → 报告成功、失败、误差和成本
```

上图是纯代理基线，全部设计和选型在本批 MPB 结果揭示前完成。反馈路线在梯度优化若干步后，将硬候选交给 MPB，更新局部带边残差或选定的 GL 权重，再冻结本轮代理继续优化；最终锁定候选使用同一标准独立复核。优化观测与最终审查各有明确用途，详见[代理校正与微调](代理校正与微调.md)。

## 首版选择

| 对象 | 当前选择 | 待执行冻结 |
|---|---|---|
| 任务 | TE，B4–B5，$a/\lambda=0.57$ | 材料、晶格、k、单位 |
| 主模型 | 固定 0.5/0.5 融合、周期 3×3 的 GL；纯代理和残差版本冻结骨干 | K5 Binary 的 checkpoint、seed、factory/指纹、normalizer、原始参考输入 |
| 参数化 | 标准化 Fourier、Sigmoid 松弛与硬阈值，先两个参数 | 模态索引、参数范围、潜场归一化及主栅格合同 |
| 优化 | Adam；DE、随机搜索、后续多初值/L-BFGS 对照 | 平滑温度、步数、重启数、学习率与公平成本 |
| 选型 | 先生成合法硬几何，再按硬输入 GL 精确目标评分；首版每 trial 固定提交 Top-1 | 并列与重复规则、候选清单锁定方式 |
| MPB 代理适配 | 首先用可微仿射双带边残差，权重微调单列；外层批次反馈 | 样本、更新频率、半径/正则、适配数据与计算预算 |
| 鲁棒扩展 | 名义/过刻蚀/欠刻蚀全部使用 GL 评分与最坏场景目标 | 真实周期边界偏移语义、幅度、可微近似与未见扰动 |
| 最终评价 | 锁定候选的 GL–MPB 谱差异、真实目标覆盖、共同带隙、总成本 | 同 k 谱比较、密 k/分辨率数值门、WSL 复核 |

多个结构可以满足同一目标，没有唯一“真实结构”。主要比较同一锁定结构的代理谱与 MPB 谱，以及 MPB 谱是否满足设计要求；若附已有参考结构对照，明确其来源与作用。

## 模型训练与更新

首个 MVP 和纯代理基线直接加载已有 GL，优化结构参数而不重训骨干。首个 MPB 适配版本按附件使用冻结 GL 加局部仿射带边残差；它学习局部误差，其求值参与结构梯度。若研究更新 GL 权重，则生成独立的微调 checkpoint，记录 MPB 新标签、源数据 replay、验证和训练成本；每次适配后冻结权重再做结构优化。二者的定义与比较集中在[代理校正与微调](代理校正与微调.md)。

首版不训练目标到结构生成器，不改变 GL 的 fixed-k 频谱输出合同。多个目标频率进入目标函数，不需要给 GL 新增目标频率条件输入。软几何分布偏移通过独立开发诊断处理，必要的数据扩展或权重微调单独登记实验和成本。

## 预期成果及判读

| 产物 | 要得到的结果 | 如何评价 |
|---|---|---|
| 可微设计器 | 可重建的硬结构、原始预测谱、参数轨迹和 Top-1 | 参数梯度、GL–MPB 同 k 谱差、真实目标裕量和合法性 |
| MPB 适配方法 | 局部校正模型或新 checkpoint，以及改善后的设计 | 拟合前的新观测误差、相对原代理/仅轨迹反馈的真实收益和全部成本 |
| 鲁棒设计 | 名义、过刻蚀、欠刻蚀具有共同目标窗口的候选 | 所有硬场景的 MPB、共同宽度、名义代价和未见扰动 |
| 论文与复现包 | 梯度、反馈、鲁棒、效率的完整对照和图表 | 多来源不确定性、失败案例、可复核配置/模型/原始谱 |

不预报成功率或加速倍数。负或混合结果需要定位影响哪一项主张，完成可用比较后形成阶段结论；不是自动追加所有保护检查或重启整条研究。
