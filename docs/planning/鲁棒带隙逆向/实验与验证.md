# 鲁棒逆向实验与验证

**先证明合同和局部搜索可用，再扩大为正式研究；不承诺任何正向改进幅度或物理成功率。** 返回[总计划](README.md)。本页是 campaign 路线，具体正式 Experiment ID、预算和阈值须在对应阶段协议中冻结，不能直接作为提交配置。

## P0：冻结研究对象

先以 K5 Binary 为审计起点，从已有正式来源定位 Global–Local 的三个 seed；TFNO 和 ConvNeXt 保留同源对照身份。具体采用历史 GL 3×3、7×7 或 031 门控版本须依据可恢复合同在审计前选定，不能混用或根据逆向 test 排名改选。F50 Binary 在后续评估覆盖收益，不默认 K5 结论适用 F50。

manifest 固定数据 hash、train/validation/test、模型 factory/架构指纹/checkpoint hash、目标 normalizer、材料栅格字段、栅格化版本、k 坐标与频率单位。回放原输入后的预测需与冻结参考在预注册容差内一致。无可恢复参考或几何对应不上时标记 blocked，不绕过。

train 用于初始结构库和拟合；validation 用于开发与门槛选择；已有 forward test 不参与开发。逆向正式目标清单另行冻结，开发目标与正式目标按频段/带对/结构来源分组隔离，并记录与 forward splits 的关系。在线 MPB 是优化预算中的观测，最终更密网格、更高分辨率与未见扰动结果只作审查，不能反馈调参后继续称原版本正式 test。

## P1：最小工程验证

| 测试 | 最小案例与断言 |
|---|---|
| 目标函数 | 已知谱；空共同区间、目标越界、多个扰动各有 gap 但无交集、单位和带序异常 |
| 表示与适配器 | 真实样本重建、normalizer 往返、checkpoint 恢复、metadata shape、材料/固定 k 身份不符拒绝 |
| 周期几何 | 穿越胞边界的连通、距离偏移、最小特征与跨边界孔隙 |
| 梯度 | 可微路径有限差分；硬阈值显式不支持；输入梯度与模型参数冻结分离 |
| 校正与状态机 | 拒绝虚假改进、零分母、回归样本不足、预算用尽和失败 solver |
| 分布式交接 | mock shard、重复/错 hash/缺失结果、中断恢复、不同精度缓存隔离 |
| 回归 | 新旧 CLI 帮助、轻量导入、既有 inverse/replay 定向回归；必要时完整回归 |

先运行窄测试再相关回归。Windows 可作编辑诊断；项目工程与物理验收均在 WSL Ubuntu 的 meep_env 执行。测试通过只支持 implemented/smoke_pass，不支持逆向科学结论。

## P2：12 结构逆向可用性审计

开发样本按粗标签目标裕量分为明显正、接近零、非正三层，各 4 个，固定 seed 及抽样清单。若某层不足则报告实际数量和缺口，不从 test 补齐；粗标签分层不能称物理真实类别。归一化目标频率、带对、邻域步长、扰动幅度和几何阈值在求解前固定。

每个结构评估原始锚点和受约束局部候选；相同候选比较代理排序、MPB 固定网格排序、加密带边和扰动共同区间。审计至少输出有效候选数、Kendall 排序相关、top 候选真实收益、梯度方向收益、complete→pseudo 次数以及表示误差。候选数与求解预算由单例计时后冻结，不在此用未经测量的总工时作承诺。

| Gate | 可继续条件 | 失败处理 |
|---|---|---|
| 身份/表示 | 所有纳入样本合同复现通过 | 修复适配器或记录数据缺口 |
| 数值 | 原始及候选评价达到冻结 edge/resolution 标准 | 增加精度评估并重新估算预算；未过不排真实最优 |
| 代理选择 | 与随机候选选择相比，真实收益在预注册统计口径下有正向证据 | 加局部校准再做独立开发批；不扩大正式 campaign |
| 梯度 | 内部差分通过，真实方向收益优于配对随机方向 | 失败则继续无梯度搜索，不能视为整条路线失败 |

12 结构仅作可用性筛选，样本不足以证明普遍优越；报告区间与失败例，不以显著性不足冒充通过。新开发批与旧批分列，保存全部尝试。

若对分层样本计算配对 bootstrap，须在该批候选结果公布前冻结来源清单、每层数量和层权重，并在每层内以来源为重采样单位；等权结果只描述所设分层的加权目标，不能直接代表总体分布。缺失来源或无效预测不得作为完整批次统计；已实现的分层汇总接口仅提供描述性统计，是否满足研究门仍须按实验协议判断。

## P3–P5：闭环与正式对照

P3 在少量冻结开发目标上跑名义目标闭环，先验证接受/拒绝、历史最优和预算恢复。P4 再加入制造扰动与带边校正；如需微调，按训练来源和优化新标签独立登记 EXP-FWD 实验，比较冻结/校准/微调三种成本。没有证据要求时不从零重训、不训练逆向生成器。

正式 P5 使用 seed 0/1/2，目标数先由 pilot 方差、成功率和预算估计后冻结；不得把 12 结构直接当最终测试集。低维子任务至少比较直接 MPB 搜索，并视可行性加入物理梯度基线；若缺少物理梯度基线，不作全面优于传统拓扑优化的主张。

| 比较维度 | 对照矩阵 |
|---|---|
| 方法 | 数据库最佳、直接 MPB 搜索、静态代理仅末尾复核、反馈校正无加密、完整方法 |
| 组件 | 反馈校正 × 带边加密的 2×2；各组最终审查一致 |
| 鲁棒性 | 同预算名义目标 vs 共同扰动目标；未见扰动独立审查 |
| 模型 | GL / TFNO / ConvNeXt 使用同目标、初值、搜索器与预算 |
| 表示/初始化 | 固定低维任务与 Fourier 扩展；数据库检索热启动与随机合法初始化 |

主比较采用相同新增 CPU 核时上限与 GPU 时上限，另报告随预算变化的最优真实裕量曲线、达到目标的成本和端到端墙钟。按目标/种子配对统计，bootstrap 以目标为重采样单位，不能把同一轨迹多个候选当独立样本。旧模型预训练成本单列，同时报告新增设计成本和包含预训练的摊销口径。

Slurm 试验可使用严格配对入口从逐任务原始账单复算核时和卡时；每个目标与种子必须有完整账本，未结算、超预算和跨试验重复分配不能进入该比较。该检查不自动证明调度记录真实性、是否不可重排或所有工作均已记账；WSL 复核和预训练等排除成本仍须单列。

图件包括：真实最优裕量随预算曲线、粗/密 k 带边差异、名义/刻蚀共同频段、代理与真实收益散点、代表成功与失败结构。候选清单和原始谱在 run 中，结果页只回答比较、认识、下一决定与证据位置。

终态区分 planned、implemented、smoke_pass、pilot_pass、formal_completed、partial、blocked；physically_verified 只在规定 WSL 复核及对应数值门通过后针对有限样本使用。否定或混合结果同样可以结束一个阶段，不自动扩种子、修改阈值或挑选案例。
