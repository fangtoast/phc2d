# 可微物理反馈逆向研究路线

**新逆向研究以冻结 Global–Local 的设计梯度和真实 MPB 反馈为方法核心，以制造扰动下的目标共同带隙为最终验证场景。** 先验证梯度，再验证反馈校正，最后研究鲁棒性。本路线取代旧计划中“先以无梯度搜索贯通整条研究”的默认次序；旧实验及其结果保持各自身份。

本文为 Draft 研究协议入口。本次完成思路整理、历史封存和协议设计；新算法尚未实现或运行。研究方向已按作者要求调整，模型文件、数值阈值和计算额度的执行冻结仍待完成。

## 要回答的科学问题

如何用可微神经算子提供的结构梯度引导二维光子晶体目标带隙设计，并用高保真求解器的观测校正代理误差和优化轨迹，最终找到在指定制造扰动下仍覆盖目标频率的结构？

| 递进命题 | 核心证据 | 反例或失败如何解释 |
|---|---|---|
| G：梯度有效 | 参数空间 AD–FD 一致；沿代理梯度更新的硬几何有 MPB 收益；与随机方向、DE 公平比较 | 内部差分通过而 MPB 不改善，说明计算图正确仍不足以支持设计梯度有效 |
| P：物理反馈有效 | 同预算反馈组改善真实裕量；残差在后续未用于拟合的观测上改善带边或方向 | 只有接受/拒绝收益时，贡献归于轨迹控制；不能宣称残差改善梯度 |
| R：鲁棒设计有效 | 名义、过刻蚀、欠刻蚀的共同目标裕量改善，并通过独立数值复核 | 三场景各有任意带隙不足以支持目标共同带隙；有限场景不代表整个扰动区间 |

G、P、R 分别验证。自动微分、局部回归、信赖域和最坏情形目标是组成技术；它们的存在不构成新颖性或协同收益的证据。

方法工作名暂用 **物理反馈引导的可微神经算子逆向优化（PF-DNO）**。附件中的 DPINO、Physics-Corrected Differentiable 等名称保留为备选；尚未完成重名和相关工作检索，不写“首次提出”。

## 第一版方法选择

| 项目 | 当前路线选择 | 执行时还需冻结 |
|---|---|---|
| 任务 | TE、B4–B5、归一化目标频率 $a/\lambda=0.57$ | 材料、晶格、k 坐标和频率单位身份 |
| 代理 | 首选固定 0.5/0.5 融合、周期局部分支 3×3 的 Global–Local；骨干冻结 | K5 Binary 的具体 seed、checkpoint、factory、架构指纹、normalizer 和原输入参考 |
| 几何 | Fourier 标准化潜场、Sigmoid 松弛、最终硬阈值；先两个参数 | 第一实模态余弦系数与阈值的索引、范围、归一化网格和输入栅格合同 |
| 优化 | 投影 Adam；DE、随机搜索和有限差分方向作对照 | 学习率、步数、温度及目标平滑参数；L-BFGS 后续比较 |
| 反馈 | 轨迹接受/拒绝与局部仿射带边残差分开开关 | 残差样本范围、正则强度、软硬桥接及信赖半径策略 |
| 鲁棒性 | 名义与两个确定性周期边界偏移场景 | 偏移符号、材料语义、幅度与未见扰动测试清单 |
| 扩展 | 多初值，随后考察 $d=4,8,16$ 和多个目标频率 | 独立来源、可用低阶模态数量、样本量与预算 |

先冻结几何映射、Adam、仿射残差、三确定性场景这四项方法选择。GP、深残差网络、大规模像素优化和概率制造模型均在相应证据显示需要后另立版本。

## 与现有项目是否衔接

可以衔接。已有正向权重恢复、输入梯度审计、Fourier 参数编辑、周期偏移、MPB 带边加密、局部带边回归和反馈状态机。当前主要缺口是**参数化几何到输入的可微路径、可微残差求值及真实 checkpoint 上的梯度优化证据**，详见[模块复用](模块复用与实施.md)。

须保留一个模型差异：[EXP-INV-010 参数](https://github.com/fangtoast/phc2d/blob/master/configs/research/exp_inv_010_prefrozen_exclusion_development.yaml)与[旧 011 参数](https://github.com/fangtoast/phc2d/blob/master/configs/research/exp_inv_011_nominal_feedback_pilot.yaml)绑定的是 `global_local_channel_gate_v1`。门控 seed 1 的 hash 不能作为固定等权 3×3 模型身份；旧选择收益也不转移给新主模型。若先沿用门控模型调通接口，须单列开发分支，再对固定融合模型重做相同验证。

已有 [EXP-INV-010](https://github.com/fangtoast/phc2d/blob/master/experiments/research/EXP-INV-010-事前排除目标搜索.md)仅支持其有限开发合同下的代理选择。本地原始判定 `runs/20261102/EXP-INV-010_202611020411/source_generation_authorized/development_decision.json`为 `development_criterion_met`，同时保留历史排除不完整、`p2_gate: not_evaluated` 和非 P5 边界。它不能证明参数梯度、物理反馈校正或新路线的成功率。
