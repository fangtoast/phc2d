# 鲁棒逆向资源与迭代

**GPU 任务使用双平台，CPU/MPB 任务使用 M9；每轮以证据决定下一轮，不预先承诺计算结果。** 返回[总计划](README.md)。用户的 N4/N5 暂对应当前作业接口的 N40/N56，执行前核对平台 profile；历史 N50 记录不能据此视为现役 N5。本文未读取实时队列，也不承诺当前容量。

## 平台职责

| 位置 | 负责 | 既有接入点与边界 |
|---|---|---|
| Windows | 编辑、静态检查、报告阅读 | 不作为正式工程/物理验收 |
| WSL Ubuntu / meep_env | 单元/集成/回归、单例 MPB、最终跨环境复核 | 不代替 M9 批量资源安排 |
| N40（N4 暂定） | 冻结代理推理、多起点搜索、必要的校准/微调 | 复用 `jobs/paracloud_official_comparison.sh` 的部署模式，算法不写入 launcher |
| N56（N5 暂定） | 独立模型/seed/目标分片、GPU 重复性检查 | 同源码与输入身份；不做跨站点 DDP |
| M9 | CPU 几何审计、MPB 标签、k 带边加密、resolution 和扰动复算 | 复用 physics campaign 控制面和 `jobs/bingxing_submit_exp_dat_008.sh` 的提交模式，不直接复用其已冻结 case 数 |

两个 GPU 平台按完整目标/模型/seed 分片，不能让同一 trial 被迁移重跑后当作独立重复。CPU 优化器若等待 GPU 代理，置于同一个经调度工作进程内；M9 只接收物理任务。候选/结果异步交接，GPU 不长期占卡空等 MPB；采用微批搜索和状态保存。

## 从测量得到预算

| 步骤 | 首轮规模建议 | 下一规模依据 |
|---|---|---|
| 本地合同 | 最小合成案例与可恢复真实样本 | 接口正确性 |
| GPU admission | 每平台一个独立单卡任务，测 batch、显存、吞吐与恢复 | 实测显存和吞吐，不沿用旧 campaign 多卡额度 |
| M9 admission | 一个结构、最小物理合同，测 CPU/内存/线程 | 串行/线程或 MPI 实测，避免嵌套超配 |
| P2 审计 | 12 锚点及冻结邻域候选，名义后再扰动 | 候选数 × 扰动数 × k/resolution 层级成本 |
| P3/P4 pilot | 小目标集，每 trial 设 CPU/GPU/时间硬预算 | 方差、成功率、失败机制与成本收益 |
| P5 正式 | 三 seed 与预冻结目标矩阵 | pilot 支持的样本量及阶段资源额度 |

资源清单必须给出 GPU 型号/数量、并发、CPU 数、内存、墙钟上限、总核时/卡时、求解数量上限、重试策略和停止门；没有单例计时不推算总天数。名义 $C$ 个候选、$D$ 个扰动、各自 $K$ 个 k 与多档 resolution 的成本逐项测量，不把 $C$ 直接当真实 solver 次数。

新远端或昂贵阶段按冻结清单获得明确执行授权；本次用户请求授权的是长期计划整理，未提交计算。后续已明确授权的阶段可在预算内连续完成测试、修复和复核，不反复请求相同授权；新增物理阶段、预算扩大、资源变更或自动重试须符合项目现行规则。旧正向作业授权和卡数不继承。

## 每轮迭代合同

1. 选一个失败机制或假设，固定本轮主层级和比较对象。
2. 改代码并运行窄测试、合同回归；WSL 通过后固化代码 commit。
3. 冻结配置、输入与 checkpoint hash，先 admission，再阶段计算。
4. N40/N56 搜索，M9 求解；检查 shard 完整性和预算账本。
5. 汇总真实结果、数值未决和负结果，做固定 WSL 跨环境复核。
6. 根据 gate 接受、修复、停止或登记下一版本；结论改变才更新结果页和项目状态。

物理反馈时区分优化过程中允许使用的新观测与最终审查数据。审查失败后若修复，建立新版本和新的独立审查批，不覆盖旧失败。代码变化先重跑受影响合同和小批，再决定是否需要重做大实验。

## 监控、停止和交付

监控默认只读：作业状态、日志末尾、完成/失败数、资源消耗、数据/checkpoint/shard hash。无自动取消、重试、重提或改资源。登录节点不运行求解或训练；有授权的 smoke 也必须使用相应资源调度合同。

停止条件包含预算耗尽、连续物理无改进、表示合同失败、数值不收敛或任务缺失。阈值在各阶段 config 中预注册。每轮交付标准 run、可重启状态、预算摘要、失败归因，以及在结论或 gate 改变时的一份 Draft 结果页；不生成普通命令流水账报告。

最终证据区分 GPU surrogate、M9 cluster solver 和 WSL acceptance。M9 求解完成先标记 cluster_generated_pending_wsl_acceptance；跨环境复核样本、容差和数值门在计算前冻结。WSL 复核通过不能外推为整个连续设计空间或实际加工器件已经验证。
