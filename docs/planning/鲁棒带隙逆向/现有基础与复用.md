# 可微逆向研究的现有基础与复用

**当前研究继续使用正向训练、结构表示、物理求解和已有实验积累。** 历史方案的“被取代”只描述整套方案及其执行顺序；其中可复用的组件和事实按本页接入当前路线。返回[研究入口](README.md)。本页是 Draft 规划和代码盘点，不是新算法的验收结果。

## 数据与结构：用现有训练合同，而非重造数据集

| 基础 | 当前能做什么 | 本研究怎样使用 |
|---|---|---|
| Fourier 与 full-cell spec | 周期 Fourier 场、材料语义、结构身份、二值与 graded 表示 | 开发从已记录的来源 spec 出发，先调整一个系数和阈值；结构身份和其他模态保留 |
| 主栅格与模型输入 | 已有直接采样和主栅格 block mean 等不同表示 | 锁定 checkpoint 对应输入字段和栅格化版本；原存输入与重建输入逐项核对，不默认不同表示等价 |
| 潜场标准化 | 硬结构编辑后按记录的 normalization 网格重算均值和总体标准差 | 可微版本同样重算并保留参数导数；软表示、硬几何、模型输入和物理栅格分开记录 |
| 周期连通与边界偏移 | 周期连通诊断与基于栅格的材料膨胀/腐蚀 | 名义 MVP 先核对几何；鲁棒阶段将硬偏移与可微近似比较，偏移小于一个像素可能无变化 |
| 数据/来源身份 | 既有 train/validation/test、结构及哈希记录 | 记录 checkpoint 与来源数据、split 和排除范围；来源 8、491、348 已观察，不能作为独立测试 |

`src/phc2d/data/` 和 `src/phc2d/inverse/` 是并列模块。前者现有文件负责结构定义、Fourier 场与栅格合同，后者使用这些能力进行候选编辑与搜索。这里复用 `data/` 不意味着重新生成整个数据集，也不要求把数据集复制进 inverse。

## 正向模型：纯代理冻结，物理适配单列

首选已有 fixed-mean、周期局部分支 3×3 的 `global_local_band_operator_v1`，冻结权重并从物理频率输出构造目标。该版本的具体 K5 Binary checkpoint、seed、factory、架构参数、归一化、数据及参考预测仍须核验；不得用代码默认核尺寸或另一个版本的 hash 代替。EXP-INV-010 的 `global_local_channel_gate_v1` 是不同身份。

现有 `FrozenBandAdapter.predict_tensor` 保留输入梯度并冻结模型参数，可作为接口起点；它只保证调用合同，不证明软几何上的预测和参数梯度有效。现有普通单例缓存拒绝需要梯度的输入；可微路径须独立计费并保持计算图。

| 决定节点 | 行动 |
|---|---|
| 原始输入无法复现 | 核查结构、栅格、材料、normalizer、k 与 checkpoint；未解决前不开始优化 |
| 软输入与硬输入差异大 | 检查温度、主栅格、二值投影、目标平滑和开发批同 k MPB 诊断 |
| 冻结代理的方向或预测仍不可靠 | 先完成已锁定批的诊断；确需扩充数据或微调时另立数据/正向实验、冻结成本和新独立测试 |
| 冻结代理可用 | 交付纯代理基线，再按 WP3 比较少量 MPB 代理适配收益；基线权重保留 |

训练源模型和代理逆向优化是不同操作：前者更新网络权重，后者对每个设计任务更新结构参数。已有 graded 数据不是自动等价于本研究的软边界分布；是否适合必须按材料、温度与数据来源核对。

## 搜索、物理与证据能力

| 项目 | 当前项目基础 | 纯代理方案中的边界 |
|---|---|---|
| 代理与搜索 | 冻结预测、输入梯度诊断、DE、硬候选构造和筛选 | 作为主设计的计算起点；尚需贯通 Fourier 参数梯度、Adam、多初值和选择锁 |
| 目标与鲁棒 | 已有精确共同带隙/裕量计算与周期几何检查 | NumPy 评价可作对照；可微目标和扰动近似需要新合同及对应测试 |
| 数值求解 | 现有 MPB 求解、带边加密、resolution、批量候选及跨环境复核接口 | 对纯代理结果，只在候选和选择规则锁定后评价；同 k 与密 k 分列 |
| 运行与成本 | run 记录、候选/求解清单、资源账本、分片与恢复组件 | 核对合同、账单和锁身份，记录实际 solver 任务、失败和复核开销；组件存在不等于整个新流程已运行 |
| 反馈组件 | 局部残差、信赖域和物理反馈状态机 | 直接作为 WP3 的复用起点，补可微求值及批次编排；纯代理基线仍独立保存 |

设计器先锁定 Top-1、候选/轨迹、模型预测和身份；复核器读取同一锁，比较该结构的 GL 与 MPB 谱、目标裕量和制造共同区间。多初值仍由 GL 决定排名。MPB 若用于事后挑选 Top-M，另称带物理选型的对照并单独计成本。

## 旧实验与数值经验

[EXP-INV-010](https://github.com/fangtoast/phc2d/blob/master/experiments/research/EXP-INV-010-事前排除目标搜索.md) 已在有限开发合同下形成门控 GL 的选候选与真实求解证据，说明原有结构、代理和求解组件有复用价值；其历史数据排除范围并不完整，也不能证明新主模型的参数梯度。来源生成和数值判定继续保留原合同。

[EXP-PHY-007](../../results/field-physics/EXP-PHY-007-validation带隙标签门.md) 的 validation 数值门没有通过，说明带边与空间分辨率需要单独审查。81 点代理排序、同 k 谱比较和密 k/空间分辨率检查各回答不同问题；有限求解点和有限扰动不构成连续 BZ 或实际制造良率的保证。

[历史方案](历史方案/旧版总计划.md)可用于理解这些接口和决策从何而来；若旧页面写的“当前实现”与源码不一致，以当前源码、配置和 run 为准。反馈优先或无梯度优先的旧阶段、旧资源数值及“先通过旧 P2 才能执行新研究”的推断不自动约束本路线；原 P2 失败与 P5 未完成仍按旧合同保留。

## 如何继续

1. [EXP-INV-012](https://github.com/fangtoast/phc2d/blob/master/experiments/research/EXP-INV-012-梯度链条开发验证.md)：先核对来源 8、固定融合模型和输入身份；实现软几何及参数梯度，完成预锁定候选的末尾 MPB 诊断。
2. 按[实验与复核](实验与复核.md)扩大纯代理算法与多来源比较，保持同 k 误差、物理成功率和总成本分列。
3. 按[纯代理方法](纯代理方法.md)加入名义与周期制造扰动的共同裕量；最后用相同求解标准对所有场景复核。
4. 按[代理校正与微调](代理校正与微调.md)完成 MPB 反馈适配，分别评价新观测误差、设计收益与成本；不改写纯代理锁定输出。

具体执行次序为纯代理、物理适配、制造鲁棒及独立比较，见[推进与交付](推进与交付.md)。

实现边界、所需测试、资源和产物见[实施与资源](实施与资源.md)。阶段号和状态以对应实验协议、实际配置及 run 为准。
