# 可微代理与物理反馈实验及复核

**主实验依次检验梯度、纯代理设计、MPB 代理适配、制造鲁棒与总成本。** 纯代理的物理结果在设计锁定后揭示，反馈路线的优化观测按外层批次使用。返回[总方案](研究总方案.md)。012 已提交平台预检，正式设计和物理批次尚未执行；013–016 仍为 Draft/预留。具体样本量与预算在准入前冻结。

## 最重要的主对照

| 路线 | 优化与选型 | MPB 使用 | 主要终点 |
|---|---|---|---|
| A：纯代理基线 | 冻结 GL 完成参数优化、制造评分、硬几何排序和 Top-1 锁定 | 仅在锁定后复核，不返回设计器 | 锁定 Top-1 真实目标裕量、成功率及总时间 |
| B：物理反馈方法 | 相同 GL 与几何基础，以少量批次 MPB 观测校正/微调代理后继续设计 | 在线成本全部计入，最终同标准复核 | 额外质量收益与额外成本 |

先完成 A，再完整实施 B 的比较；两者都是本研究交付。B 没有可重复收益时如实说明适用条件，后续成果可采用 A 或改进版本。MPB 反馈频率、每轮批量和总额按阶段配置，参数细节见[代理校正与微调](代理校正与微调.md)。

## 纯代理选择锁与最终审查

以下规则用于纯代理基线；反馈版本只允许读取对应轮次已获得的优化观测，所有版本的最终审查均不回流优化。

1. 在揭示物理结果前锁定初始化、优化种子、所有轨迹、合法性筛选、候选排名与提交顺序。
2. 首版每 trial 只提交 Top-1；不因其失败改提交 Top-2。预注册批量候选时，逐排名报告，原 Top-1 指标始终保留。
3. 中间轨迹若需 MPB 曲线，必须预先冻结诊断节点，先完成整条设计轨迹和最终选择，再批量复核；不能据曲线停止、续跑或改选。
4. 同 k 误差诊断、物理 FD 和数值重复可以在末尾计算，费用单列。物理 FD 只解释方向，不生成主方法的下一候选。
5. 复核后的修正另立开发版本与新的独立批；旧失败保留。求解未收敛、超时和未知状态不解释为已知无带隙。

## 能带差异与设计成功分开

对同一硬结构、材料输入、k 坐标、极化、单位和带序，计算 GL 与 MPB 的完整谱 MRE/MAE/RMSE、B4/B5 带边误差、目标裕量误差及预测成功—真实成功混淆情况。同时记录软输入与硬输入预测差，判断投影是否破坏设计。

最终带隙审查另做密 k/自适应带边及空间分辨率检查；其相对于 81 点的差异标为采样/求解离散影响，不并入同 k 模型误差。固定 81 点模型不提供连续 BZ 极值保证。

| 层次 | 求解与结论 |
|---|---|
| 代理选择 | 81 固定 k、10 条带，使用精确有符号目标裕量；代理成功不等于物理成功 |
| 同 k 复核 | 相同硬结构上的逐 k 谱差异；不等于连续带隙认证 |
| 最终数值审查 | 密 k/带边加密、不同分辨率、制造场景与预定 WSL Ubuntu/meep_env 对照；仅支持对应有限合同 |

目标 $\nu_\star$ 位于真实共同区间时精确 $J_P>0$；最小工程宽度/裕量若需要，须在正式测试前冻结。名义及每个扰动均重新求解，不能由名义结果代替制造复核。已有参考结构可作质量对照，不能当逆问题唯一真值。

## 成本与公平性

分别报告设计计算时间（参数化、GL forward/backward、重启、筛选）、在线 MPB 时间（纯代理为零，反馈适配逐项计入）、最终复核时间、端到端总时间及排队时间。物理候选数、扰动数、k 加密任务、分辨率任务、失败/重试、分配核时、卡时逐项记账。预训练成本单列并给摊销口径。

两种比较同时给出：相同 MPB 额度和代理计算上限下的真实质量；相同总资源上限下的成功率、目标质量和质量—成本曲线。纯代理省下的在线预算不强制转成额外 MPB 节点。统一的是最终验收标准与已声明的资源约束，不要求 A/B 花同样多物理调用。候选数量相同不代表核时相同；梯度反传、FD 和 L-BFGS closure 均计成本。

除随机搜索和 DE 外，正式范围在资源允许时加入同来源数据库候选、低维直接 MPB 搜索与其他冻结正向模型的公平对照：保持目标、参数空间、材料约束、初始来源及最终审查一致。直接 MPB 搜索的全部求解成本计入设计阶段；如果没有可比物理梯度或拓扑优化基线，不宣称全面优于这些方法。模型对照先固定身份和数据合同，不依据独立测试排名重新挑选主模型。

首次成功成本采用实际可确认成功的物理完成时刻；纯代理迭代期间不能凭 GL 分数标成“首次真实成功”。离线诊断中的 best-so-far 曲线只描述预选节点，不代表主方法曾获得这些观测并据此决策。

## 样本、统计和负结果

train/validation/test、模型 seed 与优化 seed 独立记录；开发、在线反馈训练观测和最终独立审查分开。碰撞和独立性仅按已认证历史覆盖声明；hash 无碰撞不等于全部历史独立。

以预注册来源/目标为统计单位，先在来源内汇总优化 seed，再给配对均值、中位数、标准差和区间。轨迹候选不当独立重复。全注册成功率将失败、超时和未决计为未成功并分列；另给数值可判定覆盖。连续裕量缺失不填零；无成功时 cost-per-success 未定义。

## 梯度与物理反馈的协同

| 组别 | 提案策略 G | 代理物理适配 P | 观测使用 |
|---|---|---|---|
| A | DE 黑盒 | 无 | 先完成 GL 轨迹与选择，后评价 |
| B | Adam 梯度 | 无 | 同 A |
| C | DE 黑盒 | 有，首版 SR 仿射校正与轨迹政策 | 已完成外层观测进入下一轮 |
| D | Adam 梯度 | 有，与 C 相同的 SR 和轨迹政策 | 同 C |

四组共用参数化、平滑目标、约束、初始化分布与最终审查。使用相同物理预算上限和真实成本口径，纯代理不为凑齐调用数浪费预算；同时给等总成本结果。交互项 $(Y_D-Y_B)-(Y_C-Y_A)$ 先在来源内汇总种子再按独立来源重采样，报告完整配对覆盖及区间。若改用 SF 权重微调，另列因子版本，不能混入 SR 结果。

另以原 GL、原 GL 加接受/拒绝、GL 加残差及同一接受/拒绝政策分离轨迹控制和模型校正。残差对新观测的误差在加入该点拟合前评价；SF 使用同样的样本与成本账，另记录训练/原验证误差和微调后设计。详细适配数据、版本和软硬桥接见[代理校正与微调](代理校正与微调.md)。
