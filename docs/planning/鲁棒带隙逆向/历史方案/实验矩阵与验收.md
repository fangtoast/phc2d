## 梯度证据分三层

| 层次 | 必要检查 | 支持的判断 |
|---|---|---|
| 计算图 | 同一个软函数的参数 AD 与多步长 FD；冻结权重；normalizer、均值/标准差及输入缩放全程可微 | 梯度实现正确 |
| 物理方向 | 合法硬几何的 $+g,-g$、匹配随机方向、MPB FD 方向；多半径及数值噪声检查 | 局部方向对真实求解是否有用 |
| 优化收益 | 相同初始库、约束、重启数和资源上限下，梯度方法与 DE/随机/直接 MPB 搜索比较 | 指定任务范围内的质量和效率 |

013 中 AD–FD 基线使用代理 FD；MPB FD 另计高保真成本。先保留原始精确目标优化作控制，再比较平滑目标和 continuation。不同维度都须明确模态列表；高阶固定、低阶可变，不能为满足维度数字释放原合同外的高频模态。两参数结果不自动外推到高维拓扑优化。

## G×P 的 2×2 协同实验

G 表示梯度策略，P 表示在线物理反馈包（局部残差和信赖域）。四组使用相同软几何、平滑目标、硬投影、约束和初始化分布。DE 也在同一个软目标上搜索；历史硬几何 DE 作为另列的实用基线，避免把几何差异误归于梯度。

| 组别 | G | P | 提案与观测使用 |
|---|---|---|---|
| A | 无 | 无 | DE/黑盒静态代理；预定节点的 MPB 结果封存，不能影响后续提案 |
| B | 有 | 无 | Adam 静态代理；使用相同封存规则 |
| C | 无 | 有 | DE/黑盒 + 在线 MPB + 同版本残差/信赖域 |
| D | 有 | 有 | Adam + 在线 MPB + 同版本残差/信赖域 |

P=无表示不使用优化中物理结果，四组仍有同额度的物理评价和相同最终验收。A/B 在物理结果揭示前锁定整条候选轨迹与节点；C/D 每轮只读取已经返回的观测。若在比较中只让 C/D 拟合残差，P 的含义始终是完整反馈包，不能把交互项解释成纯粹的接受/拒绝收益。

以每个来源、目标和 seed 配对的真实最优裕量 $Y$ 计算

$$
\Delta_{interaction}=(Y_D-Y_B)-(Y_C-Y_A).
$$

先在来源/目标内汇总优化 seed，再以独立来源/目标为重采样单位报告交互项与区间。正点估计不足以证明协同；只有在预冻结指标、预算、完整配对及不确定性判据下才讨论额外收益。交互效应依赖该指标和预算，不代表普遍机制。

数值失败的连续裕量记为缺失，不填零制造交互。报告全注册目标成功率和四组完整配对覆盖；完整案例交互只能作条件性结果，须说明选择偏倚。正式协议若需要全目标连续效用，失败惩罚须预先定义，不能看完结果后决定。

## 分离轨迹反馈与模型校正

014 的 G=有支路至少包含以下三组；黑盒反馈组使用相同的对应配置作关键复核：

| 对照 | 残差 | 轨迹控制 | 回答的问题 |
|---|---|---|---|
| 静态梯度 | 无 | 固定范围，末尾审查 | 单靠原代理可达到什么水平 |
| 接受/拒绝梯度 | 无 | MPB 信赖域 | 真实结果控制轨迹的收益 |
| 完整校正梯度 | 仿射双带边 | 同一信赖域政策 | 在相同轨迹政策下，校正是否有额外收益 |

残差的预测误差在每个新候选结果到达、尚未加入拟合前计算；不能拿拟合样本残差下降充当有效性。另测校正前后 MPB FD 方向一致性、边界 k 切换与投影落差。常数校正、仿射校正为首批独立消融；GP、全谱校正、直接 J 校正是后续可选实验，不随主矩阵自动扩张。

所有组的最终带边加密和分辨率审查相同。若研究在线加密是否必要，另做反馈×在线加密消融；不能降低某组最终审查精度来制造反馈收益。

## 鲁棒比较与数据隔离

015 使用同预算的名义、三场景平均和三场景最坏裕量目标。三组都评估名义及两个真实几何偏移的共同带隙，另报告名义性能损失。$d/a$ 首版可从旧开发值 $1/512$ 作为待校准候选，但在网格及工艺假设核对前不称已冻结物理公差，也不跨用旧 $1/256$ 结果。

| 数据角色 | 使用规则 |
|---|---|
| Forward train/validation/test | 保留原版本、split 和 hash；不得将正向 test 用于软几何校准或逆向超参开发 |
| 逆向开发来源 | 可用于温度、步长、残差和预算校准；记录与所有可认证历史数据的碰撞覆盖 |
| 在线 MPB 观测 | 只在对应算法轮次后可见；纳入设计预算和残差训练来源 |
| 最终逆向测试 | 来源与目标清单在方法冻结后生成；独立性按已核对的历史范围声明 |
| 未见扰动与高精度审查 | 不参与优化与调参；若失败后修复，登记新版本与新独立审查批 |

变换对称、近邻及重复几何应按实际能认证的身份处理。精确 hash 无碰撞不等于连续几何独立或远端历史穷尽。

## 预算与统计口径

每个 trial 同时设置物理尝试数、分配 CPU 核时、GPU 卡时和墙钟上限。相同候选次数不等于相同 MPB 工作量：每个扰动、k 加密层、分辨率升级和复核都分别记账。求解失败、重试和残差拟合都计成本；公共初值或缓存若共享，按预注册分摊和缓存策略处理，不能一组免费而另一组全价。

采用固定资源上限下的真实最佳裕量曲线，并报告达到同质量的成本。梯度法的 forward/backward、L-BFGS closure、FD 扰动、重启、硬重预测都计入调用及耗时；不只按一次“目标函数调用”给梯度法免费反传。端到端时间区分计算与排队，预训练成本单列并给摊销口径。

| 指标组 | 必报字段 |
|---|---|
| 设计质量 | 名义/最坏真实目标裕量、共同宽度、全注册目标成功率、数值可判定覆盖、名义代价 |
| 代理一致性 | 原始/校正带边与裕量误差，软硬投影差，平滑偏差，带序异常 |
| 梯度 | AD–FD 相对误差/余弦/步长稳定性，MPB 方向增益，零/噪声/同栅格案例 |
| 成本 | 物理候选与求解任务数、核时、卡时、实际调用、首次达标成本、墙钟和失败成本 |
| 统计 | 独立来源数、优化 seed、模型 seed、均值/标准差/中位数/区间与完整配对覆盖 |

模型 seed 与优化 seed 分列。多个初值和轨迹上的候选不是独立重复；相同物理候选被多个模型共享时保持来源配对。正式样本量由开发方差及预算确定，另行冻结，不把来源 8 或旧 12 来源审计直接充当最终 test。

全注册成功率中超时、未完成、数值未决和预算耗尽均计为未成功并分列原因；不能把未知解释为已知无带隙。无成功样本时 cost-per-success 未定义，报告消耗与零成功，不填一个虚构平均成本。

## 物理证据与停止条件

| 层次 | 验收与允许表述 |
|---|---|
| 代理 | 81 固定 k 的采样裕量；仅用于搜索和筛选 |
| 求解器反馈 | 每个硬几何在冻结带边加密和空间分辨率合同下有效；可比较相同精度的真实增益 |
| 最终数值验收 | 独立密 k/更高分辨率、全部制造场景、预选 WSL Ubuntu/meep_env 复核；范围明确的物理数值证据 |

M9 产物完成先记录 cluster 证据，不能直接标为项目 WSL 验收。跨环境差异、空间收敛和 k 加密是三个独立检查；逐谱对得上不表示已覆盖连续 BZ。最小成功条件是通过几何/数值门后，精确目标裕量大于零；若论文要求工程最小裕量或最小宽度，须在独立测试前新增冻结要求。

梯度链错误先修复实现；软硬落差或方向失真先校准表示；反馈无收益保留负结果并检查误差来源；鲁棒目标失效保留名义代价。未完成前置不扩展对应阶段；达到额度或出现无法核验的身份/数值条件则停止受影响计算，不修改原评价标准补正例。
