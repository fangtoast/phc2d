# 逆向研究实施与资源

**先实现可微几何和纯代理基线，再接入 MPB 批次观测与可微代理适配，统一完成独立复核。** 工作包与交付见[推进与交付](推进与交付.md)，适配方法见[代理校正与微调](代理校正与微调.md)。 返回[总方案](研究总方案.md)。本页是工程与资源提案，尚无新算法运行结果。

## 最近可复用模块

| 当前位置 | 主方法复用及缺口 |
|---|---|
| `data/full_cell_fourier.py`、`full_cell_spec.py`、`full_cell_raster.py` | Fourier、总体标准差归一化、材料语义和主栅格 block mean；补同语义 tensor 路径与参数 FD |
| `inverse/fourier_design.py`、`fourier_search.py` | 可序列化硬几何和 DE 基线；增补独立梯度提案策略 |
| `inverse/frozen_band_adapter.py` | 冻结权重并保留输入梯度，反归一化物理谱；绑定具体固定融合 3×3 checkpoint |
| 同文件 `SingleSampleBudgetedPredictor` | 当前拒绝 requires_grad 输入并 detach 缓存；只用于普通评分，梯度路径另计 forward/backward |
| `inverse/input_gradient_audit.py`、`candidate_gradient_audit.py` | 输入方向诊断可复用；它们不等于 Fourier 参数 Adam，需要整条几何链验证 |
| `inverse/morphology.py`、`data/periodic_geometry.py` | 周期偏移与几何检查；鲁棒阶段补可微近似并核对硬极限 |
| `inverse/robust_gap.py` | 计算多场景共同带隙的现有 NumPy 实现；用于硬候选结果核对，不能直接当可微优化目标 |
| `replay/gap_refinement.py`、`inverse/feedback_evaluator.py` | 复用求解/带边数值运算；主方法只在选择锁定后调用评价接口，不调用反馈决策 |
| `inverse/resource_ledger.py`、`design_metrics.py` | 成本与配对统计；追加设计/在线/复核三个成本阶段及选择锁身份 |
| `inverse/packed_refine.py` 及对应作业包装 | 可作为锁定候选的批量物理复核起点；具体 manifest、资源合同、输出完整性和新提交范围须重新核验 |
| `local_edge_correction.py`、`trust_region.py`、反馈状态/调度组件 | WP3 首版 SR 的复用基础；拟合保持 NumPy，补 tensor 求值、模型版本和同轮预测增益；不重复开发通用控制平台 |
| `forward/` 下现有 GL 训练与 campaign 接口 | SF 权重微调的接入起点，须补 MPB 适配数据、可训练参数与新 checkpoint 合同；不直接调用逆向生成器训练器 |

当前源码入口为 [src/phc2d](https://github.com/fangtoast/phc2d/tree/master/src/phc2d)。复用前按调用方和现有测试确认合同，代码存在不表示本版验收通过。旧 010/011 使用门控模型且曾有数据身份绑定缺口；不沿用其 hash 冒充新主模型，也不因文档改版宣称缺口修复。

`data/` 是与 `inverse/` 并列的现有结构与输入表示模块，并不要求重新生成训练集。名义设计需要 Fourier 结构及与训练一致的输入；跨边界连通性用于硬结构检查，周期膨胀/腐蚀用于后续制造扰动。它们各自提供数据或几何操作，不承担优化调度。现有周期偏移是有限栅格近似；小于一个栅格间距的非零偏移可能不改变栅格，不能视为已解析的制造误差。

## 接口和验证边界

| 责任 | 输入与输出 | 接入检查 |
|---|---|---|
| 结构表示 | 源结构及可变参数 → 软材料 tensor、硬结构 spec 与栅格 | 与现有 Fourier、标准化、材料相及栅格化版本一致；参数变化时保留均值/标准差导数 |
| 冻结预测 | 模型合同化输入 → 反归一化频谱；需要时保留输入梯度 | 原输入和输出参考、checkpoint hash、factory、normalizer 与 k 身份匹配 |
| 纯代理搜索 | 目标、初值、约束与冻结代理 → 全轨迹、硬几何预测与锁定选择 | 不接收 MPB 结果；记录无效、重复和未完成，不静默替换 |
| 代理适配 | 完成的 MPB 观测与代理版本 → 残差系数或新 checkpoint | 纯代理不接收此输入；反馈只使用当轮之前观测，温度/样本/权重版本可追溯 |
| 锁后复核 | 锁定 manifest、结构与求解配置 → 逐 k 频率、带边、数值状态 | 结构/模型/求解配置身份匹配；同 k 和加密 k、不同 resolution 的结果分开 |
| 预算与恢复 | 分阶段请求、结果及账单 → 消耗、状态、可恢复记录 | 单写者、未知提交状态先对账；缓存按几何、材料、k 与精度隔离 |

工程测试至少覆盖真实源结构零编辑重建、normalizer 往返、周期跨边界连接与偏移、参数 AD–FD、负裕量和空共同区间、硬几何重复及 Top-1 锁、求解失败与中断恢复。先运行受影响的单元/合同测试，再在 WSL `Ubuntu` 的 `meep_env` 执行适用回归；工程通过不等于物理成功。

## 实现阶段及责任

| 阶段 | 交付与最小测试 |
|---|---|
| I0 身份 | 源 spec、数据/模型/k/normalizer、参考输入与预测复现 |
| I1 几何与目标 | tensor Fourier、软/硬投影、精确及平滑目标；标准差导数、边界/负裕量/场景交集测试 |
| I2 纯代理设计 | Adam/DE/Random，共同约束、多起点、硬 GL 重评分；确定性 Top-1、去重及选择锁测试 |
| I3 独立复核 | 验证锁定结构与原始预测；同 k 谱比较、密 k/分辨率与 WSL 验收；结果不得返回设计器 |
| I4 物理反馈适配 | MPB 小批、tensor 仿射残差、必要轨迹控制；权重微调单列，检查导数/适配观测与新设计收益 |
| I5 鲁棒与独立来源 | 对原/适配代理的三场景目标、未见扰动与正式矩阵 |

workflow → inverse 领域操作 → data/models/physics/replay；CLI/jobs 为薄包装。设计器输出完整锁定包，评价器只读取它并输出谱与指标。纯代理接口不接受 MPB 成绩来生成下一候选；反馈编排显式读取优化观测并更新代理版本，最终审查不进入优化器。当前没有独立 `src/phc2d/workflows/` 目录，先扩展最近的已有编排服务；新 workflow 边界确有复用需求时再按项目架构引入。

不创建新顶层目录、不复制正向模型或 solver、不向超大 inverse/runner.py 堆循环；shape 从 metadata/spec 读取，torch/h5py/MPB 依旧可选或惰性导入。实施前选最小测试证明新合同，再在 WSL Ubuntu/meep_env 验收；具体测试只覆盖本次改变的合同，相同条件的已有有效证据直接引用。当前规划未实施新算法。

## 资源与停止

| 阶段 | 资源及费用 |
|---|---|
| 设计 | 适用本地设备或 N40/N56 做 GL forward/backward；记录卡时、墙钟、实际调用、缓存和重启 |
| 反馈适配 | M9 的批次 MPB 与本地/N40/N56 的残差拟合或权重训练；计入外层观测与更新费用 |
| 最终复核 | M9 求解锁定硬几何的同 k/密 k/多分辨率/场景；单列分配核时、内存、实际任务和失败 |
| 正式验收 | WSL Ubuntu/meep_env 的预注册跨环境复核；独立预算与数值门 |
| 编辑 | Windows 编辑与静态诊断，不作正式工程/物理验收 |

先完成来源 8 的有限 MVP，再按观测方差和求解实测冻结多来源规模。旧 011 的 12 次/100 核时及前版 012 的 63 组/150 核时均不再约束新版本。候选数、每组内部任务、核时/卡时、墙钟、并发、内存和重试权限须独立冻结，不根据历史平均秒数许诺速度。

本次仅授权文档整理，不提交计算。后续计算沿用确实覆盖该阶段的授权和资源上限；达到任一硬上限保留 partial。提交状态未知先对账，不自动重提。纯代理的末尾物理结果不触发同 trial 重选；反馈方法按自身额度和轮次继续优化，最终审查结果不回流。

## 产物、恢复与交付

标准 run 保存 `run.log`、`run.meta.json`、`config.resolved.yaml`、`results.json`、`metrics.json`、`history.csv`。目录采用 `runs/{yyyymmdd}/{experiment_id}_{YYYYMMDDHHmm}/`。

| 补充产物 | 合同 |
|---|---|
| 设计轨迹 | 参数、几何温度、平滑目标、原始完整预测、梯度与成本；软/硬分支分列 |
| selection lock | 所有起点/种子、合法与无效候选、硬 GL 排名、Top-1、几何/输入/谱/代码/模型/配置 hash、完成时刻 |
| 适配观测与版本 | 轮次、拟合前预测、软硬/温度版本、训练样本、残差系数或父/子 checkpoint、决定与更新费用 |
| 复核清单与结果 | 必须引用锁 hash；同 k 谱、加密谱、resolution、场景、数值门、原始失败与费用 |
| 指标 | 同 k 预测差异、真实成功、共同裕量、全注册分母、设计/在线/最终复核费用分列 |

恢复必须还原 optimizer、随机状态、阶段与锁；已锁定候选不可覆盖。缓存按材料、几何、模型、k 和求解精度区分；梯度路径不复用 detached 缓存。结果只写进 runs；科学结论或 gate 改变时再建立简短 Draft 结果页，链接原始证据。
