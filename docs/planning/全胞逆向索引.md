# 全胞逆向设计计划

当前非生成式路线从[Global–Local 纯代理研究](鲁棒带隙逆向/研究总方案.md)进入，先完成全程代理优化与锁后复核的基线，再用少量 MPB 观测校正/微调代理并继续设计，比较制造共同带隙与总成本。工作包见[推进与交付](鲁棒带隙逆向/推进与交付.md)，物理适配见[代理校正与微调](鲁棒带隙逆向/代理校正与微调.md)。具体定义见[方法协议](鲁棒带隙逆向/纯代理方法.md)、[实验矩阵与验收](鲁棒带隙逆向/实验与复核.md)和[模块复用与实施](鲁棒带隙逆向/实施与资源.md)。本次为 Draft 重规划，未执行新算法或物理实验。

[旧非生成式五页计划](鲁棒带隙逆向/历史方案/旧版总计划.md)已标记 superseded（总计划另存、其余原位），EXP-INV-011 保留原 DE 预检身份；新系列从 EXP-INV-012（MVP-INV-001）开始。008–010 的开发证据、P2 失败与 P5 未完成状态继续按原合同解释，不能被新编号覆盖。

生成式路线保留原[全胞解析参数逆向设计扩展计划](full_cell_forward_inverse_training/full_cell_inverse_design_extension_plan.md)及其合同。codec、CPU preflight、runner smoke 和波次 dry-run 已形成工程记录，但正式 45-run Stage-A、Stage-B surrogate 排序和 real-MPB replay 尚未准入。两条路线的准入与证据分别管理。

执行前必须重新核对：

- binary/graded 数据版本与 hash；
- forward ranker、normalization 和 checkpoint manifest；
- GPU admission、候选健康门与回放授权；
- surrogate 指标、replay 指标和物理失败的独立报告位置。

已有工程记录保留在[历史档案](../历史档案.md)，不能作为正式 inverse 结果。
