# 全胞逆向设计计划

当前权威入口是[全胞解析参数逆向设计扩展计划](full_cell_forward_inverse_training/full_cell_inverse_design_extension_plan.md)。codec、CPU preflight、runner smoke 和波次 dry-run 已形成工程记录，但正式 45-run Stage-A、Stage-B surrogate 排序和 real-MPB replay 尚未准入。

执行前必须重新核对：

- binary/graded 数据版本与 hash；
- forward ranker、normalization 和 checkpoint manifest；
- GPU admission、候选健康门与回放授权；
- surrogate 指标、replay 指标和物理失败的独立报告位置。

已有工程记录保留在[历史档案](../历史档案.md)，不能作为正式 inverse 结果。
