# 全模型论文测试数据对比表

## 阅读方式

这版报告按**数据集**组织，每张表只回答一个问题：同一个数据集上不同模型的表现如何。展示表只保留数据集、测试方式和模型指标，不显示实验编号。实验编号、checkpoint、seed、平台和哈希只保留在末尾的原始证据索引中。

所有数值均为 **Band1–10 MRE (%)**，数值越低越好；表中结果为三个 seed 汇总值在对应数据集/来源域上的平均。逐来源域、逐 seed、Band2–10、P95 和哈希仍见原始 CSV。

## 8. 完成和证据边界

- 原域有效结果：162 个 cell；另有 30 个 027 原域标签阻塞记录。
- 12K/24K：384 个 cell。
- K8/K10/K15：1,152 个 cell。
- 六域交叉：1,152 个 cell。
- 逐样本预测导出：2850 个。
- 物理真实性结论：当前不成立。
- K 域 scientific acceptance promotion：未启用。
- 测试结果未影响 checkpoint 选择。
