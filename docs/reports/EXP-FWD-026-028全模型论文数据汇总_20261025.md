# 全模型论文测试数据对比表

**截至2026-10-27：原测试表中的 Global–Local 是3×3版本。新增7×7的48项训练已完成，本次取得的是validation结果；两平台尚未发现正式7×7测试表，672个计划测试cell暂不计入完成数。**

GL 3×3 与 GL 7×7 使用同一注册模型名称，但属于不同卷积核配置。下方测试表以“待测”表示7×7缺少正式结果，不能把validation误差填入该位置。

## 阅读方式

这版报告按**数据集**组织，每张表只回答一个问题：同一个数据集上不同模型的表现如何。展示表只保留数据集、测试方式和模型指标，不显示实验编号。实验编号、checkpoint、seed、平台和哈希只保留在末尾的原始证据索引中。

所有误差数值均为 **Band1–10 MRE (%)**，越低越好。新增训练表使用validation，测试表使用冻结test；两类数值分别标明。“均值 ± 标准差”为三个seed的均值和样本标准差（ddof=1）；跨来源均值为等权平均，不是合并所有样本后的微平均，也不把来源差异作为seed标准差。

G-only及G-only cap没有局部卷积，属于新实验的控制组，其误差变化不能归因于7×7。cap是容量控制，不等同于只改变核尺寸的Full比较。

本次独立核查覆盖48个checkpoint及其phase300/终态哈希、完整epoch历史、有限validation指标；36个含局部分支的checkpoint共216个depthwise权重张量空间尺寸为7×7，另外12个G-only控制无局部分支。48/48通过既定validation停止门。这不代表全局最优，也不构成MPB/Meep物理验收。

两平台当前扫描未发现正式7×7测试清单或结果表；训练制品均为`test_executed=false`。正式test仍以测试run及其审计为准，不能用本节补齐672个计划cell。来源与复算数据见第9节。
