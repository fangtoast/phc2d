# 全模型论文测试数据对比表

**截至2026-10-27：GL 7×7的48个冻结checkpoint已完成672/672个正式测试cell，224组三seed汇总通过联合审计，覆盖268.8万条checkpoint×样本预测。下方已用正式test结果替换所有7×7占位，原3×3和其他模型结果保留。**

GL 3×3 与 GL 7×7使用同一注册模型名称，但卷积核配置不同。7×7实际正式推理全部在N56完成，包含原定N40分片的接管；原训练平台和冻结分片身份仍保留。validation表与正式test表分别展示。

## 阅读方式

这版报告按**数据集**组织，每张表只回答一个问题：同一个数据集上不同模型的表现如何。展示表只保留数据集、测试方式和模型指标，不显示实验编号。实验编号、checkpoint、seed、平台和哈希只保留在末尾的原始证据索引中。

所有误差数值均为 **Band1–10 MRE (%)**，越低越好。新增训练表使用validation，测试表使用冻结test；两类数值分别标明。“均值 ± 标准差”为三个seed的均值和样本标准差（ddof=1）；跨来源均值为等权平均，不是合并所有样本后的微平均，也不把来源差异作为seed标准差。

训练制品中的`test_executed=false`描述训练阶段；训练结束后的独立评估run已完成672个正式test cell。正式测试证据以第9节联合审计和逐cell表为准，不使用本节validation数值代替。
