# EXP-FWD-031 四域完整测试结果

本页记录 EXP-FWD-031 当前四域口径的完整 frozen-test 结果：K5-Binary、K5-Graded、F50-Binary、F50-Graded 四个训练来源，三个模型，六个测试目标，三个 seed，共 216 个测试单元和 72 组三 seed 汇总。结果已通过去重与完整性审计，状态为 `216/216`、`72/72`。

## 1. 结论与证据边界

| 项目 | 当前结论 |
|---|---|
| 完整性 | 216/216 个唯一 `(case_id, target)` 测试单元通过审计 |
| 三 seed 汇总 | 72/72 组完成；均值与样本标准差均由三个 seed 重算 |
| 四域来源 | K5-Binary、K5-Graded、F50-Binary、F50-Graded |
| 测试目标 | 四域目标 + `dat007_12000` + `dat008_24000` |
| 模型 | `global_local_channel_gate_v1`、`official_fno_band_v1`、`official_tucker_tfno_band_v1` |
| 主指标 | Band1–10 MRE（%），越低越好 |
| 证据性质 | surrogate held-out、跨域和新几何迁移测试 |
| 物理边界 | 不包含 MPB/Meep 物理验收，不将本页指标称为物理验证 |

N40 与 N56 对最后缺失单元分别重跑并完成一致性复核；两份结果的 checkpoint、数据集、测试划分和样本数一致，指标差异约 `3.3×10⁻⁸`，按跨节点浮点容差通过。最终合并按唯一测试单元计数，重复执行只作为交叉核对。
