# 工作频率与带隙探索总结

**截至 2026-08-31，当前证据支持“理论频率可作为弱频率区域先验”，不支持“理论公式已经找到精确工作频率或 complete gap”。** $9\times9$ MPB 标签中的 gap center 通常比 gap width 稳定；现有 gap-aware loss 能明显改善 band/$k$ 决策位置，却牺牲全谱误差并漏掉 complete gap。当前不应执行写死 B1–B2 或依赖粗网格 complete/pseudo 标签的训练；若继续 loss 路线，应在 Bands 1–10 全部坐标上使用有界、弱强度的频率窗口，并先完成扩大后的自适应 BZ 物理门。

本文是跨实验综合解释，不产生新的实验完成状态。原始证据仍以各 run、metrics、solver 制品和独立结果页为准。

## 二、必须分开的三个量

项目统一使用 MPB 无量纲频率

$$
\tilde f=\frac{fa}{c}=\frac{\omega a}{2\pi c}=\frac{a}{\lambda}.
$$

| 量 | 定义 | 当前能否精确获得 |
|---|---|---|
| 理论折叠频率 $\tilde f_0$ | 由有效介质与 reciprocal-lattice 折叠得到的低阶频率尺度 | 只能近似；当前单一 TE 标量估计器未通过 |
| gap center | 相邻两条 band 的全 BZ 下边缘最大值与上边缘最小值的中点 | 需要足够密的全 BZ 求解；$9\times9$ 只是粗标签 |
| 器件工作频率 | 结合 complete gap、传播方向、激励和器件目标最终选择的频率 | 不能仅由折叠公式或 band pair identity 决定 |

因此，“公式频率靠近某个 band pair”不等于“该处存在 complete gap”，更不等于“已经确定器件工作频率”。

## 四、理论先验经历了什么

### 4.1 旧先验没有对齐最大 gap

EXP-FWD-012 使用旧平均折射率和 $X/M$ 一阶 Bragg 尺度，得到：

| Validation 指标 | Binary | Graded |
|---|---:|---:|
| $X$ 窗口谱坐标覆盖率 | 90.9% | 91.4% |
| $X$ 最大 gap-center 命中率 | 0.0% | 0.0% |
| $M$ 最大 gap-center 命中率 | 0.0% | 0.0% |
| 固定中心最大 gap-center 命中率 | 1.4% | 2.4% |
| $X$ 相对固定中心改善 | -1.4 pp | -2.4 pp |

谱坐标覆盖率较高，只说明数据中有频率坐标落入窗口；它不能证明窗口对应最大 gap。该实验原先只在 lower-band 2–9 中定义最大 gap，因此也不能回答 Band 1 是否对应理论尺度。

### 4.2 偏振修正后的简单 TE 标量公式也没有成立

EXP-PHY-005 对 Band 1 near-$\Gamma$ 斜率做 real-MPB 校准。数值求解本身通过，但候选公式失败：

| Lane | 旧公式 median / P90 slope error | TE 调和候选 median / P90 | 方向差异 median / P90 |
|---|---:|---:|---:|
| Binary | 7.77% / 15.08% | 24.81% / 27.03% | 1.77% / 5.36% |
| Graded | 5.83% / 9.24% | 20.71% / 23.08% | 1.39% / 3.64% |

Binary 各向异性 P90 `5.36%` 超过 `5%` 门；pooled paired bootstrap 也表明 TE 候选误差显著增大。这里被否定的是“用一个方向无关的简单标量平均同时表示当前二维 TE 全胞结构”，不是均匀介质折叠图像本身。

### 4.3 三个折叠候选只有 $x$ 稳定映射到同一 pair

| 候选 | Validation pair 一致率 Binary / Graded | 落入 oracle complete gap |
|---|---:|---:|
| `gamma_g1` | 0% / 0% | 0/32、0/32 |
| `x` | 96.88% / 100% | 0/32、0/32 |
| `m` | 0% / 0% | 0/32、0/32 |

`x` 在当前数据上通常映射到 B1–B2，但这是“频率到 band pair 的数据映射结果”，不是公式直接输出 B1–B2。更关键的是，没有一个 validation oracle 频率真正落入 complete gap。

## 五、公式频率到底偏多少

在 EXP-PHY-006 的四个结构上，用 EXP-PHY-005 的解析 `x` 候选与加密后的 B1–B2 中点比较：

| 样本 | 公式频率 | 加密 B1–B2 中点 | 绝对偏差 | 相对偏差 | 加密 signed width |
|---|---:|---:|---:|---:|---:|
| Binary 89 | 0.32462 | 0.28758 | 0.03703 | 12.88% | -0.06946 |
| Binary 96 | 0.35564 | 0.30954 | 0.04610 | 14.89% | -0.05739 |
| Graded 62 | 0.26010 | 0.24369 | 0.01641 | 6.73% | -0.05147 |
| Graded 337 | 0.30539 | 0.27453 | 0.03086 | 11.24% | -0.06838 |

这些数值只覆盖 4 个 validation 结构，不能外推为总体误差分布。它们说明公式可以给出低频区域，但偏差达到约 7%–15%，而且四个 B1–B2 均为 band overlap，不是 complete gap。

## 六、gap 标签看起来准在哪里，又错在哪里

EXP-PHY-006 把 $9\times9$ 结果视为 coarse prediction，把局部加密 real-MPB 视为更高精度参考。四个结构、36 个 pair 的汇总为：

| 指标 | 结果 |
|---|---:|
| gap center MAE / RMSE | 0.001752 / 0.002471 |
| gap center 最大绝对变化 | 0.008062 |
| center 平均 / 中位相对误差 | 0.393% / 0.211% |
| signed width MAE / RMSE | 0.008139 / 0.011455 |
| signed width 最大误差 | 0.029797 |
| width 实质变化 | 32/36 |
| coarse/refined 状态一致 | 35/36 |
| coarse complete 中保留下来的 complete | 1/2 |

`35/36=97.22%` 的状态一致率具有误导性，因为绝大多数 pair 都是 pseudo-gap。对真正稀少的 coarse complete 候选，当前小样本中只有一半保留正宽度。

### 6.1 中心很准，但宽度被高估

Binary 89 的 B9–B10：

| 量 | $9\times9$ | 加密参考 | 偏差 |
|---|---:|---:|---:|
| lower edge | 0.763746 | 0.766613 | 0.002868 |
| upper edge | 0.772832 | 0.768728 | 0.004105 |
| center | 0.768289 | 0.767670 | 0.000619 |
| signed width | 0.009087 | 0.002115 | 0.006972 |

center 相对误差只有约 `0.081%`，但 width 被高估约 `330%`。上下边缘朝相反方向移动时，它们在 center 中会相互抵消，却会共同压缩 width。

### 6.2 粗网格 complete 发生符号翻转

Binary 96 的 B8–B9 从 `+0.0041515` 变为 `-0.0017374`，即 coarse complete 变成 refined pseudo。其估计局部不确定度为 `0.0023873`，所以严谨分类是 `numerically_ambiguous`：可以证明粗 complete 标签不可靠，但不能把两轮局部加密夸大为连续 BZ 的全局无 gap 认证。

## 七、代理 loss 实际改善了什么

EXP-FWD-014 比较相同 `dual_lane_band_operator_v1`、seed0 和 20-epoch 预算下的 full-matrix MSE 与 gap-aware v1。

| 指标变化 | Binary | Graded | 解释 |
|---|---:|---:|---|
| joint band-$k$ accuracy | +10.9 pp | +15.1 pp | 决策位置明显改善 |
| upper-edge $k$ accuracy | +20.9 pp | +26.8 pp | relative $k$-profile 项有效 |
| gap width MAE | -6.84% | -5.08% | coarse-label validation 上改善 |
| work-frequency MRE | -4.67% | -14.63% | Binary 未达到预注册的 5% 门 |
| Bands 2–10 MRE | +13.44% | +12.65% | 全谱安全门失败 |
| gap center MAE | +7.27% | -8.52% | Binary 方向退化 |

因此 v1 不是“完全无效”，而是把有限优化能力过多分配给 gap 决策位置。它没有把位置改善转化为可靠 complete gap：EXP-FWD-014 中 complete-gap 子集 status accuracy 仍为 0。

EXP-FWD-015 进一步排除了“严格命中率主要被近简并低估”的解释：

| Lane | 模型 | 严格 joint | 容差 joint | 非近简并严格 joint | complete-gap recall |
|---|---|---:|---:|---:|---:|
| Binary | baseline | 13.5% | 16.0% | 13.9% | 36.2% |
| Binary | gap-aware v1 | 24.4% | 27.3% | 27.7% | 9.7% |
| Graded | baseline | 7.7% | 10.6% | 7.6% | 0.0% |
| Graded | gap-aware v1 | 22.8% | 25.8% | 24.8% | 0.0% |

最大容差增益只有 3.0 个百分点；低命中主要来自模型候选排序和正 gap 召回能力，而不是指标定义过严。

## 八、loss 逻辑如何被修正

### 8.1 已否定或暂时冻结的做法

| 做法 | 当前状态 | 原因 |
|---|---|---|
| 把简单 TE 调和平均得到的 $\tilde f_0$ 当精确中心 | 否定 | slope 误差和方向门失败 |
| 把 `x` 高 pair 一致率解释成已找到 gap | 否定 | complete-gap 命中为 0，四个加密 B1–B2 均 overlap |
| 写死只关注 B1–B2 | 不成立 | 公式输出频率，不输出 band 编号；B1–B2 只是当前数据映射 |
| 直接强化 $9\times9$ gap width/status | 冻结 | edge 和 signed width 存在实质粗网格误差 |
| 直接运行 `equal_lane_gap_ranked_v2` | 不准入 | 当前配置从 Band 2 开始且依赖粗 gap 排序/status；尚未形成训练结果 |

### 8.2 当前唯一合理的候选：全 band 弱频率窗口

若后续物理门通过，理论公式只生成逐结构频率尺度 $\tilde f_0$。对 Bands 1–10 的全部坐标定义有界权重：

$$
w_{qb}^{\mathrm{raw}}
=
1+\rho\exp\left[-\frac{(f_{qb}-\tilde f_0)^2}{2\sigma_f^2}\right],
\qquad
w_{qb}=\frac{w_{qb}^{\mathrm{raw}}}{\operatorname{mean}_{q,b}w_{qb}^{\mathrm{raw}}}.
$$

$$
\mathcal L_{\mathrm{freq}}
=
\operatorname{mean}_{q,b}
w_{qb}(\hat z_{qb}-z_{qb})^2,
$$

$$
\mathcal L_{\mathrm{total}}
=
(1-\alpha)\mathcal L_{\mathrm{full}}
+\alpha\mathcal L_{\mathrm{freq}}.
$$

这一候选具备四个边界：

1. $q,b$ 覆盖全部 k 点和 Bands 1–10，不预设 pair；
2. 所有坐标保持非零监督，频率窗口只是弱增益；
3. 高斯权重有上界，避免逆距离分母使少数坐标主导梯度；
4. $\sigma_f$、$\rho$ 和 $\alpha$ 只能由 train/预注册合同冻结，不能读取 test 追调。

这只是尚未执行的候选 loss，不是已有训练结果。由于当前 $\tilde f_0$ 标量估计器未通过，候选仍处于物理门后，不得登记成已准入 N40。

## 九、当前决策与下一门

### 已确定的决策

- EXP-FWD-013 未启动；EXP-FWD-014 不扩三 seed。
- EXP-FWD-016 当前 ranked-v2 配置不应直接执行。
- EXP-FWD-017 resonance-prior 路线未解锁。
- 不使用 test 调整频率中心、窗口或 gap 定义。
- 不把 4 个 EXP-PHY-006 样本外推为整个 Binary/Graded 数据分布。

### 唯一最近 gate

先登记并执行 64 个 validation 结构的全局自适应 BZ 验证，建议 Binary 32 + Graded 32。它应：

1. 枚举 B1–B2 至 B9–B10；
2. 围绕所有候选 lower maximum 和 upper minimum 迭代加密；
3. 同时检查 refinement shift 与 resolution shift；
4. 报告 edge、center、signed width、pair identity 和 complete/pseudo；
5. 保持 `test_targets_loaded=false`、`training_started=false`、`n40_used=false`。

只有该门证明精细标签可以稳定生成，且人工接受理论频率只能作为弱窗口，才申请两个 N40 seed0 配对任务：原 full-matrix MSE 与一个全-band bounded-frequency-window loss。两个任务保持同一数据、模型、初始化、优化器、batch、epoch 和 checkpoint 规则，不同时混入 gap ranking 或 adaptive gate。
