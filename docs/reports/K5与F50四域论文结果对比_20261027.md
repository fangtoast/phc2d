# K5与F50四域论文结果对比

**本报告以K5-Binary、K5-Graded、F50-Binary、F50-Graded为论文主体四域，重新计算全部展示均值。K20作为高频补充单列，原六域报告和实验记录保留。** 这是测试完成后的论文展示范围调整，不是新增四域训练实验，也不改变冻结checkpoint和模型选择规则。文档为Draft，待作者审核。

## 1. 四域口径与阅读方式

| 内容 | 本报告采用的口径 |
| --- | --- |
| 原域 | 四个来源各自的冻结test split |
| 四域交叉 | 四来源×四目标；区分原域、跨lane、跨域、同时变化 |
| 12K/24K | 仅对四个单域训练来源等权平均，两类测试分别展示 |
| K8/K10/K15 | 每个目标只汇总四个训练来源，保留六目标明细 |
| K20 | 放在第7节，不进入正文四域平均 |
| mixed模型 | 原K5+K20训练，放第8节；不能改称K5+F50四域训练 |

全部主表为 **Band1–10 MRE（%），越低越好**。单个来源—目标的“均值 ± 标准差”由三个seed重算，标准差为样本标准差（ddof=1）。跨来源/目标均值为等权宏平均，不按样本量加权；K5 test每域1000、F50每域5000，不能把两种平均混用。宏平均不附上来源之间的标准差冒充seed波动。

GL 3×3与GL 7×7对应同一注册模型的核尺寸变体，合计九种模型、十行配置；Residual MLP不是ResNet。所有主表保留全部模型，但不同模型的参数量、优化合同仍须参照原报告核对，不能把全模型排序等同于严格参数量匹配排名。

本次未统一重算MAE、RMSE和P95，故不填占位值，也不把已有MRE表改名为MAE。后续多指标表应统一反归一化、能带范围和逐样本聚合口径。Band2–10的四域原域汇总在第6节单列。

与原六来源汇总相比，需要同步修改三点解释：

- 四域原域平均中，GL两种核略低于TFNO；差距很小，尚未做匹配差异检验，不能宣称显著领先。
- 只保留K5/F50训练来源后，12K与24K均为GL 3×3低于GL 7×7。原六来源下“7×7改善新几何平均误差”的结论不能移植到四来源口径。
- 两种GL在跨lane和同时变化的平均误差低于TFNO，但ConvNeXt在这两类平均上更低；不能将“优于TFNO”写成“所有模型最优”。
