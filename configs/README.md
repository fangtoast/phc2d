# Configs

统一配置入口按实验用途分组：

| 目录 | 作用 |
|---|---|
| [`research/`](research/) | 后续研究配置 |
| [`smoke/`](smoke/) | 本地快速 smoke 配置 |

论文复现、正式研究与 WSL 验收配置均由 `research/` 中的明确实验 ID 区分；快速编辑期检查使用 `smoke/`。旧顶层实现目录不再作为活跃配置入口。
